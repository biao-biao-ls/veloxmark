# Настройки

Откройте настройки сочетанием `Ctrl+,` (`Cmd+,` в macOS) или через меню приложения
**Файл → Настройки**. Параметры сохраняются между сессиями.

## Оформление

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Тема | Как в системе | `light` / `dark` / следовать за ОС. Переключается в меню «Вид». |
| Шрифт редактора | Системный набор | Гарнитура шрифта рабочей поверхности. |
| Размер шрифта | 16 | Размер шрифта редактора в пикселях. |
| Межстрочный интервал | 1.6 | Межстрочный интервал редактора. |
| Ширина колонки содержимого | 0 (авто) | Максимальная ширина строки рабочей колонки; `0` — выбор приложения. |
| Показывать строку состояния | Вкл. | Позиция курсора, счётчики и индикаторы режимов. |
| Боковая панель открыта по умолчанию | Вкл. | Когда предыдущая сессия не запомнена. |

## Редактор

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Помощники ввода | Вкл. | Продолжение списков, повышение уровня заголовка, преобразования при вставке. |
| Оборачивать голые URL при вставке | Вкл. | Превращать вставленный голый URL в Markdown-ссылку. |
| Преобразовывать HTML при вставке | Вкл. | Преобразовывать вставленный богатый текст в аккуратный Markdown. |
| Форматировать при сохранении | Выкл. | Нормализовать Markdown (интервалы, маркеры списков, выравнивание таблиц) перед записью. |
| Показывать номера строк | Выкл. | Колонка номеров строк в редакторе. |
| Номера строк в блоках кода | Выкл. | Рендерить номера строк внутри виджетов блоков кода. |
| Мягкий перенос в блоках кода | Вкл. | Переносить длинные строки внутри блоков кода. |
| Порог свёртки блока кода | 20 строк | Более длинные блоки сворачиваются с элементом развёртывания; `0` отключает. |
| Режим фокуса | Выкл. | Затемнять всё, кроме текущей области. |
| Режим печатной машинки | Выкл. | Удерживать строку с курсором на вертикальном центре. |
| Режим исходного кода | Выкл. | Всегда показывать сырой Markdown. |

## Файлы

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Автосохранение | С задержкой (3 с) | `off` / `debounce` (после того как набор останавливается) / `interval` (каждые N минут). |
| Задержка автосохранения | 3 с | Задержка для режима с задержкой. |
| Интервал автосохранения | 5 мин | Интервал для режима по интервалу. |
| Черновики восстановления после сбоя | Вкл. | Хранить черновики несохранённых изменений и предлагать восстановление после сбоя. |
| Восстанавливать последнюю сессию | Вкл. | Вновь открывать вкладки, папки и позицию курсора при запуске. |
| Показывать скрытые файлы | Выкл. | Показывать файлы с точкой в дереве файлов. |
| Игнорируемые имена | `node_modules`, `.git`, … | Имена, скрытые из дерева файлов. |

## Изображения и вложения

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Папка вложений | `assets` | Папка (относительно документа) для вставленных/вставленных изображений. |
| Именование файлов изображений | Время | Имена с меткой времени или сохранение оригинального имени файла. |
| Копировать внешние изображения | Вкл. | Копировать изображения извне папки документа во вложения. |
| Скачивать удалённые изображения | Выкл. | Загружать удалённые URL изображений во вложения. |
