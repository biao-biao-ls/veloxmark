# Автообновление

VeloxMark проверяет [GitHub Releases](https://github.com/biao-biao-ls/veloxmark/releases)
на предмет новых версий и направляет обновление по-разному в зависимости от того, как вы
установили приложение.

## Поведение по форме установки

| Форма установки | Поведение обновления |
| --- | --- |
| Установщик Windows NSIS | Полная проверка → загрузка → запрос → установка при перезапуске |
| Linux AppImage | Полная проверка → загрузка → запрос → установка при перезапуске |
| macOS (dmg / zip) | Только проверка — неподписанная сборка не может завершить обновления Squirrel.Mac, поэтому приложение открывает страницу релизов |
| Портативный zip / deb / rpm / snap / tar.gz | Только уведомление — о новой версии сообщается и даётся ссылка |
| Режим разработки (`npm run dev`) | Только уведомление |

После завершения загрузки **приложение спрашивает разрешение, прежде чем выйти для
установки**, — ничего не происходит за вашей спиной.

## Ручная проверка

Используйте **Справка → Проверить обновления** в меню приложения. В формах установки с
только уведомлениями это открывает страницу релизов или указывает на неё.

## Манифесты обновлений

Артефакты релиза включают манифесты electron-updater (`latest.yml`, `latest-mac.yml`,
`latest-linux.yml`, `latest-linux-arm64.yml`) и `SHA256SUMS.txt`. Поле `path` манифеста
для Windows указывает на универсальный `VeloxMark-Setup-<ver>.exe`.

## Если обновление не удалось

1. Проверьте сеть / прокси — обновления приходят из GitHub Releases.
2. Проверьте загрузку вручную по `SHA256SUMS.txt`
   (см. [Установка](./installation#проверка-загрузки)).
3. Переустановите свежую версию со
   [страницы релизов](https://github.com/biao-biao-ls/veloxmark/releases) —
   ваши настройки и черновики сохранятся.
