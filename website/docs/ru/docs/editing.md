# Подробнее о редактировании

Редактор VeloxMark — это CodeMirror 6 с движком декораций, который перестраивает
отрендеренный вид при каждом изменении документа и выделения. Эта страница объясняет,
как это ведёт себя во время написания.

## Живой предпросмотр

- Когда курсор покидает строку, её синтаксические маркеры (`#`, `**`, `` ` ``, `*`,
  `~~`, `==`) скрываются декорациями замены, и строка показывает свой окончательный
  стилизованный вид.
- **Строка с курсором всегда остаётся в исходной форме** — вы всегда видите именно то,
  что печатаете.
- Щелчок по скрытому маркеру возвращает исходную форму для этого диапазона.

## Блочные виджеты

Блоки кода, формулы `$$`, диаграммы Mermaid и изображения рендерятся как виджеты
вместо своего исходного кода. **Щёлкните по любому отрендеренному блоку, чтобы
отредактировать его исходный код**; покиньте блок — и он снова отрендерится.

## Таблицы

Таблицы — первоклассные: каждая ячейка — вложенный редактор CodeMirror.

- **Вставка / преобразование** — используйте диалог вставки таблицы, чтобы создать
  таблицу с выбранным числом строк и столбцов, или преобразуйте текущий абзац в
  таблицу.
- **Изменение ширины столбцов** — перетаскивайте границу столбца.
- **Выравнивание** — задавайте выравнивание по столбцам (влево / по центру / вправо);
  строка-разделитель исходного кода (`:---`, `:--:`, `---:`) поддерживается в
  синхроне.
- Все правки проходят через транзакции обратно в диапазон Markdown-исходника,
  которым владеет виджет, — документ никогда не изменяется за вашей спиной.

## Режимы фокуса и печатной машинки

- **Режим фокуса** затемняет всё, кроме абзаца, который вы пишете.
- **Режим печатной машинки** удерживает строку с курсором на вертикальном центре.
- Оба режима можно сочетать; строка состояния показывает чипы `FOCUS` / `TYPEWRITER`,
  пока они активны.

## Помощники ввода

- **Вставка HTML → Markdown** — богатый текст, вставленный из буфера обмена,
  преобразуется в аккуратный Markdown.
- **Голые URL** — вставленный голый URL автоматически оборачивается в ссылку.
- **Списки задач** — `- [ ]` рендерится как щёлкаемый флажок; щелчок переключает его.
- **Отмена/повтор** — полная история транзакций (`Ctrl+Z` / `Ctrl+Shift+Z`).

## Редактирование с несколькими вкладками

Открывайте несколько файлов сразу. Вкладки можно закрывать и открывать заново,
несохранённые изменения отмечаются, а порядок вкладок можно менять перетаскиванием.

## Блоки кода

- Подсветка синтаксиса через highlight.js для сотен языков.
- Необязательные номера строк, мягкий перенос и свёртка длинных блоков — см.
