# Введение

Добро пожаловать в пользовательскую документацию VeloxMark — бесплатного
Markdown-редактора с открытым исходным кодом и живым предпросмотром для macOS, Windows
и Linux, вдохновлённого Typora и построенного на Electron + CodeMirror 6.

![Интерфейс VeloxMark](/img/hero-light.png)

</div>

## Чем VeloxMark отличается от других

**Исходный текст Markdown — единственный источник данных.** Всё богатое —
отрендеренные заголовки, формулы, диаграммы, таблицы — это эфемерное украшение поверх
вашего обычного текстового файла. Сохранение записывает чистый `.md` с нулевыми
потерями при цикле чтения-записи. Никакого проприетарного формата документов и
никакого скрытого состояния.

Движок живого предпросмотра перестраивает свои украшения при каждом изменении
документа и выделения: синтаксические маркеры скрываются декорациями замены, а блоки
кода / формул / mermaid / изображений подменяются отрендеренными виджетами. Когда
курсор входит в диапазон, декорация для этого диапазона пропускается, и возвращается
исходная форма. Строка с курсором всегда остаётся в исходной форме, поэтому вы всегда
точно знаете, что редактируете.
