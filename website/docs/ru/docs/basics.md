# Основы

VeloxMark открывается с приветственным документом, который одновременно служит
экскурсией по возможностям. Эта страница проведёт вас по окну, боковой панели,
вкладкам и режимам редактора.

## Окно

<div class="vm-shot">

![Окно VeloxMark](/img/hero-light.png)

</div>

- **Заголовок окна** — пользовательская безрамочная панель с меню приложения (Файл /
  Правка / Вид / Вставка / Справка) и элементами управления окном. Следует за
  светлой/тёмной темой.
- **Боковая панель** — три панели: **Файлы** (рабочая папка), **Структура** (дерево
  заголовков активного документа) и **Поиск** (поиск по папке).
- **Панель вкладок** — по одной вкладке на открытый документ, с отметкой
  несохранённых изменений.
- **Редактор** — рабочая поверхность с живым предпросмотром.
- **Строка состояния** — позиция курсора, счётчики слов / символов / строк и
  индикаторы режимов фокуса, когда они активны.

## Боковая панель

- **Файлы** — откройте папку и просматривайте её Markdown-файлы; щелчок открывает файл
  во вкладке.
- **Структура** — дерево заголовков активного документа с переходом по щелчку и
  подсветкой текущей позиции.
- **Поиск** — поиск по содержимому в открытой папке с заменой.

## Вкладки

- Открывайте несколько файлов сразу; каждый получает свою вкладку.
- Несохранённые изменения отмечаются на вкладке.
- Закрывайте и открывайте вкладки заново; закрытую вкладку можно восстановить.
- Перетаскивайте вкладки, чтобы изменить порядок.

## Режимы редактора

| Режим | Что делает |
| --- | --- |
| **Живой предпросмотр** (по умолчанию) | Markdown рендерится на месте; строка с курсором остаётся в исходной форме |
| **Режим исходного кода** | Всегда сырой Markdown для полного контроля |
| **Режим фокуса** | Всё, кроме текущей строки, затемняется |
| **Режим печатной машинки** | Текущая строка остаётся закреплённой по вертикальному центру |

Переключайте тему из меню «Вид». Полный список команд: [Горячие клавиши](./key-bindings).

## Открытие и сохранение

- **Откройте** файл `.md` (`Ctrl+O` / `Cmd+O`) или откройте папку из меню «Файл».
- **Сохранение** (`Ctrl+S` / `Cmd+S`) записывает обычный исходный текст обратно —
  нулевые потери при цикле чтения-записи.
- **Сохранить как** записывает копию под новым именем.
- Несохранённая работа сохраняется как черновик и может быть восстановлена.
