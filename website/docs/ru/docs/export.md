# Экспорт документа

VeloxMark экспортирует из **исходного текста Markdown**, а не из DOM редактора, поэтому
результат в точности соответствует вашему документу. Доступно из меню «Файл»:
**Экспорт → PDF…** или **Экспорт → HTML…**. Оба открывают общий диалог экспорта.

## Параметры

| Группа | Параметр | Значения |
| --- | --- | --- |
| Страница (PDF) | Формат бумаги | A4, Letter |
| Страница (PDF) | Поля | Обычные, узкие |
| Страница (PDF) | Колонтитулы | Вкл / выкл — вверху отображается название документа / имя файла, внизу — `page / total` |
| Стиль | Тема | Следовать за текущей темой или принудительно светлая |
| Изображения | Встраивать как base64 / сохранять относительные пути | PDF всегда встраивает |
| Математика | Шрифты KaTeX | Встроить (готово к офлайну) или резервный CDN (файл меньше) |

## Что рендерится

Полный конвейер воспроизводит всё, что показывает живой предпросмотр:

- Заголовки, списки, списки задач (как отмеченные флажки), таблицы с выравниванием
- Код с цветами подсветки синтаксиса highlight.js
- **Формулы KaTeX** как настоящая набранная математика
- **Диаграммы Mermaid** как встроенный SVG
- Выноски, сноски (нумерованные со обратными ссылками), `==подсветка==`, верхний
  индекс, нижний индекс, аббревиатуры и списки определений
- Изображения с атрибутами размера / выравнивания / отражения, разрешённые
  относительно документа и встроенные там, где это указано в параметрах
- `title` из метаданных становится заголовком H1 документа

Генерация PDF рендерит HTML в скрытом песочничном окне, дожидается загрузки шрифтов и
изображений, затем печатает в PDF с фонами.

## Экспорт только выделения

**Правка → Экспортировать выделение как HTML…** экспортирует только выделенный диапазон
как отдельный HTML-файл (если ничего не выделено, используется весь документ). Тот же
охват «выделение или документ» действует для **Копировать как богатый текст** и
**Копировать как HTML**.

## Гарантия обратной совместимости

Экспорт никогда не изменяет ваш файл. Файл `.md` на диске остаётся единственным
источником истины; экспортированный PDF/HTML — лишь его отображение.
