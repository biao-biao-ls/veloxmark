# Горячие клавиши

VeloxMark ориентирован на клавиатуру. В Windows и Linux сочетания используют `Ctrl`; в
macOS те же привязки используют `Cmd` (в меню отображаются символом ⌘), и пункты ниже,
помеченные префиксом `Ctrl`, в macOS читаются как `Cmd`. Сочетания также показываются
рядом с каждой командой в меню приложения.

## Привязки уровня редактора

Работают во время набора в редакторе:

| Сочетание | Действие |
| --- | --- |
| `Tab` / `Shift+Tab` | Отступ / убрать отступ (у элементов списка) |
| `Enter` на пустом элементе списка | Выйти из списка |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+E` | Переключить жирный / курсив / строчный код |
| `Ctrl` + щелчок по ссылке | Открыть ссылку |
| Щелчок по отрендеренному блоку | Редактировать его исходный код |
| Щелчок по флажку задачи | Переключить `[ ]` / `[x]` |

## Редактирование таблиц

Во время редактирования ячейки таблицы:

| Сочетание | Действие |
| --- | --- |
| `Tab` / `Shift+Tab` | Следующая / предыдущая ячейка |
| `Enter` / `Shift+Enter` | Ячейка ниже / выше |
| `Ctrl+Enter` / `Ctrl+Shift+Enter` | Вставить строку ниже / выше |
| `Ctrl+Shift+←` / `→` | Вставить столбец слева / справа |
| `Alt+↑↓←→` | Переместить строку / столбец |
| `Escape` | Выйти из редактирования таблицы |
