# Изображения

VeloxMark разрешает изображения так, как и должен разрешать Markdown-файл на диске, —
относительно файла, который вы редактируете.

## Поддерживаемые пути

| Форма | Пример | Разрешается относительно |
| --- | --- | --- |
| Относительный путь | `![альт](./img/chart.png)` | Каталог текущего `.md`-файла |
| Абсолютный путь | `![альт](C:\pics\a.png)` / `![альт](/home/me/a.png)` | Корень файловой системы |
| Удалённый URL | `![альт](https://example.com/a.png)` | Загружается по сети |
| Data URI | `![альт](data:image/png;base64,…)` | Встраивается прямо в текст |

Относительные пути — переносимый выбор: перенесите папку с вашим `.md` и его
изображениями вместе — и всё продолжит работать.

## Размер и атрибуты

Необязательный суффикс `=WxH` после URL задаёт отображаемые размеры, а группы `{…}`
после закрывающей скобки задают выравнивание и отражение:

```markdown
![logo](./logo.png =128x128)
![banner](./banner.png =800x200){align=center}{flip=h}
```

| Атрибут | Значения | Эффект |
| --- | --- | --- |
| `=WxH` | например `=128x128` | Размер отображения в пикселях |
| `{align=…}` | `left`, `center`, `right` | Горизонтальное выравнивание |
| `{flip=…}` | `h`, `v`, `hv` | Зеркальное отражение по горизонтали / вертикали / обоим осям |

Отрендеренные изображения также можно **менять в размере перетаскиванием** мыши
(это задаёт ширину в `%`), а виджет изображения предлагает выравнивание, отражение,
сброс размера, редактирование URL и «Показать в файловом менеджере».

## Щелчок для редактирования

Изображения рендерятся как виджеты. Щёлкните по изображению, чтобы отредактировать его
Markdown-исходник; покиньте блок — и он снова отрендерится — так же, как блоки кода,
формул и диаграмм.

## Локальная безопасность

Локальные изображения обслуживаются через внутренний протокол приложения `mdres://`, а
не через прямой доступ `file://`, поэтому документ может показывать только те
изображения, которые приложение намеренно делает доступными.
