# Язык и локализация

Интерфейс VeloxMark поставляется на девяти языках:

| Язык | Код |
| --- | --- |
| Английский | `en` |
| Китайский | `zh` |
| Японский | `ja` |
| Корейский | `ko` |
| Испанский | `es` |
| Португальский | `pt` |
| Французский | `fr` |
| Немецкий | `de` |
| Русский | `ru` |

(В выборе языка приложения каждый язык указан под собственным самоназванием.)

Локализация покрывает весь интерфейс: меню (нативные в macOS), диалоги, строку состояния
— и даже образцы приветственных / справочных документов и тела шаблонов Mermaid,
которые выбираются по локали.

## Выбор языка

- **Следовать за системой** — по умолчанию приложение выбирает язык интерфейса по
  локали вашей ОС, если для неё существует языковой пакет, иначе откатывается на
  английский.
- **Задать явно** — в настройках / меню «Вид»; выбор запоминается между сессиями.

## Переводы

Переводы хранятся в одном файле-пакете на язык (словарь интерфейса, строки нативных
меню, приветственные / справочные документы и шаблоны Mermaid). Совпадение ключей
словаря обеспечивается системой типов — новый язык должен поставлять все четыре пакета,
чтобы пройти `npm run typecheck`. Ждём ваших предложений на
[GitHub](https://github.com/biao-biao-ls/veloxmark).
