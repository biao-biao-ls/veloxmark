# Частые вопросы (FAQ)

### Какие платформы поддерживаются?

macOS (Apple Silicon и Intel), Windows 10/11 (x64 и ARM64) и Linux (x64 и arm64 —
AppImage, deb, rpm, tar.gz; snap только x64). См. [Установка](./installation).

### VeloxMark бесплатный?

Да. VeloxMark распространяется с открытым исходным кодом по
[лицензии MIT](https://github.com/biao-biao-ls/veloxmark/blob/main/LICENSE). Без
аккаунта, без подписки, без телеметрии.

### Что такое «живой предпросмотр» и чем он отличается от разделённого вида?

Панели предпросмотра нет. Редактор рендерит ваш Markdown **на месте**: когда курсор
покидает строку, синтаксические маркеры вроде `#`, `**` и `` ` `` скрываются, и строка
показывает свой окончательный вид. Строка с курсором всегда остаётся в исходной форме,
а щелчок по любому отрендеренному блоку (код, формула, диаграмма, таблица, изображение)
возвращает его сырой Markdown для редактирования. Исходный текст Markdown — единственный
источник данных: сохранение записывает обычный `.md` с нулевыми потерями при цикле
чтения-записи.

### Изменяет ли VeloxMark мои Markdown-файлы при сохранении?

Нет. Сохранение записывает исходный текст обратно без изменений. Весь рендеринг — лишь
декорация.

### Какой синтаксис Markdown поддерживается?

CommonMark + GFM (таблицы, списки задач, зачёркивание), а также формулы KaTeX,
диаграммы Mermaid, выноски, сноски и `==подсветка==`. Полный справочник:
[Синтаксис Markdown](./markdown-syntax).

### Можно ли использовать VeloxMark для управления заметками?

VeloxMark — это сфокусированный редактор и читалка Markdown: открывайте папки и файлы,
используйте структуру и поиск, но слоя управления знаниями нет (ни тегов, ни обратных
ссылок, ни базы данных). Ваши файлы остаются обычными `.md` на диске, поэтому любой
другой инструмент может их подхватить.

### Как сообщить об ошибке?

Создайте issue на [GitHub](https://github.com/biao-biao-ls/veloxmark/issues), указав
версию приложения (меню «Справка»), вашу ОС, шаги воспроизведения и Markdown, который
ведёт себя неправильно.

### Где хранятся мои черновики и настройки?

Настройки, черновики и состояние сессии хранятся в стандартном каталоге данных
приложений пользователя (Electron `userData`): Windows `%APPDATA%\VeloxMark`, macOS
`~/Library/Application Support/VeloxMark`, Linux `~/.config/VeloxMark`. Сами документы
никогда не перемещаются и не копируются — вы редактируете файлы там, где они лежат.

### Почему macOS говорит, что приложение от неизвестного разработчика?

Релизные сборки в настоящее время неподписаны. Выполните один раз
`xattr -d com.apple.quarantine /Applications/VeloxMark.app` после установки — см.
[Установка](./installation#macos).

### Приложение не обновляется автоматически на моей платформе — это нормально?

Да. Полное автообновление включено для установок Windows NSIS и Linux AppImage; другие
формы установки работают только на уведомление, а macOS в настоящее время откатывается к
открытию страницы релизов, потому что сборки неподписаны. Подробности:
[Автообновление](./updates).
