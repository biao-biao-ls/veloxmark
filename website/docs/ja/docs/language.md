# 言語とローカライズ

VeloxMark の UI は 9 つの言語で提供されています：

| 言語 | コード |
| --- | --- |
| 英語 | `en` |
| 中国語 | `zh` |
| 日本語 | `ja` |
| 韓国語 | `ko` |
| スペイン語 | `es` |
| ポルトガル語 | `pt` |
| フランス語 | `fr` |
| ドイツ語 | `de` |
| ロシア語 | `ru` |

（アプリの言語選択では、各言語がそれぞれの言語名で表示されます。）

ローカライズは UI 全体をカバーします：メニュー（macOS ではネイティブ）、ダイアログ、
ステータスバー——そしてウェルカム／ヘルプのサンプルドキュメントや Mermaid テンプレートの
本文まで、ロケールに応じて選ばれます。

## 言語を選ぶ

- **既定ではシステムに追従**——その言語のパックが存在する場合、アプリは OS のロケールから
  UI 言語を選び、存在しなければ英語にフォールバックします。
- **明示的に設定**する場合は環境設定／表示メニューから。選択はセッションをまたいで記憶されます。

## 翻訳する

翻訳は言語ごとにひとつのパックファイル（UI 辞書、ネイティブメニュー文字列、
ウェルカム／ヘルプドキュメント、Mermaid テンプレート）にあります。辞書キーの対応は
型システムによって強制されます——新しい言語は、`npm run typecheck` を通すために
4 つのパックすべてを同梱する必要があります。
