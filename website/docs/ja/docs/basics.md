# 基本操作

VeloxMark は、機能ツアーを兼ねたウェルカムドキュメントを開きます。このページでは、
ウィンドウ、サイドバー、タブ、エディターモードを見ていきます。

## ウィンドウ

<div class="vm-shot">

![VeloxMark のウィンドウ](/img/hero-light.png)

</div>

- **タイトルバー** —— アプリメニュー（ファイル／編集／表示／挿入／ヘルプ）とウィンドウ制御を
  備えたカスタムのフレームレスバー。ライト／ダークテーマに追従します。
- **サイドバー** —— 3 つのパネル：**ファイル**（フォルダーのワークスペース）、
  **アウトライン**（アクティブなドキュメントの見出しツリー）、**検索**（フォルダー内検索）。
- **タブバー** —— 開いているドキュメントごとに 1 つのタブ。未保存の変更はマークされます。
- **エディター** —— ライブプレビューの執筆画面。
- **ステータスバー** —— カーソル位置、単語／文字／行数、有効時はフォーカスモードの表示。

## サイドバー

- **ファイル** —— フォルダーを開き、その Markdown ファイルを閲覧。クリックでタブに開きます。
- **アウトライン** —— アクティブなドキュメントの見出しツリー。クリックでジャンプ、
  現在位置をハイライト。
- **検索** —— 開いているフォルダーを横断する全文検索。置換にも対応。

## タブ

- 複数のファイルを同時に開くと、それぞれにタブが付きます。
- 未保存の変更はタブにマークされます。
- タブを閉じて再び開けます。閉じたタブは復元できます。
- タブをドラッグして並べ替えられます。

## エディターモード

| モード | 動作 |
| --- | --- |
| **ライブプレビュー**（既定） | Markdown がその場で描画される。カーソル行はソース形式のまま |
| **ソースモード** | 常に生の Markdown。完全な制御が欲しいときに |
| **フォーカスモード** | 現在の行以外がすべて暗くなる |
| **タイプライターモード** | 現在の行が垂直方向の中央に固定される |

テーマは表示メニューから切り替えられます。完全なコマンド一覧：[キーバインド](./key-bindings)。

## 開く・保存する

- `.md` ファイルを**開く**（`Ctrl+O` / `Cmd+O`）、またはファイルメニューからフォルダーを開く。
- **保存**（`Ctrl+S` / `Cmd+S`）はプレーンなソースを書き戻します——往復でロスはゼロ。
- **名前を付けて保存**は新しい名前のコピーを書き出します。
- 未保存の作業は下書きとして保持され、復元できます。
