# ドキュメントの書き出し

VeloxMark は **Markdown ソース**から書き出します——エディターの DOM からはではなく——
そのため出力はドキュメントと正確に一致します。ファイルメニューから利用できます：
**書き出し → PDF…** または **書き出し → HTML…**。どちらも共通の書き出しダイアログが開きます。

## オプション

| グループ | 設定 | 値 |
| --- | --- | --- |
| ページ（PDF） | 用紙サイズ | A4、Letter |
| ページ（PDF） | 余白 | 通常、狭い |
| ページ（PDF） | ヘッダーとフッター | オン／オフ——ヘッダーはドキュメントタイトル／ファイル名、フッターは `page / total` |
| スタイル | テーマ | 現在のテーマに追従、またはライトを強制 |
| 画像 | base64 で埋め込む／相対パスを保持 | PDF は常に埋め込む |
| 数式 | KaTeX フォント | 埋め込む（オフライン対応）または CDN フォールバック（ファイルサイズを抑えられる） |

## 何が描画されるか

完全なパイプラインは、ライブプレビューが表示するすべてを再現します：

- 見出し、リスト、タスクリスト（チェック済みチェックボックスとして）、配置付きテーブル
- highlight.js のシンタックスカラー付きのコード
- **KaTeX 数式**を実際の組版済み数式として
- **Mermaid 図表**をインライン SVG として
- コールアウト、脚注（後方参照付きで番号付け）、`==ハイライト==`、上付き、下付き、
  略語、定義リスト
- サイズ／配置／反転属性付きの画像。ドキュメントからの相対で解決され、
  オプションに従ってインライン化されます
- フロントマターの `title` はドキュメントの H1 になります

PDF 生成は、非表示のサンドボックス化されたウィンドウで HTML を描画し、フォントと画像を
待ってから、背景付きで PDF に印刷します。

## 選択範囲のみの書き出し

**編集 → 選択範囲を HTML として書き出す…** は、選択した範囲だけをスタンドアロンの
HTML ファイルとして書き出します（何も選択されていない場合はドキュメント全体を使用）。
同じ「選択範囲またはドキュメント」のスコープが **リッチテキストとしてコピー**と
**HTML としてコピー**にも適用されます。

## 往復の保証

書き出しはファイルを決して変更しません。ディスク上の `.md` が唯一の真実であり続け、
書き出された PDF/HTML はただの描画結果です。
