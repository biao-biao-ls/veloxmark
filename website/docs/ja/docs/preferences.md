# 環境設定

環境設定は `Ctrl+,`（macOS では `Cmd+,`）で開くか、アプリ内の **ファイル →
環境設定** メニューから開きます。設定はセッションをまたいで永続化されます。

## 外観

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| テーマ | システム | `light` / `dark` / OS に追従。表示メニューで切り替え。 |
| エディターのフォント | システムスタック | 執筆画面のフォントファミリー。 |
| フォントサイズ | 16 | エディターのフォントサイズ（ピクセル）。 |
| 行の高さ | 1.6 | エディターの行の高さ。 |
| コンテンツの列幅 | 0（自動） | 執筆列の最大行幅。`0` でアプリに選択させる。 |
| ステータスバーを表示 | オン | カーソル位置、カウント、モード表示。 |
| サイドバーを既定で開く | オン | 前のセッションが記憶されていないとき。 |

## エディター

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| 入力支援 | オン | リストの続き、見出しレベルの上げ、貼り付けの変換。 |
| 貼り付け時に裸の URL を囲む | オン | 貼り付けた裸の URL を Markdown リンクに変える。 |
| 貼り付け時に HTML を変換 | オン | 貼り付けたリッチテキストをクリーンな Markdown に変換する。 |
| 保存時にフォーマット | オフ | 書き出す前に Markdown を正規化（空白、リストマーカー、テーブル配置）。 |
| 行番号を表示 | オフ | エディターの行番号ガター。 |
| コードブロック内の行番号 | オフ | コードブロックウィジェット内に行番号を描画する。 |
| コードブロックをソフト折り返し | オン | コードブロック内の長い行を折り返す。 |
| コードブロックの折りたたみしきい値 | 20 行 | それより長いブロックは展開コントロール付きで折りたたむ。`0` で無効。 |
| フォーカスモード | オフ | 現在の領域以外をすべて暗くする。 |
| タイプライターモード | オフ | カーソル行を垂直方向の中央に固定する。 |
| ソースモード | オフ | 常に生の Markdown を表示する。 |

## ファイル

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| 自動保存 | デバウンス（3 秒） | `off` / `debounce`（入力が止まった後）/ `interval`（N 分ごと）。 |
| 自動保存の遅延 | 3 秒 | デバウンスモードの遅延。 |
| 自動保存の間隔 | 5 分 | インターバルモードの間隔。 |
| クラッシュリカバリの下書き | オン | 未保存の変更の下書きを保持し、クラッシュ後に復元を提案する。 |
| 最後のセッションを復元 | オン | 起動時にタブ、フォルダー、カーソル位置を開き直す。 |
| 隠しファイルを表示 | オフ | ファイルツリーにドットファイルを表示する。 |
| 無視する名前 | `node_modules`、`.git`、… | ファイルツリーから隠す名前。 |

## 画像と添付

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| 添付フォルダー | `assets` | 貼り付け／挿入した画像の置き場（ドキュメントからの相対）。 |
| 画像ファイルの命名 | タイムスタンプ | タイムスタンプ付きの名前、または元のファイル名を保持。 |
| 外部画像をコピー | オン | ドキュメントフォルダー外の画像を添付にコピーする。 |
| リモート画像をダウンロード | オフ | リモートの画像 URL を添付に取得する。 |

## 言語

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| UI 言語 | システム | OS のロケールに追従するか、9 つの言語のひとつに固定。[言語とローカライズ](./language) を参照。 |

## リンク

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| 外部リンクを確認 | オン | ブラウザでリンクを開く前に確認する。 |
