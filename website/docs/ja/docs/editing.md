# 編集の詳細

VeloxMark のエディターは CodeMirror 6 をベースに、ドキュメントと選択範囲が変わるたびに
描画ビューを再構築する装飾エンジンを備えています。このページでは、執筆中にそれが
どう振る舞うかを説明します。

## ライブプレビュー

- カーソルが行から離れると、その行の構文マーク（`#`、`**`、`` ` ``、`*`、`~~`、`==`）は
  置換装飾で隠れ、最終的なスタイル付きの形を表示します。
- **カーソル行は常にソース形式のまま**——自分が何を打っているか常に正確に見えます。
- 隠れたマークをクリックすると、その範囲のソース形式が戻ってきます。

## ブロックウィジェット

コードブロック、`$$` 数式、Mermaid 図表、画像は、ソースの代わりにウィジェットとして
描画されます。**描画されたブロックをクリックするとそのソースを編集できます**。ブロックから
離れると再び描画されます。

## テーブル

テーブルは第一級の存在です：各セルはネストした CodeMirror エディターです。

- **挿入／変換** —— テーブル挿入ダイアログで指定した行数・列数のテーブルを作成するか、
  現在の段落をテーブルに変換します。
- **列のリサイズ** —— 列の境界をドラッグします。
- **配置** —— 列ごとの配置（左／中央／右）を設定。ソースの区切り行
  （`:---`、`:--:`、`---:`）は常に同期されます。
- すべての編集はトランザクションを通じて、ウィジェットが所有する Markdown ソース範囲へ
  戻されます——ドキュメントが背後で書き換わることはありません。

## フォーカスモードとタイプライターモード

- **フォーカスモード**は、書いている段落以外をすべて暗くします。
- **タイプライターモード**は、カーソル行を垂直方向の中央に固定します。
- 両方は組み合わせられます。有効な間、ステータスバーに `FOCUS` / `TYPEWRITER` チップが
  表示されます。

## 入力支援

- **HTML を Markdown に貼り付け** —— クリップボードから貼り付けたリッチテキストを
  クリーンな Markdown に変換します。
- **裸の URL** —— 貼り付けた裸の URL は自動的にリンクで囲まれます。
- **タスクリスト** —— `- [ ]` はクリックできるチェックボックスとして描画されます。クリックで切替。
- **元に戻す／やり直す** —— 完全なトランザクション履歴（`Ctrl+Z` / `Ctrl+Shift+Z`）。

## 複数タブでの編集

複数のファイルを同時に開けます。タブは閉じて再び開け、未保存の変更はマークされ、
タブの並びはドラッグで並べ替えられます。

## コードブロック

- highlight.js による数百の言語のシンタックスハイライト。
- 任意の行番号、ソフト折り返し、長いブロックの折りたたみ——
  [環境設定](./preferences) を参照。

## 書き出し

ファイルメニューから PDF または HTML に書き出せます。選択範囲のみの HTML 書き出しにも
対応しています。[ドキュメントの書き出し](./export) を参照。
