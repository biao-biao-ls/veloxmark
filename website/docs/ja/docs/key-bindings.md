# キーバインド

VeloxMark はキーボードファーストです。Windows と Linux のショートカットは `Ctrl` を使い、
macOS では同じ割り当てが `Cmd`（メニューでは ⌘ グリフで表示）になります。以下の
`Ctrl` で始まる項目は macOS では `Cmd` と読んでください。ショートカットはアプリ内の
メニューで各コマンドの隣にも表示されます。

## ファイル

| コマンド | ショートカット | 説明 |
| --- | --- | --- |
| 新規 | `Ctrl+N` | 新しい無題のタブ |
| 開く… | `Ctrl+O` | `.md` ファイルを開く |
| フォルダーを開く… | `Ctrl+Shift+O` | ワークスペースをサイドバーに読み込む |
| クイックオープン… | `Ctrl+P` | ワークスペース内のあいまいファイル選択 |
| 保存 | `Ctrl+S` | |
| 名前を付けて保存… | `Ctrl+Shift+S` | |
| 環境設定… | `Ctrl+,` | |
| PDF を書き出す… | メニュー | [書き出し](./export) |
| HTML を書き出す… | メニュー | [書き出し](./export) |

## エディターレベルの割り当て

エディターで入力中に動作します：

| ショートカット | アクション |
| --- | --- |
| `Tab` / `Shift+Tab` | インデント／アウトデント（リスト項目） |
| 空のリスト項目で `Enter` | リストを抜ける |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+E` | 太字／斜体／インラインコードを切り替え |
| リンクを `Ctrl` + クリック | リンクを開く |
| 描画されたブロックをクリック | ソースを編集 |
| タスクのチェックボックスをクリック | `[ ]` / `[x]` を切り替え |

## テーブル編集

テーブルセルを編集中：

| ショートカット | アクション |
| --- | --- |
| `Tab` / `Shift+Tab` | 次／前のセル |
| `Enter` / `Shift+Enter` | 下／上のセル |
| `Ctrl+Enter` / `Ctrl+Shift+Enter` | 下／上に行を挿入 |
| `Ctrl+Shift+←` / `→` | 左／右に列を挿入 |
| `Alt+↑↓←→` | 行／列を移動 |
| `Escape` | テーブル編集を抜ける |
