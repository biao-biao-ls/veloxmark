# 画像

VeloxMark は、ディスク上の Markdown ファイルがそうあるべきように画像を解決します——
編集中のファイルからの相対パスとして。

## 対応するパス

| 形式 | 例 | 解決の基準 |
| --- | --- | --- |
| 相対パス | `![alt](./img/chart.png)` | 現在の `.md` ファイルのディレクトリ |
| 絶対パス | `![alt](C:\pics\a.png)` / `![alt](/home/me/a.png)` | ファイルシステムのルート |
| リモート URL | `![alt](https://example.com/a.png)` | ネットワーク経由で取得 |
| データ URI | `![alt](data:image/png;base64,…)` | インラインで埋め込み |

相対パスが移植性の高い選択です——`.md` と画像を含むフォルダーを一緒に移動すれば、
すべてがそのまま動作し続けます。

## サイズと属性

URL の後に任意の `=WxH` 接尾辞で描画寸法を、閉じ括弧の後の `{…}` グループで配置と
反転を設定できます：

```markdown
![logo](./logo.png =128x128)
![banner](./banner.png =800x200){align=center}{flip=h}
```

| 属性 | 値 | 効果 |
| --- | --- | --- |
| `=WxH` | 例：`=128x128` | 表示サイズ（ピクセル） |
| `{align=…}` | `left`、`center`、`right` | 水平方向の配置 |
| `{flip=…}` | `h`、`v`、`hv` | 水平／垂直／両方向に反転 |

描画された画像はマウスで**ドラッグしてリサイズ**もできます（`%` 幅を出力）。画像ウィジェットには
配置、反転、サイズのリセット、URL の編集、「ファイルマネージャーで表示」があります。

## クリックして編集

画像はウィジェットとして描画されます。画像をクリックすると Markdown ソースを編集でき、
ブロックから離れると再び描画されます——コード、数式、図表ブロックと同じ挙動です。

## ローカルセキュリティ

ローカル画像は、生の `file://` アクセスではなくアプリ内部の `mdres://` プロトコルを通じて
配信されます。そのため、ドキュメントはアプリが意図的に公開した画像だけを表示できます。
