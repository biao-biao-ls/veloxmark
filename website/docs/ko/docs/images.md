# 이미지

VeloxMark는 디스크의 Markdown 파일이 해야 할 방식대로 이미지를 해석합니다 — 편집 중인
파일을 기준으로.

## 지원되는 경로

| 형태 | 예시 | 기준 |
| --- | --- | --- |
| 상대 경로 | `![alt](./img/chart.png)` | 현재 `.md` 파일의 디렉터리 |
| 절대 경로 | `![alt](C:\pics\a.png)` / `![alt](/home/me/a.png)` | 파일 시스템 루트 |
| 원격 URL | `![alt](https://example.com/a.png)` | 네트워크를 통해 가져옴 |
| 데이터 URI | `![alt](data:image/png;base64,…)` | 인라인으로 포함 |

상대 경로가 이식성 있는 선택입니다 — `.md`와 이미지가 든 폴더를 함께 옮기면
모든 것이 계속 작동합니다.

## 크기 및 속성

URL 뒤의 선택적 `=WxH` 접미사가 렌더링 크기를 정하고, 닫는 괄호 뒤의 `{…}` 그룹이
정렬과 뒤집기를 지정합니다:

```markdown
![logo](./logo.png =128x128)
![banner](./banner.png =800x200){align=center}{flip=h}
```

| 속성 | 값 | 효과 |
| --- | --- | --- |
| `=WxH` | 예: `=128x128` | 표시 크기(픽셀) |
| `{align=…}` | `left`, `center`, `right` | 수평 정렬 |
| `{flip=…}` | `h`, `v`, `hv` | 수평 / 수평 / 양쪽 대칭 |

렌더링된 이미지는 마우스로 **드래그하여 크기를 조정**할 수도 있고( `%` 너비를
생성합니다), 이미지 위젯은 정렬, 뒤집기, 크기 초기화, URL 편집과
"파일 관리자에서 보기"를 제공합니다.

## 클릭하여 편집

이미지는 위젯으로 렌더링됩니다. 이미지를 클릭하면 Markdown 소스를 편집할 수 있고,
블록을 떠나면 다시 렌더링됩니다 — 코드, 수식, 다이어그램 블록과 같은 동작입니다.

## 로컬 보안

로컬 이미지는 원시 `file://` 접근 대신 앱의 내부 `mdres://` 프로토콜을 통해 제공되므로,
문서는 앱이 의도적으로 노출한 이미지만 표시할 수 있습니다.
