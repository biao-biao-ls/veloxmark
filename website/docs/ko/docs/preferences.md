# 환경 설정

`Ctrl+,`(macOS에서는 `Cmd+,`) 또는 앱 내 **파일 → 환경 설정** 메뉴로 환경 설정을
엽니다. 설정은 세션 사이에도 유지됩니다.

## 모양

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 테마 | 시스템 | `light` / `dark` / OS를 따름. 보기 메뉴에서 전환합니다. |
| 편집기 글꼴 | 시스템 글꼴 스택 | 글쓰기 화면의 글꼴 패밀리. |
| 글꼴 크기 | 16 | 편집기 글꼴 크기(픽셀). |
| 줄 높이 | 1.6 | 편집기 줄 높이. |
| 본문 열 너비 | 0 (자동) | 글쓰기 열의 최대 줄 너비. `0`이면 앱이 결정합니다. |
| 상태 표시줄 표시 | 켜짐 | 커서 위치, 글자 수, 모드 표시기. |
| 사이드바 기본 열기 | 켜짐 | 기억할 이전 세션이 없을 때 적용됩니다. |

## 편집기

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 입력 도우미 | 켜짐 | 목록 이어 쓰기, 제목 수준 올리기, 붙여넣기 변환. |
| 붙여넣기 시 짧은 URL 링크로 감싸기 | 켜짐 | 붙여넣은 짧은 URL을 Markdown 링크로 바꿉니다. |
| 붙여넣기 시 HTML 변환 | 켜짐 | 붙여넣은 리치 텍스트를 깔끔한 Markdown으로 변환합니다. |
| 저장 시 서식 지정 | 꺼짐 | 쓰기 전에 Markdown을 정규화합니다(간격, 목록 표식, 테이블 정렬). |
| 줄 번호 표시 | 꺼짐 | 편집기의 줄 번호 여백. |
| 코드 블록 줄 번호 | 꺼짐 | 코드 블록 위젯 안에 줄 번호를 렌더링합니다. |
| 코드 블록 소프트 랩 | 켜짐 | 코드 블록 안의 긴 줄을 줄 바꿈합니다. |
| 코드 블록 접기 임계값 | 20 줄 | 더 긴 블록은 펼치기 컨트롤과 함께 접힙니다. `0`이면 비활성화됩니다. |
| 포커스 모드 | 꺼짐 | 현재 영역 외의 모든 것을 흐리게 만듭니다. |
| 타자기 모드 | 꺼짐 | 커서 줄을 수직 가운데에 고정합니다. |
| 소스 모드 | 꺼짐 | 항상 원시 Markdown을 표시합니다. |

## 파일

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 자동 저장 | 디바운스 (3 s) | `off` / `debounce` (입력이 멈춘 후) / `interval` (N분마다). |
| 자동 저장 지연 | 3 s | 디바운스 모드의 지연 시간. |
| 자동 저장 간격 | 5 min | 간격 모드의 간격. |
| 충돌 복구 초안 | 켜짐 | 저장하지 않은 변경 사항의 초안을 보관하고 충돌 후 복구를 제안합니다. |
| 마지막 세션 복원 | 켜짐 | 시작 시 탭, 폴더와 커서 위치를 다시 엽니다. |
| 숨김 파일 표시 | 꺼짐 | 파일 트리에 점 파일을 표시합니다. |
| 무시할 이름 | `node_modules`, `.git`, … | 파일 트리에서 숨길 이름. |

## 이미지 및 첨부 파일

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 첨부 파일 폴더 | `assets` | 붙여넣거나 삽입한 이미지를 넣는 폴더(문서 기준 상대 경로). |
| 이미지 파일 이름 지정 | 타임스탬프 | 타임스탬프 이름 또는 원본 파일 이름 유지. |
| 외부 이미지 복사 | 켜짐 | 문서 폴더 밖의 이미지를 첨부 파일로 복사합니다. |
| 원격 이미지 다운로드 | 꺼짐 | 원격 이미지 URL을 첨부 파일로 가져옵니다. |
