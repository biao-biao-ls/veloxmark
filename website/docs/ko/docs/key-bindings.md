# 단축키

VeloxMark는 키보드 우선입니다. Windows와 Linux에서는 단축키에 `Ctrl`을 사용하고,
macOS에서는 같은 바인딩에 `Cmd`를 사용합니다(메뉴에는 ⌘ 기호로 표시됩니다). 아래에서
`Ctrl`로 시작하는 항목은 macOS에서 `Cmd`로 읽으면 됩니다. 앱 내 메뉴의 각 명령 옆에도
단축키가 표시됩니다.

## 파일

| 명령 | 단축키 | 설명 |
| --- | --- | --- |
| 새로 만들기 | `Ctrl+N` | 새 제목 없는 탭 |
| 열기… | `Ctrl+O` | `.md` 파일 열기 |
| 폴더 열기… | `Ctrl+Shift+O` | 사이드바에 작업 공간 불러오기 |
| 빠른 열기… | `Ctrl+P` | 작업 공간에서 퍼지 파일 선택기 |
| 저장 | `Ctrl+S` | |
| 다른 이름으로 저장… | `Ctrl+Shift+S` | |
| 환경 설정… | `Ctrl+,` | |
| PDF로 내보내기… | 메뉴 | [내보내기](./export) |
| HTML로 내보내기… | 메뉴 | [내보내기](./export) |

## 편집기 수준 단축키

편집기에서 입력하는 동안 작동합니다:

| 단축키 | 동작 |
| --- | --- |
| `Tab` / `Shift+Tab` | 들여쓰기 / 내어쓰기 (목록 항목) |
| 빈 목록 항목에서 `Enter` | 목록 나가기 |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+E` | 굵게 / 기울임 / 인라인 코드 전환 |
| 링크에 `Ctrl` + 클릭 | 링크 열기 |
| 렌더링된 블록 클릭 | 소스 편집 |
| 작업 체크박스 클릭 | `[ ]` / `[x]` 전환 |

## 테이블 편집

테이블 셀을 편집하는 동안:

| 단축키 | 동작 |
| --- | --- |
| `Tab` / `Shift+Tab` | 다음 / 이전 셀 |
| `Enter` / `Shift+Enter` | 아래 / 위 셀 |
| `Ctrl+Enter` / `Ctrl+Shift+Enter` | 아래 / 위에 행 삽입 |
| `Ctrl+Shift+←` / `→` | 왼쪽 / 오른쪽에 열 삽입 |
| `Alt+↑↓←→` | 행 / 열 이동 |
| `Escape` | 테이블 편집 나가기 |
