# 기본

VeloxMark는 기능 투어를 겸하는 환영 문서와 함께 열립니다. 이 페이지에서는 창, 사이드바,
탭, 편집기 모드를 살펴봅니다.

## 창

<div class="vm-shot">

![VeloxMark 창](/img/hero-light.png)

</div>

- **제목 표시줄** — 앱 메뉴(파일 / 편집 / 보기 / 삽입 / 도움말)와 창 컨트롤이 있는
  사용자 지정 프레임리스 바입니다. 라이트/다크 테마를 따릅니다.
- **사이드바** — 세 개의 패널: **파일**(폴더 작업 공간), **개요**(활성 문서의 제목 트리),
  **검색**(폴더 내 찾기).
- **탭 표시줄** — 열린 문서마다 탭 하나, 저장하지 않은 변경 사항이 표시됩니다.
- **편집기** — 실시간 미리보기 글쓰기 화면.
- **상태 표시줄** — 커서 위치, 단어 / 글자 / 줄 수, 그리고 포커스 모드가 켜져 있으면
  모드 표시기가 나타납니다.

## 사이드바

- **파일** — 폴더를 열고 Markdown 파일을 탐색합니다. 클릭하면 탭에서 열립니다.
- **개요** — 활성 문서의 제목 트리로, 클릭하여 이동하고 현재 위치가 강조됩니다.
- **검색** — 열린 폴더 전체에서 본문 검색, 바꾸기 포함.

## 탭

- 여러 파일을 한 번에 엽니다. 각 파일에 탭이 하나씩 주어집니다.
- 저장하지 않은 변경 사항은 탭에 표시됩니다.
- 탭을 닫았다가 다시 엽니다. 닫은 탭은 복원할 수 있습니다.
- 탭을 드래그하여 순서를 바꿉니다.

## 편집기 모드

| 모드 | 동작 |
| --- | --- |
| **실시간 미리보기** (기본) | Markdown이 제자리에서 렌더링되고, 커서 줄은 소스 형태를 유지합니다 |
| **소스 모드** | 완전한 제어를 위해 항상 원시 Markdown을 표시합니다 |
| **포커스 모드** | 현재 줄을 제외한 모든 것이 흐려집니다 |
| **타자기 모드** | 현재 줄이 수직 가운데에 고정됩니다 |

보기 메뉴에서 테마를 전환합니다. 전체 명령 목록: [단축키](./key-bindings).

## 열기 및 저장

- **열기** — `.md` 파일(`Ctrl+O` / `Cmd+O`)을 열거나 파일 메뉴에서 폴더를 엽니다.
- **저장**(`Ctrl+S` / `Cmd+S`)은 순수 소스를 그대로 기록합니다 — 왕복 손실 없음.
- **다른 이름으로 저장**은 새 이름으로 사본을 기록합니다.
- 저장하지 않은 작업은 초안으로 보관되며 복구할 수 있습니다.
