# 문서 내보내기

VeloxMark는 **Markdown 소스**에서 내보냅니다 — 편집기 DOM이 아니라 — 따라서 출력은
문서와 정확히 일치합니다. 파일 메뉴에서 사용할 수 있습니다: **내보내기 → PDF…** 또는
**내보내기 → HTML…**. 둘 다 공유 내보내기 대화 상자를 엽니다.

## 옵션

| 그룹 | 설정 | 값 |
| --- | --- | --- |
| 페이지 (PDF) | 용지 크기 | A4, Letter |
| 페이지 (PDF) | 여백 | 보통, 좁게 |
| 페이지 (PDF) | 머리글 및 바닥글 | 켜기 / 끄기 — 머리글은 문서 제목 / 파일 이름을, 바닥글은 `페이지 / 전체`를 표시합니다 |
| 스타일 | 테마 | 현재 테마를 따르거나 라이트로 강제 |
| 이미지 | base64로 포함 / 상대 경로 유지 | PDF는 항상 포함합니다 |
| 수식 | KaTeX 글꼴 | 포함(오프라인 사용 가능) 또는 CDN 대체(더 작은 파일) |

## 렌더링되는 것

전체 파이프라인은 실시간 미리보기가 보여주는 모든 것을 재현합니다:

- 제목, 목록, 작업 목록(선택된 체크박스로), 정렬이 있는 테이블
- highlight.js 구문 색상이 있는 코드
- **KaTeX 수식** — 진짜로 조판된 수식으로
- **Mermaid 다이어그램** — 인라인 SVG로
- 콜아웃, 각주(참조 역참조와 함께 번호 매김), `==강조==`, 위 첨자, 아래 첨자,
  약어와 정의 목록
- 크기 / 정렬 / 뒤집기 속성이 있는 이미지, 문서 기준으로 해석되며 옵션에 따라 인라인으로
  포함됩니다
- 프론트 매터의 `title`은 문서의 H1이 됩니다

PDF 생성은 HTML을 숨겨진 샌드박스 창에서 렌더링하고, 글꼴과 이미지를 기다린 뒤
배경과 함께 PDF로 인쇄합니다.

## 선택 영역만 내보내기

**편집 → 선택 영역을 HTML로 내보내기…**는 선택한 범위만 독립형 HTML 파일로 내보냅니다
(선택한 것이 없으면 전체 문서를 사용합니다). 같은 선택-문서 범위가 **리치 텍스트로
복사**와 **HTML로 복사**에도 적용됩니다.

## 왕복 보장

내보내기는 파일을 절대 수정하지 않습니다. 디스크의 `.md`가 계속해서 유일한 진실 원천이며,
내보낸 PDF/HTML은 그저 렌더링일 뿐입니다.
