# 언어 및 현지화

VeloxMark의 UI는 아홉 가지 언어로 제공됩니다:

| 언어 | 코드 |
| --- | --- |
| 영어 | `en` |
| 중국어 | `zh` |
| 일본어 | `ja` |
| 한국어 | `ko` |
| 스페인어 | `es` |
| 포르투갈어 | `pt` |
| 프랑스어 | `fr` |
| 독일어 | `de` |
| 러시아어 | `ru` |

(앱의 언어 선택기에서 각 언어는 해당 언어의 고유한 이름으로 표시됩니다.)

현지화는 전체 UI를 다룹니다: 메뉴(macOS에서는 네이티브), 대화 상자, 상태 표시줄 —
그리고 로케일에 따라 선택되는 환영 / 도움말 예제 문서와 Mermaid 템플릿 본문까지.

## 언어 선택

- **기본적으로 시스템을 따릅니다** — 해당 언어 팩이 있으면 OS 로케일에 따라 UI 언어를
  선택하고, 없으면 영어로 대체됩니다.
- 환경 설정 / 보기 메뉴에서 **명시적으로 설정**할 수 있으며, 선택은 세션 사이에
  기억됩니다.

## 번역

번역은 언어당 하나의 팩 파일(UI 사전, 네이티브 메뉴 문자열, 환영/도움말 문서와
Mermaid 템플릿)에 저장됩니다. 사전 키 정합성은 타입 시스템이 강제합니다 — 새 언어는
`npm run typecheck`를 통과하려면 네 개의 팩을 모두 제공해야 합니다.
[GitHub](https://github.com/biao-biao-ls/veloxmark)에서 기여를 환영합니다.
