# 편집 심화

VeloxMark의 편집기는 CodeMirror 6를 기반으로 하며, 문서와 선택 영역이 바뀔 때마다 렌더링
보기를 다시 만드는 장식 엔진을 갖추고 있습니다. 이 페이지는 쓰는 동안 그 동작을 설명합니다.

## 실시간 미리보기

- 커서가 줄을 떠나면 그 줄의 문법 마커(`#`, `**`, `` ` ``, `*`, `~~`, `==`)가
  바꾸기 장식으로 숨겨지고, 줄은 최종 서식을 갖춘 형태를 보여줍니다.
- **커서 줄은 항상 소스 형태를 유지합니다** — 지금 입력하는 것을 정확히 볼 수 있습니다.
- 숨겨진 마커를 클릭하면 그 범위의 소스 형태가 돌아옵니다.

## 블록 위젯

코드 블록, `$$` 수식, Mermaid 다이어그램과 이미지는 소스 대신 위젯으로 렌더링됩니다.
**렌더링된 블록을 클릭하면 그 소스를 편집할 수 있습니다.** 블록을 떠나면 다시 렌더링됩니다.

## 테이블

테이블은 일급 기능입니다. 각 셀이 중첩된 CodeMirror 편집기입니다.

- **삽입 / 변환** — 표 삽입 대화 상자로 원하는 행과 열 수의 테이블을 만들거나, 현재
  단락을 테이블로 변환합니다.
- **열 크기 조정** — 열 경계를 드래그합니다.
- **정렬** — 열별 정렬(왼쪽 / 가운데 / 오른쪽)을 설정합니다. 소스 구분 행
  (`:---`, `:--:`, `---:`)이 동기화됩니다.
- 모든 편집은 위젯이 소유한 Markdown 소스 범위로 트랜잭션을 통해 전달됩니다 —
  문서가 뒤에서 몰래 수정되는 일은 없습니다.

## 포커스 및 타자기 모드

- **포커스 모드**는 쓰고 있는 단락을 제외한 모든 것을 흐리게 만듭니다.
- **타자기 모드**는 커서 줄을 수직 가운데에 고정합니다.
- 둘 다 함께 사용할 수 있으며, 켜져 있는 동안 상태 표시줄에 `FOCUS` / `TYPEWRITER`
  칩이 표시됩니다.

## 입력 도우미

- **HTML 붙여넣기 → Markdown** — 클립보드에서 붙여넣은 리치 텍스트가 깔끔한 Markdown으로
  변환됩니다.
- **짧은 URL** — 붙여넣은 짧은 URL은 자동으로 링크로 감싸집니다.
- **작업 목록** — `- [ ]`는 클릭 가능한 체크박스로 렌더링됩니다. 클릭하여 전환합니다.
- **실행 취소/다시 실행** — 전체 트랜잭션 기록 (`Ctrl+Z` / `Ctrl+Shift+Z`).

## 다중 탭 편집

여러 파일을 한 번에 엽니다. 탭은 닫았다가 다시 열 수 있고, 저장하지 않은 변경 사항이
표시되며, 탭 표시줄은 드래그로 순서를 바꿀 수 있습니다.
