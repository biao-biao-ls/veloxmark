# Atalhos de teclado

O VeloxMark é orientado ao teclado. No Windows e no Linux os atalhos usam `Ctrl`; no macOS
os mesmos atalhos usam `Cmd` (mostrados nos menus com o glifo ⌘), e os itens abaixo
prefixados com `Ctrl` leem-se como `Cmd` nesse caso. Os atalhos também são mostrados ao
lado de cada comando nos menus do aplicativo.

## Atalhos ao nível do editor

Estes funcionam enquanto escreve no editor:

| Atalho | Ação |
| --- | --- |
| `Tab` / `Shift+Tab` | Aumentar / diminuir indentação (itens de lista) |
| `Enter` num item de lista vazio | Sair da lista |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+E` | Alternar negrito / itálico / código em linha |
| `Ctrl` + clique num link | Abrir o link |
| Clicar num bloco renderizado | Editar o seu código-fonte |
| Clicar numa caixa de seleção de tarefa | Alternar `[ ]` / `[x]` |

## Edição de tabelas

Ao editar uma célula de tabela:

| Atalho | Ação |
| --- | --- |
| `Tab` / `Shift+Tab` | Célula seguinte / anterior |
| `Enter` / `Shift+Enter` | Célula abaixo / acima |
| `Ctrl+Enter` / `Ctrl+Shift+Enter` | Inserir linha abaixo / acima |
| `Ctrl+Shift+←` / `→` | Inserir coluna à esquerda / à direita |
| `Alt+↑↓←→` | Mover linha / coluna |
| `Escape` | Sair da edição da tabela |
