# Atajos de teclado

VeloxMark está pensado para el teclado primero. En Windows y Linux los atajos usan `Ctrl`;
en macOS los mismos enlaces usan `Cmd` (se muestran en los menús con el glifo ⌘), y los
elementos con prefijo `Ctrl` de abajo se leen como `Cmd` en consecuencia. Los atajos
también se muestran junto a cada comando en los menús de la aplicación.

## Enlaces a nivel de editor

Estos funcionan mientras escribes en el editor:

| Atajo | Acción |
| --- | --- |
| `Tab` / `Shift+Tab` | Sangrar / reducir sangría (elementos de lista) |
| `Enter` en un elemento de lista vacío | Salir de la lista |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+E` | Alternar negrita / cursiva / código en línea |
| `Ctrl` + clic en un enlace | Abrir el enlace |
| Clic en un bloque renderizado | Editar su código fuente |
| Clic en una casilla de tarea | Alternar `[ ]` / `[x]` |

## Edición de tablas

Mientras editas una celda de tabla:

| Atajo | Acción |
| --- | --- |
| `Tab` / `Shift+Tab` | Celda siguiente / anterior |
| `Enter` / `Shift+Enter` | Celda de abajo / de arriba |
| `Ctrl+Enter` / `Ctrl+Shift+Enter` | Insertar fila debajo / encima |
| `Ctrl+Shift+←` / `→` | Insertar columna a la izquierda / a la derecha |
| `Alt+↑↓←→` | Mover fila / columna |
| `Escape` | Salir de la edición de tablas |
