# 快捷键

VeloxMark 以键盘为先。Windows 与 Linux 上快捷键使用 `Ctrl`；macOS 上同样的绑定使用
`Cmd`（菜单中显示 ⌘ 符号），下面标 `Ctrl` 的项目在 macOS 上读作 `Cmd`。
应用内菜单中每个命令旁也显示快捷键。

## 文件

| 命令 | 快捷键 | 说明 |
| --- | --- | --- |
| 新建 | `Ctrl+N` | 新建未命名标签 |
| 打开… | `Ctrl+O` | 打开 `.md` 文件 |
| 打开文件夹… | `Ctrl+Shift+O` | 将工作区载入侧栏 |
| 快速打开… | `Ctrl+P` | 工作区模糊文件选择器 |
| 保存 | `Ctrl+S` | |
| 另存为… | `Ctrl+Shift+S` | |
| 偏好设置… | `Ctrl+,` | |
| 导出 PDF… | 菜单 | [导出](./export) |
| 导出 HTML… | 菜单 | [导出](./export) |

## 编辑器级绑定

在编辑器中输入时可用：

| 快捷键 | 动作 |
| --- | --- |
| `Tab` / `Shift+Tab` | 升级 / 降级（列表项） |
| 空列表项上按 `Enter` | 退出列表 |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+E` | 切换粗体 / 斜体 / 行内代码 |
| `Ctrl` + 点击链接 | 打开链接 |
| 点击渲染块 | 编辑其源码 |
| 点击任务复选框 | 切换 `[ ]` / `[x]` |

## 表格编辑

编辑表格单元格时：

| 快捷键 | 动作 |
| --- | --- |
| `Tab` / `Shift+Tab` | 下一个 / 上一个单元格 |
| `Enter` / `Shift+Enter` | 下方 / 上方单元格 |
| `Ctrl+Enter` / `Ctrl+Shift+Enter` | 在下方 / 上方插入行 |
| `Ctrl+Shift+←` / `→` | 在左侧 / 右侧插入列 |
| `Alt+↑↓←→` | 移动行 / 列 |
| `Escape` | 退出表格编辑 |
