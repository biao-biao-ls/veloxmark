# 偏好设置

用 `Ctrl+,`（macOS 上 `Cmd+,`）或应用内**文件 → 偏好设置**菜单打开偏好设置。
设置会跨会话持久保存。

## 外观

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 主题 | 跟随系统 | `亮色` / `暗色` / 跟随系统。在视图菜单切换。 |
| 编辑器字体 | 系统字体栈 | 写作区的字体族。 |
| 字号 | 16 | 编辑器字号（像素）。 |
| 行高 | 1.6 | 编辑器行高。 |
| 内容栏宽度 | 0（自动） | 写作栏的最大行宽；`0` 表示由应用决定。 |
| 显示状态栏 | 开 | 光标位置、计数与模式指示。 |
| 侧栏默认打开 | 开 | 没有可记忆的历史会话时生效。 |

## 编辑器

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 输入辅助 | 开 | 列表续行、标题升级、粘贴转换。 |
| 粘贴时包装裸链接 | 开 | 把粘贴的裸 URL 变成 Markdown 链接。 |
| 粘贴时转换 HTML | 开 | 把粘贴的富文本转换为干净的 Markdown。 |
| 保存时格式化 | 关 | 写盘前规范化 Markdown（间距、列表标记、表格对齐）。 |
| 显示行号 | 关 | 编辑器行号槽。 |
| 代码块显示行号 | 关 | 在代码块组件内渲染行号。 |
| 代码块软换行 | 开 | 代码块内长行换行。 |
| 代码块折叠阈值 | 20 行 | 更长的块折叠并显示展开控件；`0` 禁用。 |
| 专注模式 | 关 | 当前区域之外的一切变暗。 |
| 打字机模式 | 关 | 光标行锁定在垂直居中位置。 |
| 源码模式 | 关 | 始终显示原始 Markdown。 |

## 文件

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 自动保存 | 防抖（3 秒） | `关闭` / `防抖`（输入停止后）/ `固定间隔`（每 N 分钟）。 |
| 自动保存延迟 | 3 秒 | 防抖模式的延迟。 |
| 自动保存间隔 | 5 分钟 | 固定间隔模式的间隔。 |
| 崩溃恢复草稿 | 开 | 保留未保存更改的草稿，崩溃后提供恢复。 |
| 恢复上次会话 | 开 | 启动时重新打开标签页、文件夹与光标位置。 |
| 显示隐藏文件 | 关 | 在文件树中显示点开头的文件。 |
| 忽略名称 | `node_modules`、`.git`、… | 文件树中隐藏的名称。 |

## 图片与附件

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 附件文件夹 | `assets` | 存放粘贴 / 插入图片的文件夹（相对文档）。 |
| 图片文件命名 | 时间戳 | 时间戳命名，或保留原文件名。 |
| 复制外部图片 | 开 | 把文档目录之外的图片复制进附件目录。 |
| 下载远程图片 | 关 | 把远程图片 URL 拉取到附件目录。 |

## 语言

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 界面语言 | 跟随系统 | 跟随系统语言或固定为九种语言之一。见[语言与本地化](./language)。 |

## 链接

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 打开外部链接前确认 | 开 | 在浏览器打开链接前询问。 |
