# 语言与本地化

VeloxMark 的界面提供九种语言：

| 语言 | 代码 |
| --- | --- |
| 英语 | `en` |
| 中文 | `zh` |
| 日语 | `ja` |
| 韩语 | `ko` |
| 西班牙语 | `es` |
| 葡萄牙语 | `pt` |
| 法语 | `fr` |
| 德语 | `de` |
| 俄语 | `ru` |

本地化覆盖整个界面：菜单（macOS 上为原生菜单）、对话框、状态栏——
乃至欢迎 / 帮助示例文档与 Mermaid 模板正文，都按语言区域选取。

## 选择语言

- **默认跟随系统**——存在对应语言包时，应用按操作系统语言选择界面语言，
  否则回退到英语。
- **显式设置**——在偏好设置 / 视图菜单中固定语言；选择会被跨会话记住。

## 参与翻译

翻译存放在每语言一个的语言包文件中（界面词典、原生菜单字符串、
欢迎 / 帮助文档与 Mermaid 模板）。词典键位对齐由类型系统强制——
新语言必须补齐全部四类包才能通过 `npm run typecheck`。
欢迎在 [GitHub](https://github.com/biao-biao-ls/veloxmark) 贡献。
