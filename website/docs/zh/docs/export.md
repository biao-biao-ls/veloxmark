# 导出文档

VeloxMark 从 **Markdown 源码**导出——而非编辑器 DOM——因此输出与你的文档完全一致。
在文件菜单：**导出 → PDF…** 或**导出 → HTML…**。两者共用导出对话框。

## 选项

| 分组 | 设置 | 取值 |
| --- | --- | --- |
| 页面（PDF） | 纸张尺寸 | A4、Letter |
| 页面（PDF） | 页边距 | 常规、窄 |
| 页面（PDF） | 页眉与页脚 | 开 / 关——页眉显示文档标题 / 文件名，页脚显示`页码 / 总页数` |
| 样式 | 主题 | 跟随当前主题，或强制亮色 |
| 图片 | 嵌入 base64 / 保留相对路径 | PDF 始终嵌入 |
| 公式 | KaTeX 字体 | 嵌入（离线可用）或 CDN 回退（文件更小） |

## 渲染内容

完整管线重现实时预览的一切：

- 标题、列表、任务列表（作为已勾选的复选框）、带对齐的表格
- 带 highlight.js 语法色的代码
- **KaTeX 公式**——真正的排版数学
- **Mermaid 图表**——内联 SVG
- 提示块、脚注（编号并带返回引用）、`==高亮==`、上标、下标、缩写与定义列表
- 带尺寸 / 对齐 / 翻转属性的图片，相对文档解析并按选项内联
- 前置元数据的 `title` 成为文档 H1

PDF 生成时在隐藏的沙箱窗口中渲染 HTML，等待字体与图片就绪后带背景打印成 PDF。

## 仅选区导出

**编辑 → 导出选区为 HTML…** 将选中的范围导出为独立 HTML 文件
（没有选区时使用整个文档）。**复制为富文本**与**复制为 HTML** 同样作用于选区或整篇。

## 往返保证

导出绝不修改你的文件。磁盘上的 `.md` 始终是唯一的数据源；
导出的 PDF/HTML 只是它的一种呈现。
