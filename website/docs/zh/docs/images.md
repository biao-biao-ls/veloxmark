# 图片

VeloxMark 解析图片的方式就是一个磁盘上的 Markdown 文件应有的方式——相对于你正在编辑的文件。

## 支持的路径

| 形式 | 示例 | 解析基准 |
| --- | --- | --- |
| 相对路径 | `![alt](./img/chart.png)` | 当前 `.md` 文件所在目录 |
| 绝对路径 | `![alt](C:\pics\a.png)` / `![alt](/home/me/a.png)` | 文件系统根 |
| 远程 URL | `![alt](https://example.com/a.png)` | 通过网络获取 |
| Data URI | `![alt](data:image/png;base64,…)` | 内嵌于文档 |

相对路径是可移植的选择——把 `.md` 与它的图片一起移动，一切照常工作。

## 尺寸与属性

URL 后的可选 `=WxH` 后缀设定显示尺寸，闭括号后的 `{…}` 组设定对齐与翻转：

```markdown
![logo](./logo.png =128x128)
![banner](./banner.png =800x200){align=center}{flip=h}
```

| 属性 | 取值 | 效果 |
| --- | --- | --- |
| `=WxH` | 如 `=128x128` | 显示尺寸（像素） |
| `{align=…}` | `left`、`center`、`right` | 水平对齐 |
| `{flip=…}` | `h`、`v`、`hv` | 水平 / 垂直 / 双向镜像 |

渲染出的图片还可以用鼠标**拖拽调宽**（输出 `%` 宽度），图片组件提供对齐、翻转、
重置尺寸、编辑 URL 与"在文件管理器中显示"。

## 点击编辑

图片渲染为组件。点击图片即可编辑其 Markdown 源码；离开该块即重新渲染——
与代码、公式和图表块行为一致。

## 本地安全

本地图片通过应用内部的 `mdres://` 协议提供，而非原始 `file://` 访问，
因此文档只能显示应用有意暴露的图片。
