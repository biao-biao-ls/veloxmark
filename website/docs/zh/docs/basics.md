# 基础

VeloxMark 启动后会打开一份欢迎文档，它同时是功能导览。本页带你认识窗口、侧栏、
标签页与编辑器模式。

## 窗口

<div class="vm-shot">

![VeloxMark 窗口](/img/hero-light.png)

</div>

- **标题栏**——自定义无边框栏，含应用菜单（文件 / 编辑 / 视图 / 插入 / 帮助）与窗口控制按钮。
  随明暗主题变色。
- **侧栏**——三个面板：**文件**（文件夹工作区）、**大纲**（当前文档的标题树）与
  **搜索**（文件夹内查找）。
- **标签栏**——每个打开的文档一个标签，未保存更改有标记。
- **编辑器**——实时预览写作区。
- **状态栏**——光标位置、字数 / 字符数 / 行数统计，以及激活时的专注模式指示。

## 侧栏

- **文件**——打开文件夹并浏览其中的 Markdown 文件；点击在标签页中打开。
- **大纲**——当前文档的标题树，点击跳转并高亮当前位置。
- **搜索**——跨打开文件夹的全文搜索，支持替换。

## 标签页

- 同时打开多个文件；每个文件一个标签。
- 未保存更改会在标签上标记。
- 关闭与重新打开标签；已关闭的标签可恢复。
- 拖拽标签可重排顺序。

## 编辑器模式

| 模式 | 作用 |
| --- | --- |
| **实时预览**（默认） | Markdown 就地渲染；光标行保持源码形式 |
| **源码模式** | 始终显示原始 Markdown，完全掌控 |
| **专注模式** | 当前行之外的一切变暗 |
| **打字机模式** | 当前行锁定在垂直居中位置 |

在视图菜单切换主题。完整命令列表见[快捷键](./key-bindings)。

## 打开与保存

- **打开** `.md` 文件（`Ctrl+O` / `Cmd+O`）或从文件菜单打开文件夹。
- **保存**（`Ctrl+S` / `Cmd+S`）写回纯源码——往返零损失。
- **另存为**将副本写到新名字下。
- 未保存的工作会存为草稿，可恢复。
