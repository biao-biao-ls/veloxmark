# Tastenkürzel

VeloxMark ist tastaturorientiert. Unter Windows und Linux verwenden Tastenkürzel `Ctrl`; unter macOS
verwenden dieselben Bindings `Cmd` (in Menüs mit dem ⌘-Zeichen angezeigt), und `Ctrl`-präfixierte Einträge
unten lesen sich entsprechend als `Cmd`. Tastenkürzel stehen auch neben jedem Befehl in den
App-Menüs.

## Datei

| Befehl | Tastenkürzel | Hinweise |
| --- | --- | --- |
| Neu | `Ctrl+N` | Neuer unbenannter Tab |
| Öffnen… | `Ctrl+O` | Eine `.md`-Datei öffnen |
| Ordner öffnen… | `Ctrl+Shift+O` | Einen Arbeitsbereich in die Seitenleiste laden |
| Schnell öffnen… | `Ctrl+P` | Unschärfe-Dateiwähler im Arbeitsbereich |
| Speichern | `Ctrl+S` | |
| Speichern unter… | `Ctrl+Shift+S` | |
| Einstellungen… | `Ctrl+,` | |
| PDF exportieren… | Menü | [Export](./export) |
| HTML exportieren… | Menü | [Export](./export) |

## Editor-Bindings

Diese funktionieren beim Tippen im Editor:

| Tastenkürzel | Aktion |
| --- | --- |
| `Tab` / `Shift+Tab` | Einrücken / ausrücken (Listeneinträge) |
| `Enter` auf einem leeren Listeneintrag | Liste beenden |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+E` | Fett / kursiv / Inline-Code umschalten |
| `Ctrl` + Klick auf einen Link | Link öffnen |
| Klick auf einen gerenderten Block | Seine Quelle bearbeiten |
| Klick auf ein Aufgaben-Kontrollkästchen | `[ ]` / `[x]` umschalten |

## Tabellenbearbeitung

Während des Bearbeitens einer Tabellenzelle:

| Tastenkürzel | Aktion |
| --- | --- |
| `Tab` / `Shift+Tab` | Nächste / vorherige Zelle |
| `Enter` / `Shift+Enter` | Zelle darunter / darüber |
| `Ctrl+Enter` / `Ctrl+Shift+Enter` | Zeile darunter / darüber einfügen |
| `Ctrl+Shift+←` / `→` | Spalte links / rechts einfügen |
| `Alt+↑↓←→` | Zeile / Spalte verschieben |
| `Escape` | Tabellenbearbeitung verlassen |
