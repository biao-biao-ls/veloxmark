## 架构要点（跨项）

- **单一数据源不变量**：markdown 源码始终是唯一数据源；UI 状态全部走 CM6 StateField / compartment（折叠、callout、代码块 UI、mermaid pin、tab 模型均不回写文档）。
- **live preview 管线扩展**（P11/P16/P18/P21/P24/P25）：handlers + widget + config facet 可选字段（`??` 回退，兼容 table 嵌套编辑器的部分 config 字面量）；`codeBlockUiChanged` 等 field-identity 分支保证装饰安全重建。
- **P26 DocTab**：`useFileOps` 内部重构为 `Map<id, DocTab>`（对外 API 名保留）；`view.setState` 与初始创建共用**同一 extensions 数组**（CM6 契约），每次切换后重应用视图级 prefs；会话仅持久化路径（`openTabs`+`activePath`），不存内容。
- **主进程/渲染层协作**：搜索 IPC 流式（P13）、外部打开/关闭拦截（P12）、Cmd/Ctrl+W 标签感知路由（P26 before-input → `menu:closeTabOrWindow`）。
- **window.api 冻结**：e2e 一律走产品侧 seam（`__veloxPXX` hooks 挂在 App 自有状态/命令上）或真实 IPC 往返，不扩 preload。

### 测试脚本修复（均为 e2e 侧 macOS / P26 语义对齐，非产品缺陷）

- **cdp-p03**：portable Electron 二进制解析；macOS `~/Library/Application Support` window-state 探测；`execSync` 导入（端口清理曾因未导入被 try/catch 吞掉）；行号断言改为 `.cm-gutter.cm-lineNumbers`（P21 fold gutter 使 `.cm-gutters` 容器常驻）。
- **cdp-p06**：表格单元格点击期望改为 P22 就地编辑语义；CM6 viewport 回收防护（fence 外定位 + null guard）。
- **cdp-p08**：`.platform-mac .menubar` 隐藏 — 由 CDP 坐标点击改为 `el.click()` 驱动 MenuBar 组件同一处理链（buildMenus → action → cmd.run）；键盘路径（F8 / Ctrl+/）仍走 window keydown。
- **cdp-p09**：source-mode 装饰计数限定 `.cm-content`（fold-gutter chrome 不计）。
- **cdp-p11 / cdp-p12**：收尾改为 SIGKILL + 显式 `process.exit`（SIGTERM + 事件循环挂起会卡住回归 runner）。
- **cdp-p12**：debounce 场景在 `setPreferences` 后 settle 450ms — `notifyChange` 读 `argsRef.mode`，同一 tick 的编辑会读到旧 mode 而不布防定时器（探针实测 settle 后 2s 落盘）。
- **cdp-p17**：脏文档链接导航断言更新为 P26 语义（多文档并存：导航不弹 gate，脏 a.md 留在自己 tab）。
- **cdp-p21**：boot pin 补齐 `typewriterMode/focusMode/sourceMode:false`（SIGKILL 丢 localStorage 会污染共享 userData）；⑥ 步进滚动累积 callout 类（CM6 回收后离屏 widget 不在 DOM）。
