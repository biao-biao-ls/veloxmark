# VeloxMark UI/UX 全面交互重设计 · 功能树

> 依据正式 PRD v1.0 生成：M06 功能清单全部功能点逐项落位，深度按 M09 功能域（表格交互/顶部菜单栏/左侧导航栏/渲染区/全局交互/设计规范）展开，联动项（导出一致性）随全局交互收录。层级：页面 → 功能组 → 原子功能（最小可测单元）；`F-` 编号为流程功能，步骤以 `{##原子功能编号}` 引用既有原子功能。

- SPEC 设计规范与原型门禁（交付物 · 非应用界面）
  - SPEC-DOC 规范定稿
    - SPEC-DOC-DONE 定稿设计规范五部分：作者产出《UI/UX 设计规范》并组织评审定稿，视觉原则/交互模式库/chrome 扩展/快捷键总表/信息架构五部分齐备，统辖全部界面区域
  - SPEC-GATE 原型门禁
    - SPEC-GATE-PROT 评审 UI 高保真原型：用户评审 UI 高保真原型，通过后才允许进入界面改造实现（动代码前置门禁）
  - SPEC-FLOW 入口
    - F-SPECGATE 规范与原型门禁流程
      - {##SPEC-DOC-DONE}：起草并定稿设计规范五部分
      - {##SPEC-GATE-PROT}：产出 UI 高保真原型送审，评审通过则解锁总看板分期改造，打回则回草案迭代
- TBL 表格交互（主窗口 · 表格编辑视图）
  - TBL-CHRM 把手与外观
    - TBL-CHRM-HAND 移除增删把手：用户在静息/编辑态查看表格，界面不再出现常驻 +/− 增删把手与左侧留白，表格左缘与正文列对齐（水平偏移 0px），行列增删改由工具栏/菜单/快捷键承载
  - TBL-KEYS 结构操作快捷键
    - TBL-KEYS-IDWN 下插行：用户在激活单元格按 Ctrl+Enter，在该单元格下方插入空行（锚定单元格而非表尾），单事务一次完成且一步 undo 可还原
    - TBL-KEYS-IUPS 上插行：用户在激活单元格按 Ctrl+Shift+Enter，在该单元格上方插入空行，单事务一次完成且一步 undo 可还原
    - TBL-KEYS-IRGT 右插列：用户在激活单元格按 Ctrl+Shift+→，在该单元格右侧插入空列（默认左对齐），单事务一次完成且一步 undo 可还原
    - TBL-KEYS-ILFT 左插列：用户在激活单元格按 Ctrl+Shift+←，在该单元格左侧插入空列（默认左对齐），单事务一次完成且一步 undo 可还原
    - TBL-KEYS-MOVE 移行列：用户按 Alt+↑/↓ 移动行、Alt+←/→ 移动列，行列顺序即时更新；首行上移与首列左移禁用（表头保护）并在菜单灰显
  - TBL-TOOL 表格工具栏
    - TBL-TOOL-GRID 网格选择器缩放整表：用户点击 ⊞ 展开行×列网格并拖选 R 行 C 列，整表缩放至 R×C，网格单元格清晰可辨（对比度达标），缩放上限 20 行×12 列钳制，新增行/列默认左对齐、删减从尾部移除
    - TBL-TOOL-MENU 更多操作菜单：用户点击 ⋮ 打开按行操作/列操作/对齐/结构删除分组的菜单，限高滚动 + 边缘翻转保证窗口任意位置全项完整可达，每项回显对应快捷键且与右键菜单同源（同操作、同 toast、同禁用规则）
    - TBL-TOOL-ALGN 设置对齐：用户点击左/中/右对齐三键，对齐写入表格冒号行并即时回显
    - TBL-TOOL-DELT 删除表格：用户点击 🗑 并在确认框确认删除，整表删除且一步 undo 可还原，取消则不执行
  - TBL-WIDT 列宽显示态
    - TBL-WIDT-CLMP 列宽钳制与重置：用户拖拽列边界调整列宽后，行列结构变化时旧列宽钳制到新结构，失效即重置默认宽而非错乱
  - TBL-FLOW 入口
    - F-TBLOP 表格结构操作闭环（三入口同源）
      - {##TBL-KEYS-IDWN}：光标在激活单元格经快捷键 / ⋮ 菜单 / 工具栏任一入口执行结构操作，同源操作语义单事务完成并即时反馈
      - {##GLB-SAFE-UNDO}：误触或操作错误时一步 undo 还原，toast 告知结果
      - {##GLB-HUSH-COLL}：操作满意后退出编辑，一键回安静回到零 chrome 静息态
- MENU 顶部菜单栏（主窗口 · 顶部菜单栏）
  - MENU-ARCH 信息架构
    - MENU-ARCH-RORD 菜单信息架构重排：用户展开任一菜单，菜单项按设计规范完成分组/命名/层级重排，命令标识不变（自动化验收硬契约），呈现向行业习惯看齐
  - MENU-DRPD 下拉行为
    - MENU-DRPD-OVER 下拉防溢出：用户在窗口底部/右侧展开下拉或子菜单，菜单限高滚动并自动边缘翻转，全部菜单项完整可达，子菜单 hover 延展不丢失、不超出可视范围
  - MENU-HINT 快捷键回显
    - MENU-HINT-KEYS 菜单快捷键回显：用户展开下拉菜单，有快捷键的命令 100% 右侧回显提示，提示由快捷键总表单源派生，与实际键位一致率 100%
  - MENU-LOOK 视觉统一
    - MENU-LOOK-VISU 菜单视觉统一：用户查看菜单栏全量，间距/对齐/hover/激活态统一呈现，视觉细节由设计规范令牌统辖、不写裸值
- NAV 左侧导航栏（主窗口 · 左侧边栏）
  - NAV-AUDT 审计改造
    - NAV-AUDT-VISU 侧栏审计改造：用户使用文件树/大纲，视觉细节与布局行为按设计规范对照走查逐项收敛，大纲激活态跟随滚动、点击平滑跳转不迷路
  - NAV-FOLD 折叠记忆
    - NAV-FOLD-KEEP 折叠态会话记忆：用户折叠/展开大纲或章节，折叠状态跨重启持久保持（AC-RULE-14 口径）且不写入文档正文
  - NAV-GAPS 功能缺口补齐
    - NAV-GAPS-KBRD 键盘导航：用户用键盘在文件树/大纲移动焦点并打开节点，焦点可见、键鼠双通道可达（实现（FE-06/FE-08 落地）——Q9 取舍裁决，取舍清单见 gap-tradeoffs.md）
    - NAV-GAPS-MSLT 节点多选：用户在文件树多选节点并执行批量操作，选择范围准确可控（不实现（Q9）——批量文件安全语义成本过高，替代=单节点操作循环执行，取舍清单见 gap-tradeoffs.md）
    - NAV-GAPS-SORT 大纲排序：用户拖拽大纲节点调整章节顺序，文档结构随之正确更新（不实现（Q9）——文档结构重写风险大，替代=剪切/粘贴正文段落，取舍清单见 gap-tradeoffs.md）
- REN 渲染区（主窗口 · 正文渲染区）
  - REN-IMAG 图片
    - REN-IMAG-EDIT 图片编辑浮层：用户 hover/点击图片唤起编辑浮层，拖拽尺寸、调整对齐，尺寸与对齐写入 .md 语法（非显示态旁路），退出后浮层干净消失
  - REN-LINK 链接
    - REN-LINK-HOVR 链接悬浮操作：用户 hover 链接打开浮层，可编辑 URL、经系统默认浏览器固定入口外开、复制完整 URL
  - REN-LIST 列表与任务项
    - REN-LIST-DRAG 行首拖拽排序：用户 hover 列表行首出现拖拽把手并拖动排序，把手按需浮现、不常驻不遮挡正文
    - REN-LIST-CHK 任务项勾选：用户点击任务项复选框切换勾选，勾选结果写入 .md 任务语法
  - REN-HEAD 标题折叠
    - REN-HEAD-FOLD 章节折叠/展开：用户点击标题左侧三角，章节含全部子章节折叠为单行、展开还原，与大纲折叠状态一致且会话记忆
  - REN-QUOT 引用块
    - REN-QUOT-FOLD 长引用折叠：用户对超阈值长度的引用块折叠为摘要行并可展开还原（本期观感到标即可）
  - REN-CHRM 块级 chrome 审计
    - REN-CHRM-AUDT 公式/代码/图表块审计微调：用户使用公式/代码/mermaid 块，双区编辑、错误态可修复、跳源码能力保持，仅观感按新规范微调且不改已收敛契约
  - REN-CLIK 点击语义
    - REN-CLIK-EDIT 内容点击进入编辑：用户点击正文内容进入对应编辑形态，纯选中/复制不弹 chrome，图/表/代码相邻处点击语义一致
- GLB 全局交互（全界面）
  - GLB-HUSH 一键回安静
    - GLB-HUSH-COLL 一键收拢浮层与编辑态：用户按 Esc 或点击正文空白，菜单/popover/工具栏/双区编辑/chip 一次全部收拢（非逐个关闭），焦点回正文，终态必为静息态
  - GLB-SAFE 误触防护
    - GLB-SAFE-UNDO 操作反馈与一步撤销：用户完成结构操作后收到轻量 toast 告知，误触可一步 undo 还原，删表/删列等破坏性操作先确认，toast 自动消失、不打断输入
  - GLB-CALM 静息态纯净
    - GLB-CALM-ZERO 静息零 chrome：用户浏览正文时界面零控件 chrome，hover 控件出入防抖不闪烁、不遮挡正文、进出编辑态零布局抖动（位移 0px）
  - GLB-EXP 导出联动
    - GLB-EXP-SYNC 导出观感一致：用户导出 HTML/PDF/富文本，导出物表格行列/对齐与视觉观感同编辑视图一致
  - GLB-FLOW 入口
    - F-QUIET 一键回安静流程
      - {##GLB-HUSH-COLL}：按 Esc 或点击正文空白触发一次收拢
      - {##GLB-CALM-ZERO}：界面回零 chrome 静息态，焦点回正文
