|---|------|---------|---------|
| 1 | 重度写作者（heavy-writer） | 最低摩擦把内容落成结构良好的 Markdown，守住心流与截稿 | user-perspectives/heavy-writer.md |
| 2 | 复杂排版用户（complex-doc-author） | 高效产出/维护含表格/公式/图表的体面文档，改表成本可控 | user-perspectives/complex-doc-author.md |

## 关键发现

**跨角色共性诉求**：
1. **界面安静、内容优先**：四个角色都要求控件按需浮现、不遮挡正文、退出干净（静息态零 chrome 是共识）。
2. **操作可预期、可撤销**：结构操作一步 undo、误触可恢复、点击语义一致——"不把文档改坏"是所有角色的底线。
3. **弹层/菜单完整可达**：下拉超界是全员痛点（新用户误判能力、写作者找不到项、排版用户点不到底部项）。
4. **可发现性**：菜单快捷键回显 + hover 提示被四个角色从不同角度同时要求。

**角色间冲突点**：
1. 阅读/新用户要"点击不轻易进编辑"，重度写作者要"点进编辑要快"——需要显式的编辑态进入语义（如明确的点击判定/退出兜底）调和。
2. 新用户要"误触有提示"，重度写作者要"界面不打扰"——提示形态需轻量（toast 可关/仅新手期）。
3. 复杂排版用户要"鼠标直达入口丰富"，阅读者要"界面干净"——hover 浮现策略 + 双入口（快捷键+菜单）是公约数。

**隐性需求汇总**：
- 快捷键族的一致性模式（Shift 升档/方向对称），菜单 100% 回显
- "一键回安静"：Esc/点空白收拢全部浮层与编辑态
- 结构操作锚定光标单元格语义
- 表格静息态与正文列对齐、无常驻留白
- 折叠/会话状态记忆
- 深浅主题下所有块级渲染物观感达标
- hover 控件不闪烁、不误触发
