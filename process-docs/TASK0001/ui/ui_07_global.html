一次收拢语义：菜单 / popover / 表格工具栏 / 双区编辑 / chip 在同一次 Esc（或点击正文空白）内全部消失，非逐个关闭；收拢后焦点回到正文，键盘输入直接进入编辑，终态必为「静息」——不存在工具栏残留、半展开菜单、浮层驻留等悬空态。

窗口右下角

undo 回执统一为「已撤销」，不带撤销按钮；随后自动消失，界面回静息。
toast 规范：深底（#1f2328）白字（#e6edf3）小圆角条，投影 --shadow-pop，与应用 tooltip 同族、双主题一致；固定于窗口右下角，不遮挡光标所在单元格；自动消失、不打断输入。执行态带右侧「撤销」小按钮（accent 字）。

破坏性操作确认 + 一步 undo 双保险。行/列删除 toast 告知（Ctrl+Z 一步撤销）；仅删除表格弹确认框——「取消」则文档逐字节不变，「确认删除」执行后仍可一步 Ctrl+Z 整体还原。
确认文案固定：「删除后可用一步撤销还原，确认删除该表格」；行/列删除 toast 告知（Ctrl+Z 一步撤销），仅删除表格弹确认框。

设计标注 · 全局交互

  • 一键收拢覆盖：菜单 / popover / 工具栏 / 双区编辑 / chip，一次 Esc 或点击正文空白全部收拢
  • undo 入口三处并存：Ctrl+Z / 编辑菜单「撤销」/ toast 撤销钮，三入口等效同源
  • toast 两态文案：执行态「已插入列（Ctrl+Z 可撤销）」+ 撤销钮；undo 后态「已撤销」
  • 终态必回静息：任何路径收口到静息或菜单关闭，无悬空态（工具栏残留 / 半展开 / 浮层驻留判不通过）
