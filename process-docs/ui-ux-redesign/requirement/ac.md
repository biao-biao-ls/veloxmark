## 2. 全局业务规则（AC-RULE-{NN}）

### 2.1 状态枚举定义

| 编号 | 状态类型 | 状态值 | 语义说明 | 来源 |
|---|---|---|---|---|
| AC-RULE-01 | 界面交互态 | 静息 | 无 hover、无焦点、无浮层的界面常态，正文区域零控件 chrome | PRD 术语表、PRD 5.5 |
| AC-RULE-01 | 界面交互态 | hover | 鼠标悬停块级元素，控件按延迟防抖浮现（延迟约束见 AC-NF-04） | PRD 5.5、PRD 6.5 |
| AC-RULE-01 | 界面交互态 | 编辑态 | 块级元素进入编辑形态（表格编辑/双区编辑等），工具栏/编辑面板可见 | PRD 5.5、PRD 术语表 |
| AC-RULE-01 | 界面交互态 | 单元格激活 | 表格编辑态下某单元格获得输入焦点，结构操作以该单元格为锚点 | PRD 5.5、PRD 6.1 |
| AC-RULE-02 | 菜单状态 | 关闭 | 菜单不可见、不响应 hover 延展 | PRD 5.5 |
| AC-RULE-02 | 菜单状态 | 一级展开 | 点击触发后一级菜单项全部可见（限高滚动+边缘翻转策略见 AC-RULE-10） | PRD 5.5 |
| AC-RULE-02 | 菜单状态 | 子菜单展开 | hover 子菜单项后子菜单展开；移回父级时子菜单收拢回一级展开（菜单不关闭）；子项选择 / Esc / 外点后整个菜单关闭 | PRD 5.5 |
| AC-RULE-03 | 表格对齐态 | 左对齐 / 居中对齐 / 右对齐 | 由表格冒号行（`:---` / `:---:` / `---:`）承载，三键切换后冒号行与显示回显一致 | PRD 6.1 |
| AC-RULE-04 | 任务项状态 | 未勾选 / 已勾选 | 由 `.md` 任务语法 `[ ]` / `[x]` 承载，勾选写回源码 | PRD 6.4 |

**状态机出口规则（AC-RULE-05）**：界面交互态与菜单状态的任何路径终态必为「静息」或菜单「关闭」，不存在悬空态（工具栏残留、半展开菜单、浮层驻留均判不通过）。来源：PRD 核心闭环契约、PRD 5.5。

### 2.2 操作与交互规则

| 编号 | 规则名称 | 规则内容 | 来源 |
|---|---|---|---|
| AC-RULE-06 | 表格结构操作键位表 | Ctrl+Enter=当前激活单元格下方插行；Ctrl+Shift+Enter=上方插行；Ctrl+Shift+→=右侧插列；Ctrl+Shift+←=左侧插列；Alt+↑/↓=上/下移行；Alt+←/→=左/右移列。全部操作锚定当前激活单元格（插入位置为该单元格的上/下/左/右相邻位，非表尾/表边固定位）；Ctrl+Shift+←/→ 与单元格内文本选区扩展的键位冲突裁决见 AC-PEND-03 [PENDING]，相关断言以「单元格内无文本选区」为前置 | PRD 6.1、PRD 术语表、PRD 12 #7 |
| AC-RULE-07 | 表头保护 | 禁用范围仅限「首行上移」与「首列左移」两项（快捷键与菜单路径同禁）；「首行上插行」「首列左插列」在任意单元格均允许执行（首行上插的源码级表头/冒号行归属未规定，裁决见 AC-PEND-11 [PENDING]） | PRD 6.1、PRD 8 |
| AC-RULE-08 | 单事务与一步 undo | 每次结构操作为单事务一次完成（不存在「列加了但对齐没跟上」的半提交态）；一次 Ctrl+Z 还原该操作引起的全部变化（含行列结构、对齐、列宽） | PRD 6.1、PRD 5.4、PRD 8 |
| AC-RULE-09 | 同源操作语义 | 同一操作在快捷键 / 表格工具栏 / ⋮ 菜单 / 右键菜单四面的行为结果、toast 文案、禁用规则完全一致（同 op id）；当前无快捷键的项（删除行/列、对齐三键、⊞ 缩放、删表）键盘通道是否补齐见 AC-PEND-06 [PENDING] | PRD 术语表、PRD 6.1、PRD 12 #10 |
| AC-RULE-10 | 弹层可达 | 全部下拉/子菜单/popover 采用限高滚动 + 边缘翻转策略，在窗口任意位置全项完整可达可点 | PRD 2 可达性、PRD 6.2、PRD 8 |
| AC-RULE-11 | 快捷键提示单源派生 | 菜单快捷键提示由快捷键总表单源派生；提示文本与实际触发键位一致；禁止手工双源维护提示 | PRD 6.2、PRD 10、PRD M10 |
| AC-RULE-12 | ⊞ 缩放可选范围 | 网格可选范围逐维取 max(20 行, 既有行数) × max(12 列, 既有列数)（例：25 行×10 列表的可选范围为 25 行×12 列）：20 行×12 列为常规可选上限，既有结构超过上限的维度可选范围扩至该维度现有值，网格不主动缩减既有超出结构（缩放仅按用户拖选值执行）；缩放新增的行/列默认左对齐；缩放删减从表格尾部移除行/列 | PRD 6.1 |
| AC-RULE-13 | 点击语义裁决 | 点击元素内容进入该元素对应编辑形态（写作者路径优先）；纯选中/复制是安全动作，不触发任何工具浮层；图/表/代码相邻处点击语义一致 | PRD 6.4 |
| AC-RULE-14 | 显示态持久化 | 折叠/展开、列宽等显示态不写入 .md 正文、写入本地偏好键；折叠态跨重启持久（关闭并重启应用后保持）；既有偏好键位不变、新增键向后兼容 | PRD 6.3、PRD M10、PRD 10 |
| AC-RULE-15 | 破坏性操作确认 | 破坏性删除（删表/删行/删列）执行前弹确认框，确认后才执行；删表确认文案固定为「删除后可用一步撤销还原，确认删除该表格」；删行/删列确认框文案当前按删表同模板实例化（「…确认删除该行」/「…确认删除该列」），固定值回填裁决见 AC-PEND-16 [PENDING]；取消则不变更文档 | PRD 6.1、PRD 6.5、PRD 8 |
| AC-RULE-16 | 只读拦截 | 文件只读时编辑/结构操作全部拦截，不产生半提交状态；提示文案固定为「文件为只读，无法修改，可另存后编辑」 | PRD 8 |
| AC-RULE-17 | e2e 缝硬契约 | window.__velox 系列、data-op、data-table-handle、命令 id 字面量全部保持不变；任何改造后 cdp 探针可扫描到与改造前相同的契约集合 | PRD 6 导语、PRD M10 |

### 2.3 权限模型

| 编号 | 角色 | 可访问功能 | 数据范围 | 角色特有行为 | 来源 |
|---|---|---|---|---|---|
| AC-RULE-18 | 重度写作者 | 全部功能 | 本机全部文档 | 无权限差异；核心旅程为快捷键驱动的长文与表格改稿 | PRD M12 |
| AC-RULE-18 | 复杂排版用户 | 全部功能 | 本机全部文档 | 无权限差异；核心旅程为表格结构大改与导出一致性 | PRD M12 |
| AC-RULE-18 | 阅读/审阅用户 | 全部功能 | 本机全部文档 | 无权限差异；核心旅程为折叠扫读与最小编辑 | PRD M12 |
| AC-RULE-18 | 新用户/轻度用户 | 全部功能 | 本机全部文档 | 无权限差异；核心旅程为菜单/提示发现能力 | PRD M12 |

> 本应用为本机单用户桌面工具，四类角色为使用场景视角而非权限概念；上表断言四角色对全部功能拥有同等操作权限。敏感信息不涉及（PRD M12）。

## 3. 功能验收标准（AC-FN-{NN}）

### 3.1 表格交互（PRD 6.1）

| 编号 | Given（前置条件） | When（操作） | Then（预期结果） | 来源 |
|---|---|---|---|---|
| AC-FN-01 | 文档含 Markdown 表格，表格未聚焦且鼠标不在表格上 | 进入静息态后逐项核对表格区域 | 表格左缘与正文列左缘水平偏移为 0px；表格左缘无把手带、无常驻留白槽；表格四周无任何常驻控件 | PRD 6.1、PRD 13 AC-01 |
| AC-FN-02 | 表格处于编辑态（至少一个单元格已激活） | 逐项核对表格上/下/左/右边缘区域 | 四周无 +/− 增删把手；行列增删入口仅存在于表格工具栏、⋮ 菜单、右键菜单、快捷键四处 | PRD 6.1、PRD 13 AC-02 |
| AC-FN-03 | 表格处于静息态或 hover 态 | 点击表格内任意单元格的内容区域，或点击表格内未命中单元格的空白区域（每次验证单一路径） | 1) 命中路径：表格进入编辑态且被点击单元格进入单元格激活态并显示输入光标；未命中路径：表格进入编辑态、无单元格处于激活态（无输入光标） 2) 两条路径下表格工具栏均浮现（⊞、对齐三键、⋮、🗑） 3) 正文其他区域位置不变（位移 0px，AC-NF-05） | PRD 5.5、PRD 6.1 |
| AC-FN-04 | 表格工具栏已浮现 | 点击 ⊞ 按钮 | 1) 弹出 行×列 网格选择器，网格单元格与弹层表面可辨（UI-ELEM-02、对比度满足 AC-NF-09） 2) 鼠标拖过 R 行 C 列时选区高亮 R×C 并显示「R×C」回显 3) 未松开鼠标前表格结构不变 | PRD 6.1、PRD 13 AC-03 |
| AC-FN-05 | 表格位于窗口底部边缘，工具栏 ⋮ 可点击 | 点击 ⋮ 打开更多操作菜单 | 1) 菜单应用限高内滚动与边缘翻转（向上翻转） 2) 菜单全部项位于窗口可视区内且每一项可点击 3) 菜单项按「行操作/列操作/对齐/结构删除」分组呈现 | PRD 6.1、PRD 13 AC-04 |
| AC-FN-06 | 任意表格结构操作（AC-OP-01~10 覆盖的操作）已执行 | 操作执行后打开 ⋮ 菜单与右键菜单，逐项核对界面反馈与菜单回显 | 1) toast 显示本次操作回执文案（具体文案以对应 AC-OP 条目为准，统一含「（Ctrl+Z 可撤销）」后缀；undo 回执为「已撤销」），且与经 ⋮ 菜单/右键菜单/工具栏执行同一操作（同 op id）时的文案完全一致 2) toast 自动消失且消失前不遮挡光标所在单元格 3) 菜单中有快捷键的对应项显示该操作实际快捷键（键位与 AC-RULE-06 键位表一致），无快捷键的对应项右侧为空（AC-FN-07） 4) 右键菜单与 ⋮ 菜单的菜单项集合、分组标题与排列顺序逐项一致（镜像全同，项集/分组无增减） | PRD 6.1、PRD 13 AC-10 |
| AC-FN-24 | 表格首行为表头，光标位于首行某单元格 | 打开 ⋮ 菜单与右键菜单，查看「上移该行」项 | 两个菜单中「上移该行」均为灰显禁用态且点击不执行；「上插行」「左插列」等非禁用项为可点击态（AC-RULE-07） | PRD 6.1、PRD 8、PRD 13 AC-09 |
| AC-FN-29 | 表格处于单元格激活态 | 点击表格内未命中单元格的空白区域 | 1) 退出单元格激活态、回到表格编辑态（分级退格，非直达静息） 2) 表格工具栏保持可见（直达静息路径见 AC-FN-21/AC-FN-22，本条仅承载分级退格分支） | PRD 5.5 |
| AC-FN-31 | 表格处于编辑态（含单元格激活态），光标与焦点位于表格内 | 光标与焦点移出表格区域（移至表格外正文或其他面板） | 1) 表格退出编辑态与单元格激活态、回到静息态 2) 表格工具栏、单元格高亮、把手、chip 全部消失，无残留 3) 正文区域零控件 chrome（AC-FN-23） | PRD 5.5、PRD 6.5 |
| AC-FN-32 | 表格处于编辑态且当前无单元格激活（AC-FN-29 分级退格后的状态） | 依次点击单元格 A 的内容区域、再点击另一单元格 B 的内容区域 | 1) 点击 A 后 A 进入单元格激活态并显示输入光标 2) 点击 B 后激活态从 A 转移至 B，A 高亮消除，同一时刻至多一个单元格处于激活态 3) 表格全程保持编辑态，表格工具栏保持可见 | PRD 5.5、PRD 6.1 |
| AC-FN-33 | 文档含表格，鼠标悬停于表格上方（hover 态，未点击） | 仅移动鼠标悬停表格各区域，并拖选单元格文本后复制 | 1) 不浮现表格工具栏、把手及任何常驻 chrome（工具栏仅点击进入编辑态后浮现，与 AC-FN-03 衔接） 2) 可安全选中复制：不触发编辑、不弹浮层（AC-RULE-13） 3) 鼠标移出后无残留 | PRD 6.1 hover 显隐规范 |

### 3.2 顶部菜单栏（PRD 6.2）

| 编号 | Given（前置条件） | When（操作） | Then（预期结果） | 来源 |
