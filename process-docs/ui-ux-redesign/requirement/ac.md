## 2. 全局业务规则（AC-RULE-{NN}）

### 2.1 状态枚举定义

| 编号 | 状态类型 | 状态值 | 语义说明 | 来源 |
|---|---|---|---|---|
| AC-RULE-01 | 界面交互态 | 静息 | 无 hover、无焦点、无浮层的界面常态，正文区域零控件 chrome | PRD 术语表、PRD 5.5 |
| AC-RULE-01 | 界面交互态 | hover | 鼠标悬停块级元素，控件按延迟防抖浮现（延迟约束见 AC-NF-04；tech-design 防抖措辞已按本条校准为 ≥150ms，CHANGE-34） | PRD 5.5、PRD 6.5 |
| AC-RULE-01 | 界面交互态 | 编辑态 | 块级元素进入编辑形态（表格编辑/双区编辑等），工具栏/编辑面板可见 | PRD 5.5、PRD 术语表 |
| AC-RULE-01 | 界面交互态 | 单元格激活 | 表格编辑态下某单元格获得输入焦点，结构操作以该单元格为锚点 | PRD 5.5、PRD 6.1 |
| AC-RULE-02 | 菜单状态 | 关闭 | 菜单不可见、不响应 hover 延展 | PRD 5.5 |
| AC-RULE-02 | 菜单状态 | 一级展开 | 点击触发后一级菜单项全部可见（限高滚动+边缘翻转策略见 AC-RULE-10） | PRD 5.5 |
| AC-RULE-02 | 菜单状态 | 子菜单展开 | hover 子菜单项后子菜单展开；移回父级时子菜单收拢回一级展开（菜单不关闭）；子项选择 / Esc / 外点后整个菜单关闭 | PRD 5.5 |
| AC-RULE-03 | 表格对齐态 | 左对齐 / 居中对齐 / 右对齐 | 由表格冒号行（`:---` / `:---:` / `---:`）承载，三键切换后冒号行与显示回显一致（显示层经 effectiveAlign 归一：`''`→`'left'` 计入按下回显，冒号行写回不动——CHANGE-14） | PRD 6.1 |
| AC-RULE-04 | 任务项状态 | 未勾选 / 已勾选 | 由 `.md` 任务语法 `[ ]` / `[x]` 承载，勾选写回源码 | PRD 6.4 |

**状态机出口规则（AC-RULE-05）**：界面交互态与菜单状态的任何路径终态必为「静息」或菜单「关闭」，不存在悬空态（工具栏残留、半展开菜单、浮层驻留均判不通过）。来源：PRD 核心闭环契约、PRD 5.5。

### 2.2 操作与交互规则

| 编号 | 规则名称 | 规则内容 | 来源 |
|---|---|---|---|
| AC-RULE-06 | 表格结构操作键位表 | Ctrl+Enter=当前激活单元格下方插行；Ctrl+Shift+Enter=上方插行；Ctrl+Shift+→=右侧插列；Ctrl+Shift+←=左侧插列；Alt+↑/↓=上/下移行；Alt+←/→=左/右移列。全部操作锚定当前激活单元格（插入位置为该单元格的上/下/左/右相邻位，非表尾/表边固定位）；Ctrl+Shift+←/→ 与单元格内文本选区扩展的键位冲突按上下文分流（selection.empty 判定）：有文本选区时词选扩展优先、无文本选区时左/右插列，冻结键位不变，裁决见 AC-PEND-03 | PRD 6.1、PRD 术语表、PRD 12 #7 |
| AC-RULE-07 | 表头保护 | 禁用范围仅限「首行上移」与「首列左移」两项（快捷键与菜单路径同禁）；「首行上插行」「首列左插列」在任意单元格均允许执行（首行上插走表头身份迁移：新行升为表头、原表头降为 body 首行、冒号行仍为源码第 2 行，裁决见 AC-PEND-11）；末行「下移该行」/末列「右移该列」不灰显，边界点击静默 no-op（CHANGE-19） | PRD 6.1、PRD 8 |
| AC-RULE-08 | 单事务与一步 undo | 每次结构操作为单事务一次完成（不存在「列加了但对齐没跟上」的半提交态）；一次 Ctrl+Z 还原该操作引起的全部变化（含行列结构、对齐、列宽）；表头污染/undo 双历史缺陷经 handoff 抑制窗修复，覆盖结构 op 与 TSV 粘贴整表替换 dispatch（CHANGE-20/25，见 AC-PEND-11） | PRD 6.1、PRD 5.4、PRD 8 |
| AC-RULE-09 | 同源操作语义 | 同一操作在快捷键 / 表格工具栏 / ⋮ 菜单 / 右键菜单四面的行为结果、toast 文案、禁用规则完全一致（同 op id）；当前无快捷键的项（删除行/列、对齐三键、⊞ 缩放、删表）不补专键，键盘通道经 Shift+F10/菜单键唤出与 ⋮=右键同源的菜单后方向键移动、Enter 执行兜底（禁用态灰显不可达），见 AC-PEND-06 | PRD 术语表、PRD 6.1、PRD 12 #10 |
| AC-RULE-10 | 弹层可达 | 全部下拉/子菜单/popover 采用限高滚动 + 边缘翻转策略，在窗口任意位置全项完整可达可点；面板自身限高内滚动不收拢菜单，仅菜单外滚动/超界滚动选择收拢（CHANGE-5） | PRD 2 可达性、PRD 6.2、PRD 8 |
| AC-RULE-11 | 快捷键提示单源派生 | 菜单快捷键提示由快捷键总表单源派生；提示文本与实际触发键位一致；禁止手工双源维护提示（平台键面派生例外仅限登记清单：MENU-menubar §3.4——zoomIn、toggleDevTools，CHANGE-7 登记，见 AC-PEND-02）。已知缺口登记（CHANGE-30，方向待终裁）：mac 回显 ⌘ 与实触发 Ctrl 不一致（收口二选一：(a) 键位注册改 Mod- 使 mac 触发=⌘，或 (b) 回显字面 Ctrl 不做 ⌘ 转换）；`app.searchInFolder` tooltip 键面手工双源（改 fmtShortcut 单源派生或登记入 DERIVATION_EXCEPTIONS） | PRD 6.2、PRD 10、PRD M10 |
| AC-RULE-12 | ⊞ 缩放可选范围 | 网格可选范围逐维取 max(20 行, 既有行数) × max(12 列, 既有列数)（例：25 行×10 列表的可选范围为 25 行×12 列）：20 行×12 列为常规可选上限，既有结构超过上限的维度可选范围扩至该维度现有值，网格不主动缩减既有超出结构（缩放仅按用户拖选值执行）；缩放新增的行/列默认左对齐；缩放删减从表格尾部移除行/列 | PRD 6.1 |
| AC-RULE-13 | 点击语义裁决 | 点击元素内容进入该元素对应编辑形态（写作者路径优先）；纯选中/复制是安全动作，不触发任何工具浮层；图/表/代码相邻处点击语义一致 | PRD 6.4 |
| AC-RULE-14 | 显示态持久化 | 折叠/展开、列宽等显示态不写入 .md 正文、写入本地偏好键；折叠态跨重启持久（关闭并重启应用后保持）；既有偏好键位不变、新增键向后兼容 | PRD 6.3、PRD M10、PRD 10 |
| AC-RULE-15 | 破坏性操作确认 | 破坏性删除中**仅删表**执行前弹确认框，确认后才执行；删表确认文案固定为「删除后可用一步撤销还原，确认删除该表格」；取消则不变更文档。删行/删列为可逆操作不弹确认框，直接执行并以 toast 操作回执 + 一步 undo 承载恢复（见 AC-OP-10、AC-PEND-16）；确认路径以重解析最新表格跨度执行删除，解析失败静默 no-op（CHANGE-22） | PRD 6.1、PRD 6.5、PRD 8 |
| AC-RULE-16 | 只读拦截 | 文件只读时编辑/结构操作全部拦截，不产生半提交状态；提示文案固定为「文件为只读，无法修改，可另存后编辑」（写前拦截真源：`file:isWritable` 跨进程探针 + `assertWritable()` 单点闸门，CHANGE-8/21） | PRD 8 |
| AC-RULE-17 | e2e 缝硬契约 | window.__velox 系列、data-op、data-table-handle、命令 id 字面量为 e2e 缝硬契约；已登记的契约集演进为准入变更（删 4 留 1：删 `data-table-handle="row-insert"/"row-delete"/"col-insert-left"/"col-delete"`、留 `col-grip`，工具栏/⋮ 改挂统一 `data-op` id；⊞ 工具栏项挂 `data-op="resizeTable"` op id 命名空间，弃原型 `TBL-TOOL-GRID` 节点码，探针以 `resizeTable` 为准——CHANGE-3 登记）；此后契约集变更须走登记流程，禁止静默破坏（编辑态整表外框改画 wrap outline 为纯呈现层，零契约影响，CHANGE-15） | PRD 6 导语、PRD M10 |

### 2.3 权限模型

| 编号 | 角色 | 可访问功能 | 数据范围 | 角色特有行为 | 来源 |

### 3.1 表格交互（PRD 6.1）

| 编号 | Given（前置条件） | When（操作） | Then（预期结果） | 来源 |
|---|---|---|---|---|
| AC-FN-01 | 文档含 Markdown 表格，表格未聚焦且鼠标不在表格上 | 进入静息态后逐项核对表格区域 | 表格左缘与正文列左缘水平偏移为 0px；表格左缘无把手带、无常驻留白槽；表格四周无任何常驻控件（常驻 DOM 但 CSS 零漆——静息零像素面——的 hover 微控件挂载点如 col-grip 不计「常驻控件」，CHANGE-29 解读） | PRD 6.1、PRD 13 AC-01 |
| AC-FN-02 | 表格处于编辑态（至少一个单元格已激活） | 逐项核对表格上/下/左/右边缘区域 | 四周无 +/− 增删把手；行列增删入口仅存在于表格工具栏、⋮ 菜单、右键菜单、快捷键四处 | PRD 6.1、PRD 13 AC-02 |
| AC-FN-03 | 表格处于静息态或 hover 态 | 点击表格内任意单元格的内容区域，或点击表格内未命中单元格的空白区域（每次验证单一路径） | 1) 命中路径：表格进入编辑态且被点击单元格进入单元格激活态并显示输入光标；未命中路径：表格进入编辑态、无单元格处于激活态（无输入光标） 2) 两条路径下表格工具栏均浮现（⊞、对齐三键、⋮、🗑；形态为右上浮动紧凑 pill 单组连续排列，CHANGE-13） 3) 正文其他区域位置不变（位移 0px，AC-NF-05）；编辑态整表外框画在 wrap（outline 绕开 border-collapse 压盖，CHANGE-15） | PRD 5.5、PRD 6.1 |
