# FE-03 - 键位归属清理与补注册（Q6 Ctrl+Shift+T 独占 + Q7 zoom×3/DevTools 注册表侧）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_04_menubar.html`

> 来源：[grill-rulings.md#菜单快捷键键盘通道q6q8--pend-010206](../../design/adr/grill-rulings.md#菜单快捷键键盘通道q6q8--pend-010206) / [MENU-menubar.md#33-ctrlshiftt-归属裁决与清理清单q6](../../design/api/MENU-menubar.md#33-ctrlshiftt-归属裁决与清理清单q6) / [MENU-menubar.md#34-缩放devtools-补注册键位表q7](../../design/api/MENU-menubar.md#34-缩放devtools-补注册键位表q7)

落地 Q6/Q7 裁决的**渲染进程注册表侧**改动：① Q6——`Ctrl+Shift+T` 唯一归属 `reopenClosedTab`（重开已关标签，行业肌肉记忆），`toggleTheme` 撤键（仅保留 Titlebar 按钮 + 「视图▸切换主题」菜单入口，回显留空）；② Q7——`zoomIn`/`zoomOut`/`zoomReset`/`toggleDevTools` 补注册 `Ctrl+=` / `Ctrl+-` / `Ctrl+0` / `F12`，动作通道复用 `window.api.windowZoom`/`windowToggleDevTools` 零改动。清理清单生产侧 3 处 + 测试同步 1 处全部闭环（BE-01 承担 darwin 加速键侧）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| Titlebar | 切换主题按钮 tooltip `tb.theme` | Tooltip | Titlebar 主题按钮 hover | 文案去键位：「切换主题」/「Toggle theme」（不再含「（Ctrl+Shift+T）」） | hover 显示 | 无键位后缀 |
| 视图菜单 | 「切换主题」菜单项回显 | MenuItem | 视图▸开发与主题组 | 右侧回显留空（无快捷键） | 空回显 | 点击仍执行 toggleTheme（id/run 不变） |
| 视图菜单 | 「放大」「缩小」「重置缩放」「开发者工具」回显 | MenuItem | 视图▸缩放组 / 开发与主题组 | 回显 `Ctrl+=` / `Ctrl+-` / `Ctrl+0` / `F12`（由 FE-02 派生自动出现） | 补注册后自动显示 | macOS 显示 `⌘+`/`⌘-`/`⌘0`/`⌘⌥I` 转换形态 |

### 交互操作

**1. Q6 Ctrl+Shift+T 归属切换**
- 来源：[grill-rulings.md Q6](../../design/adr/grill-rulings.md#菜单快捷键键盘通道q6q8--pend-010206) / [ac.md#AC-PEND-01](../../requirement/ac.md#51-pending-待确认条目确认后转正式-ac)
- 触发：按 `Ctrl+Shift+T`
- 前置条件：存在可恢复的已关标签（无则 reopenClosedTab 灰显不执行，键位不落 toggleTheme）
- 操作：`tabsCmds.ts` `reopenClosedTab` 独占 `shortcut: 'Ctrl+Shift+T'`（bindGlobal）；`viewCmds.ts` 删除 `toggleTheme` 的 `shortcut` 字段（id/run 不变）
- 期望数据：命令注册表条目 `{ id: 'reopenClosedTab', shortcut: 'Ctrl+Shift+T' }`、`{ id: 'toggleTheme', shortcut: undefined }`
- 状态更新：局部更新——标签栏新增一个恢复标签；切换主题不再被该键触发

**2. Q6 i18n tb.theme 文案去键位**
- 来源：[MENU-menubar.md#33-ctrlshiftt-归属裁决与清理清单q6](../../design/api/MENU-menubar.md#33-ctrlshiftt-归属裁决与清理清单q6) 清理项 #3
- 触发：hover Titlebar 主题按钮 / 查看 zh、en 字典
- 操作：`i18n/zh.ts` `tb.theme` 改「切换主题」、`i18n/en.ts` 改「Toggle theme」
- 期望效果：tooltip 与菜单回显均无「（Ctrl+Shift+T）」字样
- 状态更新：局部更新 tooltip 文案

**3. Q7 zoom×3/DevTools 补注册**
- 来源：[MENU-menubar.md#34-缩放devtools-补注册键位表q7](../../design/api/MENU-menubar.md#34-缩放devtools-补注册键位表q7) / [ac.md#AC-PEND-02](../../requirement/ac.md#51-pending-待确认条目确认后转正式-ac)
- 触发：按 `Ctrl+=` / `Ctrl+-` / `Ctrl+0` / `F12`
- 前置条件：无
- 操作：`viewCmds.ts` 四命令补 `shortcut` 字段（`Ctrl+=`/`Ctrl+-`/`Ctrl+0`/`F12`）；run 闭包不变（`window.api.windowZoom('in'|'out'|'reset')`、`window.api.windowToggleDevTools()`）
- 期望数据：`{ id: 'zoomIn', shortcut: 'Ctrl+=' }` 等四条；动作后窗口缩放比例变化/DevTools 开关（AC-NF-16 复用通道零改动）
- 状态更新：局部更新（缩放为窗口级状态，菜单回显随派生自动齐）
