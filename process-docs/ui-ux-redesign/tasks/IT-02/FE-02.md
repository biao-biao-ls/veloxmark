# FE-02 - 快捷键回显单源派生与双源守护（fmtShortcut 派生固化 + shortcutSync.test）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_04_menubar.html`

> 来源：[MENU-menubar.md#32-快捷键回显单源派生ac-rule-11-零例外](../../design/api/MENU-menubar.md#32-快捷键回显单源派生ac-rule-11-零例外) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型) / [PRD.md#62-顶部菜单栏](../../requirement/prd/PRD.md#62-顶部菜单栏)

把菜单快捷键回显收口为**单源派生**（AC-RULE-11 零例外）：派生源 = 命令注册表 `Command.shortcut` + 表格 `STRUCT_KEYS`（TBL §3.2），派生函数 `fmtShortcut`；有快捷键命令 100% 右侧回显、逐键一致（AC-FN-07/AC-NF-06），无快捷键命令右侧留空不显示占位符。同时把 `shortcutSync.test.ts` 固化为双源守护基线：注册表 `shortcut` 与 `DARWIN_COMMAND_ACCELERATORS` 按派生规则（`Ctrl+`→`Cmd+` 惯例）逐键互检，写法差异（如 zoomIn `Ctrl+=` ↔ `Cmd+Plus`）登记 `DERIVATION_EXCEPTIONS` 并注明原因，双源守护不放宽。禁止菜单侧硬编码键位文案。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 下拉面板 | 菜单项快捷键列 `mi-key` | Text | 菜单项右端对齐列 | 键位文本由 `fmtShortcut` 渲染（Windows/Linux `Ctrl+N`，macOS `⌘N`）；色值取 `--color-*` 弱化 token | 有键命令显示键位，无键命令渲染为空 | 跟随 `Command.shortcut` 变化自动重派生 |
| 下拉面板 | 无键菜单项右端 | Empty | 菜单项右端 | 无占位符、无省略号、无空框 | 留空 | 不随平台变化 |
| 表格 ⋮/右键菜单 | 结构操作快捷键列 `mi-key` | Text | 菜单项右端 | 由 `STRUCT_KEYS` 经同一 `fmtShortcut` 派生（TBL 域共用规则） | 按 STRUCT_KEYS 注册值 | 键位变更时同步重派生 |
| 双源守护 | `DERIVATION_EXCEPTIONS` 登记表 | Data | `commands/shortcutSync.test.ts` 内 | 每条含键对与原因注释（如 `zoomIn: Ctrl+= ↔ Cmd+Plus` 惯例写法差异） | 空表 | 每个例外必须带原因，禁止静默放宽 |

### 交互操作

**1. 菜单展开回显核对（AC-FN-07）**
- 来源：[MENU-menubar.md#32-快捷键回显单源派生](../../design/api/MENU-menubar.md#32-快捷键回显单源派生ac-rule-11-零例外) / [ac.md#AC-FN-07](../../requirement/ac.md#32-顶部菜单栏prd-62)
- 触发：展开任一菜单（含各级子菜单）
- 操作：回显由 `shortcut ? fmtShortcut(shortcut) : undefined` 派生（现状口径固化），覆盖顶部菜单全部菜单项 + 表格 ⋮/右键结构操作菜单
- 期望数据：菜单项渲染结构 `{ label, shortcutText?: 'Ctrl+Shift+P' }`——有键命令 `shortcutText` 与实际触发键位逐字符一致；无键命令 `shortcutText` 为 undefined（右侧留空）
- 状态更新：局部更新菜单 DOM，无整页刷新

**2. 双源守护测试执行（AC-RULE-11）**
- 来源：[tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型) / [MENU-menubar.md#34-缩放devtools-补注册键位表q7](../../design/api/MENU-menubar.md#34-缩放devtools-补注册键位表q7)
- 触发：`npx vitest run src/renderer/src/commands/shortcutSync.test.ts`
- 操作：逐命令比对 `Command.shortcut` 与 `DARWIN_COMMAND_ACCELERATORS` 派生一致性；例外项必须命中 `DERIVATION_EXCEPTIONS` 且带原因
- 期望数据：断言输出示例 `{ cmd: 'save', win: 'Ctrl+S', darwin: 'Cmd+S', derived: 'Cmd+S', exception: null }`；不一致且未登记例外 → 测试失败
- 状态更新：纯测试，无 UI

**3. 回显一致率度量（AC-NF-06）**
- 来源：[ac.md#AC-NF-06](../../requirement/ac.md#6-非功能需求ac-nf-nn) / [PRD.md#10-非功能需求m13](../../requirement/prd/PRD.md#10-非功能需求m13)
- 触发：菜单栏全部菜单项与快捷键总表就绪后逐项比对
- 操作：菜单提示文本 ↔ 实际触发键位逐键比对（含 `fmtShortcut` 平台转换后的显示文本）
- 期望效果：一致率 100%，无一条提示与实际键位不符；禁止菜单侧硬编码键位文案（代码审查断言：menuLayout/MenuBar 无键位字面量）
- 状态更新：不适用（验收度量）
