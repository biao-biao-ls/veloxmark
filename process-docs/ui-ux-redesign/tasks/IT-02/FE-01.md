# FE-01 - 菜单信息架构重排（menuLayout 五根菜单分组/插入域去重/命名统一，命令 id 不变）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_04_menubar.html`

> 来源：[PRD.md#62-顶部菜单栏](../../requirement/prd/PRD.md#62-顶部菜单栏) / [menu-tree.md#2-分组重排意图总表](../../requirement/prd/menu-tree.md#2-分组重排意图总表) / [MENU-menubar.md#31-菜单信息架构重排menu-tree-对照命令标识不变](../../design/api/MENU-menubar.md#31-菜单信息架构重排menu-tree-对照命令标识不变) / [tech-design.md#3-api-接口设计命令契约面](../../design/tech-design.md#3-api-接口设计命令契约面)

把 `MENU_LAYOUT`（`src/renderer/src/commands/menuLayout.ts`）按 menu-tree §3 目标分组重排：文件 5 组 / 编辑 5 组 / 视图 6 组 / 插入 2 组 / 帮助单项；`insertTable`/`convertToTable` 迁出编辑菜单入插入域，插入域去重后「插入表格…」只此一份；「文件夹内搜索…」命名与 `globalSearch` 语义统一。**红线：命令 id / `data-op` 字面量一个都不改**，cdp 探针扫描的命令 id 集合与重排前完全一致（AC-FN-09）。

### 页面元素

> 按区域拆分，覆盖设计稿 ui_04_menubar.html 中全部可交互区域；样式取值引用 token（`--space-*`/`--radius-*`/`--color-*`），不新增裸值。

### 交互操作

**1. 打开任一根菜单查看目标分组**
- 来源：[menu-tree.md#3-顶部菜单栏菜单树](../../requirement/prd/menu-tree.md#3-顶部菜单栏菜单树) / [MENU-menubar.md#31-菜单信息架构重排](../../design/api/MENU-menubar.md#31-菜单信息架构重排menu-tree-对照命令标识不变)
- 触发：点击 Titlebar 菜单按钮「文件」（或「编辑」「视图」「插入」「帮助」）
- 前置条件：应用已启动，无模态确认框开启
- 操作：菜单呈现层 `menu:ia-reorder`——`MENU_LAYOUT` 重排后 buildMenus 输出目标分组（文件：新建与打开/保存/标签页/导出/设置；编辑：历史/剪贴板/查找与整理/格式/选区导出；视图：侧栏与搜索/折叠/模式/输入辅助/缩放/开发与主题；插入：表格/图表与容器；帮助：单项）
- 期望数据：`MENU_LAYOUT` 结构示例 `{ menu: 'view', groups: [{ labelKey: 'menu.grp.sidebarSearch', items: ['toggleSidebar', 'globalSearch', ...] }, ...] }`（组名走 i18n key，item 为命令 id 字面量）
- 状态更新：局部更新——仅下拉面板 DOM 重建，正文零位移（AC-NF-05 口径）
- 空态处理：不适用（菜单为静态结构）
- 禁用规则：`precondition` 不满足灰显（`reopenClosedTab` 无可恢复标签、`nextTab` 标签数 <2、`convertToTable`/`exportSelectionHtml` 无选区），点击不执行

**2. 插入域去重（insertTable 迁移）**
- 来源：[MENU-menubar.md#menu-insert-dedupe](../../design/api/MENU-menubar.md#2-契约清单) / [menu-tree.md#2-分组重排意图总表](../../requirement/prd/menu-tree.md#2-分组重排意图总表)
- 触发：打开「编辑」与「插入」菜单对照
- 操作：`MENU_LAYOUT` 中 `insertTable`、`convertToTable` 从编辑组尾部删除、挂入插入域「表格」组（命令 id 不变，run 闭包不改）
- 期望效果：编辑菜单不再含插入类项；插入菜单显示「插入表格…」（唯一份）与「选区转表格…」；cdp 探针扫描命令 id 集合与重排前完全一致
- 状态更新：局部更新菜单呈现层

**3. 命名统一（globalSearch）**
- 来源：[MENU-menubar.md#menu-rename-consistency](../../design/api/MENU-menubar.md#2-契约清单) / [PRD.md#62-顶部菜单栏](../../requirement/prd/PRD.md#62-顶部菜单栏)
- 触发：查看「视图▸文件夹内搜索…」菜单项
- 操作：菜单文案核对为「文件夹内搜索…」/「Search in folder…」（id `globalSearch` 不变）；文档/文案中旧「全局搜索」表述统一为该口径
- 期望效果：命名与搜索范围语义一致，id 不变

**4. 新分组名 i18n 双字典对齐（AC-FN-28）**
- 来源：[MENU-menubar.md#4-与现有实现差异](../../design/api/MENU-menubar.md#4-与现有实现差异差异-10) / [ac.md#AC-FN-28](../../requirement/ac.md#37-跨模块与联动prd-m10)
- 触发：切换界面语言 en → zh → en
- 操作：新增分组名 key（`menu.grp.newOpen`、`menu.grp.save`、`menu.grp.tabs`、`menu.grp.export`、`menu.grp.settings`、`menu.grp.history`、`menu.grp.clipboard`、`menu.grp.findOrganize`、`menu.grp.format`、`menu.grp.selectionExport`、`menu.grp.sidebarSearch`、`menu.grp.fold`、`menu.grp.mode`、`menu.grp.inputAssist`、`menu.grp.zoom`、`menu.grp.devTheme`、`menu.grp.table`、`menu.grp.chartContainer` 等）同时写入 `i18n/en.ts` + `i18n/zh.ts`
- 期望数据：`en.ts`/`zh.ts` key 集合完全一致，无原始 key 裸露
- 状态更新：局部更新菜单文案，不刷新窗口

### 异常场景
