# BE-02 - macOS 原生菜单分组与文案对齐（menu-tree 附录 A + NATIVE_MENU_STRINGS 新分组名 en/zh）

<!-- REQUIRED:任务目标 -->
## 任务目标

> 来源：[MENU-menubar.md#36-macos-原生菜单对齐附录-a-口径](../../design/api/MENU-menubar.md#36-macos-原生菜单对齐附录-a-口径) / [menu-tree.md#附录-a-macos-原生菜单差异对照](../../requirement/prd/menu-tree.md#附录-a-macos-原生菜单差异对照只读现状对照非-windowslinux-菜单栏范围) / [ac.md#AC-FN-28](../../requirement/ac.md#37-跨模块与联动prd-m10)

对齐 macOS 原生菜单与 menu-tree 目标分组（附录 A 口径）：原生菜单分组（文件/编辑/视图/窗口 + App 菜单）与 menu-tree §3 分组对照对齐；新增分组名（「标签页」「侧栏与搜索」「开发与主题」等）写入 `NATIVE_MENU_STRINGS`（i18n 第 3 份字典）en/zh 双语；命令 id 经 `menu:<id>` 转发同一命令注册表，id 契约不变（AC-FN-09）。保持既有裁决行为：格式子菜单不挂原生加速键（CM6 keymap 拥有 Mod-B/I/E）、标签命令不挂原生加速键（Ctrl+W 走 before-input 标签感知路由）。

## API 接口文档

> 本仓无 HTTP 后端；「接口」为原生菜单文案/分组契约（桌面适配口径）。接口定义维护在 MENU-menubar.md。

### 新增接口

| 接口 | 文档路径 |
|------|---------|
| 文案契约 `menu:native-parity`（NATIVE_MENU_STRINGS 新分组名 en/zh 增补） | [../../design/api/MENU-menubar.md](../../design/api/MENU-menubar.md) |

### 复用接口

| 接口/方法 | 本任务调用说明 |
|----------|--------------|
| `NATIVE_MENU_STRINGS`（electron/shared/menuStrings.ts） | 既有 label 字典，本任务增补新分组名 key（en/zh 两份同加） |
| `menu:<id>` 命令转发（darwin 菜单 click → 命令注册表） | 调用参数：命令 id 字面量；使用响应字段：命令执行结果（id 集合不变，AC-FN-09） |
| `DARWIN_COMMAND_ACCELERATORS`（BE-01 维护） | 加速键注入来源，本任务只读（不手写 accelerator） |

<!-- REQUIRED:核心流程 -->
## 核心流程

**1. 原生菜单分组对齐**
- 来源：[MENU-menubar.md#36-macos-原生菜单对齐](../../design/api/MENU-menubar.md#36-macos-原生菜单对齐附录-a-口径) / [menu-tree.md#附录-a](../../requirement/prd/menu-tree.md#附录-a-macos-原生菜单差异对照只读现状对照非-windowslinux-菜单栏范围)
- 输入：menu-tree §3 目标分组（文件 5 组/编辑 5 组/视图 6 组/插入 2 组/帮助单项）+ 附录 A 差异对照表
- 处理逻辑：逐菜单比对 darwin 菜单模板分组与 menu-tree 目标 → 调整分组线与组内位次（label/分组为呈现层）→ 命令 id 与 `menu:<id>` 转发零改动 → 差异处（mac 特有 App 菜单/窗口菜单）保留并在附录 A 登记理由
- 输出：darwin 菜单模板（分组对齐、id 集合不变）
- 异常处理：命令 id 集合漂移由 cdp 探针扫描断言拦截（AC-FN-09）

**2. NATIVE_MENU_STRINGS 新分组名双语增补**
- 来源：[MENU-menubar.md#4-9](../../design/api/MENU-menubar.md#4-与现有实现差异差异-10) / [ac.md#AC-FN-28](../../requirement/ac.md#37-跨模块与联动prd-m10)
- 输入：新分组名清单（与 FE-01 i18n key 清单同源：标签页/侧栏与搜索/折叠/模式/输入辅助/缩放/开发与主题/表格/图表与容器 等）
- 处理逻辑：在 `electron/shared/menuStrings.ts` 的 en/zh 两份字典同加 key → 分组名 label 查字典渲染 → 与渲染端 `i18n/en.ts`+`zh.ts` 同名语义对齐（第 3 份字典独立维护但 key 语义一致）
- 输出：`NATIVE_MENU_STRINGS` en/zh key 集合一致
- 异常处理：key 集合不一致时切换语言出现裸 key → 由 AC-FN-28 走查拦截

**3. 既有不挂键行为保持核对**
- 来源：[MENU-menubar.md#36](../../design/api/MENU-menubar.md#36-macos-原生菜单对齐附录-a-口径)
- 输入：格式子菜单、标签命令（Ctrl+W）
- 处理逻辑：核对两处不挂原生加速键（避免与 CM6 keymap / before-input 标签感知路由抢注）——行为既有不变，仅回归确认
- 输出：无变更（回归通过）
- 异常处理：若误挂加速键导致键位抢注，测试/走查暴露后回退
