# FE-10 - 侧栏视觉 token 化审计（焦点环/三态取 token，深浅主题对照走查）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_05_sidebar.html`

> 来源：[NAV-sidebar.md#4-7-侧栏视觉-token-化改造](../../design/api/NAV-sidebar.md#4-与现有实现差异现状--目标) / [ac.md#AC-FN-12](../../requirement/ac.md#33-左侧导航栏prd-63) / [tech-design.md#84-差异化策略](../../design/tech-design.md#84-差异化策略)

对左侧导航栏（文件树/大纲）执行**视觉 token 化审计改造**（PRD 6.3）：侧栏间距/圆角/颜色/焦点环/三态（hover/激活/键盘焦点）全部取自设计规范 token（`--space-*`/`--radius-*`/`--color-*`），代码中无 token 之外新增裸 px/色值；深浅主题差异一律 `.theme-light`/`.theme-dark` 翻值，零 `.theme-dark` 补丁选择器（宪法）。深色与浅色主题各执行一遍对照走查，两遍清单全部条目通过（AC-FN-12）。

### 页面元素

> 对 ui_05_sidebar.html 侧栏全区做审计式覆盖；元素规格以 token 名声明，不新增裸值。

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 侧栏容器 | 面板背景/边框 | Panel | 左侧栏整体 | 背景/边框取 `--color-*` token；宽度/内边距 `--space-*` | 跟随主题 | 深浅主题仅 token 翻值 |
| 侧栏 tab | 面板 tab（文件树/大纲） | Tab | 面板头 | 间距/圆角/激活下划线取 token | 文件树激活 | hover/激活态 token 化 |
| 文件树 | 树行三态（hover/激活/焦点） | TreeItem | 行 | hover/active/focus 三态色值各取 token，可区分 | 静息 | 键盘焦点环 `--color-focus` 系 token |
| 大纲 | 节点行三态 + 层级缩进 | ListItem | 按 lvl-N 缩进 | 缩进步长 `--space-*`；active-follow 高亮 token | 静息 | 三态切换仅类名 |
| 侧栏 | 折叠三角/图标/拖拽把手 | Icon/Handle | 行内 | 图标色/把手浮现规格 token（UI-ELEM-05 口径） | 按态渲染 | 无常驻 chrome |
| 主题适配 | .theme-light / .theme-dark 翻值 | Token | `:root` 唯一声明点 | 仅翻 token 值 | 跟随主题 | 无新增 `.theme-dark` 补丁选择器 |

### 交互操作

**1. token 扫描审计**
- 来源：[ac.md#AC-FN-12](../../requirement/ac.md#33-左侧导航栏prd-63) / [ac.md#UI-ELEM-01](../../requirement/ac.md#82-样式类ui-elem-nn)
- 触发：改造完成后代码扫描侧栏样式分区
- 操作：扫描侧栏相关 css/组件样式中的裸 px/色值，逐处替换为 token 或登记豁免（间距/圆角/颜色三类）
- 期望数据：扫描报告示例 `{ file: 'styles/sidebar.css', rawValues: 0, tokensUsed: ['--space-2', '--radius-sm', '--color-focus'] }`
- 状态更新：纯样式，无交互行为变化

**2. 深浅主题对照走查（AC-FN-12）**
- 来源：[ac.md#AC-FN-12](../../requirement/ac.md#33-左侧导航栏prd-63) / [PRD.md#12-开放问题与风险m16](../../requirement/prd/PRD.md#12-开放问题与风险m16)
- 触发：切换 `.theme-dark` / `.theme-light` 各执行一遍走查清单
- 操作：逐项判定侧栏间距/圆角/颜色/三态对比度（≥4.5:1，AC-NF-09 口径）
- 期望效果：两遍走查清单全部条目通过；无未适配硬编码色

### 异常场景

| 场景 | 处理 | 提示文案 |
|------|------|---------|
| 发现裸 px/色值 | 替换为 token；确需保留的登记豁免并注明理由 | 无 |
| 深浅主题下对比度 <4.5:1 | 调整 token 翻值后重走该条目 | 无 |
| 新增样式误用 .theme-dark 补丁选择器 | 审查拦截（宪法：不新增选择器级补丁） | 无 |
