# FE-08 - 大纲键盘导航（roving tabindex + ↑/↓/←/→/Enter，折叠写 headingFolds）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_05_sidebar.html`

> 来源：[NAV-sidebar.md#32-大纲键盘导航nav-keyboard-outline新增](../../design/api/NAV-sidebar.md#32-大纲键盘导航nav-keyboard-outline新增) / [grill-rulings.md Q9](../../design/adr/grill-rulings.md#左导航与存储q9q10--pend-08091415) / [ac.md#AC-FN-30](../../requirement/ac.md#33-左侧导航栏prd-63)

为大纲面板新增键盘导航（Q9「实现」项的大纲半侧）：roving tabindex + ↑/↓ 焦点在大纲节点间移动、Enter 激活跳转（等效点击，走 FE-07 `useOutlineNav` 平滑跳转，active 随焦点项）、←/→ 折叠/展开该章节（等效点击折叠三角，与正文双向同步 AC-FN-30，折叠写 `headingFolds`）。焦点移动不跳转正文（Enter 才跳）；折叠为轻量态切换**不回 toast**（PEND-15 口径）；焦点环 token 化（UI-ELEM-01）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 大纲面板 | 大纲节点行 `outline-row lvl-N` | TreeItem | 按层级缩进纵向排列 | 标题文本；层级缩进 `--space-*` token | 无焦点行 | ↑/↓ 移动键盘焦点（roving tabindex） |
| 大纲面板 | 节点折叠三角 | Icon | 节点行左侧 | 指向随折叠/展开切换（UI-IXD-06） | 按 headingFolds 持久态 | ←/→/点击切换折叠，正文同步 |
| 大纲面板 | 键盘焦点环 | Style | 焦点节点外缘 | `--color-focus`/`--radius-*` token | 不显示 | 仅键盘导航时可见，与 hover/active 三态可区分 |
| 大纲面板 | active 高亮（联动 FE-07） | Style | 当前可视章节项 | token 高亮 | 跟随滚动 | Enter 跳转后随焦点项 |

### 交互操作

**1. 键盘移动焦点（↑/↓）**
- 来源：[NAV-sidebar.md#32-大纲键盘导航](../../design/api/NAV-sidebar.md#32-大纲键盘导航nav-keyboard-outline新增)
- 触发：大纲面板聚焦后按 ↑/↓
- 前置条件：大纲非空
- 操作：roving tabindex（仅焦点行 `tabIndex=0`，其余 -1），焦点在大纲节点间移动
- 期望数据：焦点模型 `{ nodes: OutlineNode[], focusIndex }`（node 含 `{ id, level, text, expanded, hasChildren }`）
- 状态更新：局部更新焦点类名；**焦点移动不跳转正文**

**2. Enter 激活跳转（等效点击）**
- 来源：[NAV-sidebar.md#32-大纲键盘导航](../../design/api/NAV-sidebar.md#32-大纲键盘导航nav-keyboard-outline新增) / [NAV-sidebar.md#35-大纲激活态与平滑跳转](../../design/api/NAV-sidebar.md#35-大纲激活态与平滑跳转nav-outline)
- 触发：焦点节点按 Enter
- 操作：调用 FE-07 `useOutlineNav.jumpToHeading(headingId)`（与点击同一路径）：平滑跳转 + active 随焦点项 + 光标落标题
- 期望效果：行为与鼠标点击大纲项完全一致（AC-FN-11 口径）

**3. ←/→ 折叠/展开（AC-FN-30）**
- 来源：[NAV-sidebar.md#32-大纲键盘导航](../../design/api/NAV-sidebar.md#32-大纲键盘导航nav-keyboard-outline新增) / [NAV-sidebar.md#34-折叠双向同步](../../design/api/NAV-sidebar.md#34-折叠双向同步nav-fold-bidirectional复用)
- 触发：焦点节点按 ←（折叠）/ →（展开）
- 操作：等效点击折叠三角；折叠态写入 `veloxmark.session.headingFolds`（`foldKey(level,text)` 格式，Q10 复用既有键）；正文对应章节同步折叠/展开
- 期望数据：`headingFolds: Record<filePath, string[]>` 追加/移除 foldKey
- 状态更新：局部更新大纲折叠态 + 正文装饰折叠（双向同步）；不回 toast（PEND-15）；不移动正文光标
- 期望效果：折叠含全部子章节、标题行保留；.md 正文零字节变化

### 异常场景

| 场景 | 处理 | 提示文案 |
|------|------|---------|
| 无子章节的叶子节点按 ←/→ | 不动作、不报错 | 无 |
| 大纲空态 | 无焦点行，键盘事件不劫持正文输入 | 无 |
| 焦点在正文时按 ↑/↓/Enter | 不触发大纲动作 | 无 |
| 折叠操作（轻量态） | 不回 toast（PEND-15 差异声明口径） | 无 |
