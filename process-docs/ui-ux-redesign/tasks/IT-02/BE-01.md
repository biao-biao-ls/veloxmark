# BE-01 - 加速键单源收敛（Q6 toggleTheme 撤键 + Q7 zoom×3/DevTools 四键迁入 DARWIN_COMMAND_ACCELERATORS）

<!-- REQUIRED:任务目标 -->
## 任务目标

> 来源：[MENU-menubar.md#34-缩放devtools-补注册键位表q7](../../design/api/MENU-menubar.md#34-缩放devtools-补注册键位表q7) / [MENU-menubar.md#33-ctrlshiftt-归属裁决与清理清单q6](../../design/api/MENU-menubar.md#33-ctrlshiftt-归属裁决与清理清单q6) / [tech-design.md#3-api-接口设计命令契约面](../../design/tech-design.md#3-api-接口设计命令契约面)

收敛 macOS 原生菜单加速键到 `DARWIN_COMMAND_ACCELERATORS` 单源（Q6/Q7 裁决的主进程侧）：① Q6 清理项 #2——删除 `toggleTheme: 'Cmd+Shift+T'` entry（原生菜单不再挂加速键，切换主题仅 Titlebar 按钮+菜单入口）；② Q7——`zoomIn`/`zoomOut`/`zoomReset`/`toggleDevTools` 四键迁入单源映射（`Cmd+Plus`/`Cmd+-`/`Cmd+0`/`Cmd+Alt+I`），`electron/menu/darwin.ts` 现手写 `accelerator` 字段全部改读单源映射（darwin 菜单构建走 `menu:<id>` 转发同一命令注册表，id 契约不变）。双源同步由 `shortcutSync.test` 派生规则守护（`Ctrl+`→`Cmd+` 惯例；zoomIn `Ctrl+=` ↔ `Cmd+Plus` 写法差异由渲染侧登记 `DERIVATION_EXCEPTIONS`，本任务保证映射值与该登记一致）。

<!-- REQUIRED:核心流程 -->
## 核心流程

**1. 单源映射表增删**
- 来源：[MENU-menubar.md#33-清理清单](../../design/api/MENU-menubar.md#33-ctrlshiftt-归属裁决与清理清单q6) 清理项 #2 / [MENU-menubar.md#34-键位表](../../design/api/MENU-menubar.md#34-缩放devtools-补注册键位表q7)
- 输入：Q6/Q7 键位裁决表（toggleTheme 撤键；zoomIn=`Cmd+Plus`、zoomOut=`Cmd+-`、zoomReset=`Cmd+0`、toggleDevTools=`Cmd+Alt+I`）
- 处理逻辑：在 `electron/shared/commandAccelerators.ts` 的 `DARWIN_COMMAND_ACCELERATORS` 中删除 `toggleTheme` 条目 → 新增 4 条 zoom/DevTools 映射（键为命令 id 字面量，值为 mac 加速键串）→ 条目顺序按命令域归组
- 输出：更新后的单源映射表（`Record<命令id, 加速键串>`）
- 异常处理：命令 id 与渲染端注册表不一致时由 `shortcutSync.test` 断言失败拦截（构建期暴露，不进运行态）

**2. darwin 菜单构建改走单源**
- 来源：[MENU-menubar.md#accel-single-source](../../design/api/MENU-menubar.md#2-契约清单) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构)
- 输入：菜单树（分组与命令 id，BE-02 对齐 menu-tree 附录 A）
- 处理逻辑：扫描 `electron/menu/darwin.ts` 中手写 `accelerator: '...'` 字段（现状位于视图菜单 zoom 三项与 DevTools 约 L240-247）→ 全部删除 → 构建菜单项时按命令 id 查 `DARWIN_COMMAND_ACCELERATORS` 单源映射注入 accelerator → 映射缺失则不挂加速键（如格式子菜单 Mod-B/I/E、标签命令 Ctrl+W 维持既有不挂行为）
- 输出：darwin 原生菜单模板（accelerator 全部派生自单源）
- 异常处理：映射缺失不抛错、不挂键（灰显/无键即可发现）；toggleTheme 经映射删除后原生菜单无加速键

**3. 双源一致性自检**
- 来源：[tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)
- 输入：渲染端 `Command.shortcut` 集 + 本映射表
- 处理逻辑：逐命令派生比对（`Ctrl+`→`Cmd+` 惯例）；zoomIn `Ctrl+=` ↔ `Cmd+Plus` 命中渲染侧 `DERIVATION_EXCEPTIONS` 登记（原因：惯例写法差异）；`toggleTheme` 双侧均无键（反向钉住）
- 输出：`shortcutSync.test` 全绿
- 异常处理：不一致且未登记例外 → 测试失败，禁止合入（AC-RULE-11 零例外）
