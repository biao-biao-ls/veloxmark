# FE-04 - 菜单弹层限高滚动与边缘翻转（下拉/子菜单全项可达 + 四条关闭路径）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_04_menubar.html`

> 来源：[MENU-menubar.md#35-弹层限高滚动--边缘翻转可达ac-rule-10](../../design/api/MENU-menubar.md#35-弹层限高滚动--边缘翻转可达ac-rule-10) / [tech-design.md#112-参数化设计](../../design/tech-design.md#112-参数化设计) / [ac.md#AC-RULE-10](../../requirement/ac.md#22-操作与交互规则)

为全部下拉/子菜单弹层落地**限高滚动 + 边缘翻转**（AC-RULE-10，弹层基座横向能力不绑定表格）：最大高度 = 窗口可视高 − 菜单栏高 − 边距，超出内滚动；靠窗口下缘整菜单上翻、靠右缘子菜单左翻；子菜单 hover 延展不因翻转/滚动断链。窗口极窄/极小（min 640×400）自适应收紧/滚动不裁切。四条关闭路径（选中项 / Esc / 外点 / 超界滚动选择）终态必关闭且 Esc/外点/超界路径焦点回正文（AC-FN-10）。视图 15 项、表格 ⋮ 19 项为最高风险面（AC-FN-05 与 TBL 域共验）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 下拉面板 | menu-panel 限高容器 | Menu | 根按钮下方；最大高 = 窗口可视高 − 菜单栏高 − 边距 | 滚动条样式走 token；面板圆角/阴影 `--radius-*`/`--color-*` | 展开即计算限高 | 内容超高出现内滚动，不重排父级位置 |
| 下拉面板 | 边缘翻转态 menu-panel（上翻/左翻） | Menu | 贴下缘时整面板上翻至根按钮上方；贴右缘时子菜单左翻 | 翻转后视觉规格不变 | 按锚点位置自动选择展开方向 | 窗口移动/缩放后重算方向 |
| 子菜单 | submenu（打开最近/导出/格式） | SubMenu | 父项右侧（左翻时左侧） | 同面板 token 规格 | hover 父项延展展开 | 移回父项收拢子菜单、一级保持展开（AC-RULE-02） |
| 子菜单 | `submenu--flip` 左翻标记 | Style | 右缘命中时 | 类名切换，无新增裸值 | 未翻转 | 翻转后 hover 路径不断链 |
| 滚动指示 | mini-track / mini-thumb | Scrollbar | 面板右缘内侧 | token 化滚动条 | 内容超高才显示 | 滚动不改变面板锚点 |
| 窗口极窄态 | 收紧/滚动布局 | Style | min 640×400 | 自适应手段不限，以结果断言为准 | 自动 | 调大窗口后布局还原，无持久错位 |

### 交互操作

**1. 下拉菜单限高滚动（AC-RULE-10 / AC-FN-08）**
- 来源：[MENU-menubar.md#35-弹层限高滚动](../../design/api/MENU-menubar.md#35-弹层限高滚动--边缘翻转可达ac-rule-10) / [ac.md#AC-FN-08](../../requirement/ac.md#32-顶部菜单栏prd-62)
- 触发：在窗口右/下边缘位置展开「视图」（15 项）或表格 ⋮（19 项）菜单
- 前置条件：窗口位置使菜单自然尺寸超出可视区
- 操作：弹层基座计算限高（窗口可视高 − 菜单栏高 − 边距）→ 超高内滚动；命中下缘整菜单上翻、命中右缘子菜单左翻
- 期望数据：布局计算输入 `{ anchorRect, viewport, menuNaturalSize }` → 输出 `{ maxHeight, placement: 'bottom'|'top', submenuPlacement: 'right'|'left' }`
- 状态更新：局部更新弹层定位，正文 0 位移（AC-NF-05）
- 期望效果：全部一级项位于可视区内；子菜单完整展开不裁切；hover 子菜单项间移动不闪烁；移回父级收拢子菜单、一级保持展开

**2. 四条关闭路径（AC-FN-10）**
- 来源：[MENU-menubar.md#35-关闭路径](../../design/api/MENU-menubar.md#35-弹层限高滚动--边缘翻转可达ac-rule-10) / [ac.md#AC-FN-10](../../requirement/ac.md#32-顶部菜单栏prd-62)
- 触发：选择一个菜单项，或按 Esc，或点击菜单外区域，或限高滚动下的超界滚动选择（每次验证单一触发）
- 操作：菜单状态机出口统一收拢（含子菜单）
- 期望效果：四条路径均收拢至关闭态；Esc/外点/超界滚动选择后焦点回编辑器正文，后续键盘输入直接进正文

**3. 窗口极窄自适应（AC-ERR-09）**
- 来源：[ac.md#AC-ERR-09](../../requirement/ac.md#5-异常场景ac-err-nn)
- 触发：窗口缩至 640×400 后展开全部下拉/子菜单
- 操作：自适应收紧/滚动
- 期望效果：全部菜单项完整可见可点、无裁切不可达；调回大窗口布局还原

### 异常场景

| 场景 | 处理 | 提示文案 |
|------|------|---------|
| 菜单自然高度超过可视区 | 限高内滚动（mini-track/thumb），不裁切 | 无 |
| 子菜单展开会越过右/下边界 | 边缘翻转（左翻/上翻），hover 路径保持 | 无 |
| 超界滚动选择（滚动到边界继续选择） | 视为关闭路径之一，收拢并焦点回正文 | 无 |
| 窗口极窄 640×400 | 自适应收紧/滚动，无不可达项 | 无 |
| 菜单文字/快捷键列对比度不足 | 严格取 token 值（深浅主题翻值），走查拦截（AC-NF-09 口径） | 无 |
