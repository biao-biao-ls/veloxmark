# FE-06 - 文件树键盘导航（filetreeKeys 纯逻辑模块 + roving tabindex + 单测）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_05_sidebar.html`

> 来源：[NAV-sidebar.md#31-文件树键盘导航nav-keyboard-file-tree新增](../../design/api/NAV-sidebar.md#31-文件树键盘导航nav-keyboard-file-tree新增) / [grill-rulings.md Q9](../../design/adr/grill-rulings.md#左导航与存储q9q10--pend-08091415) / [PRD.md#63-左侧导航栏](../../requirement/prd/PRD.md#63-左侧导航栏)

为文件树新增键盘导航（Q9 三候选中唯一「实现」项的文件树半侧）：抽 `filetreeKeys.ts` 纯逻辑模块（键位 → 动作映射 + 可见行计算），`FileTree.tsx` 接 roving tabindex（仅当前焦点行 `tabIndex=0`，其余 -1）。键位：↑/↓ 可见行间移动焦点、← 折叠当前目录/已折叠移至父节点、→ 展开/已展开移至首个子节点、Enter 打开文件节点或切换目录展开态、Home/End 首/末可见行。焦点可见（token 化焦点环，UI-ELEM-01），与 hover/激活态三态可区分。焦点移动不触发文件打开；与既有拖拽排序（Esc 取消拖拽）、活动文件行滚入视口、虚拟滚动共存不回归。

### 交互操作

**1. 键盘移动焦点（↑/↓/Home/End）**
- 来源：[NAV-sidebar.md#31-文件树键盘导航](../../design/api/NAV-sidebar.md#31-文件树键盘导航nav-keyboard-file-tree新增)
- 触发：文件树面板聚焦（Tab/点击进入侧栏）后按 ↑/↓/Home/End
- 前置条件：树非空（空树无焦点行、键盘事件不劫持正文输入）
- 操作：`filetreeKeys.resolveKey(state, key)` → `{ action: 'move'|'collapse'|'expand'|'open'|'first'|'last', nextIndex }`；roving tabindex 仅焦点行 `tabIndex=0`
- 期望数据：状态 `{ rows: VisibleRow[], focusIndex }`，VisibleRow `{ path, depth, isDir, expanded, visible }`（虚拟滚动下仅渲染窗口内行参与）
- 状态更新：局部更新（焦点类名/tabIndex 切换），焦点行滚入视口
- 期望效果：焦点移动不触发文件打开（Enter 才执行）

**2. 折叠/展开与打开（←/→/Enter）**
- 来源：[NAV-sidebar.md#31-文件树键盘导航](../../design/api/NAV-sidebar.md#31-文件树键盘导航nav-keyboard-file-tree新增)
- 触发：焦点行按 ← / → / Enter
- 操作：← 折叠当前目录，已折叠时焦点移至父节点；→ 展开，已展开时移至首个子节点；Enter 打开文件节点（载入文档标签，走既有文件 IO 流程）/ 切换目录展开态
- 期望效果：无子节点的文件行 ←/→ 不动作；只读文件打开仍走既有流程（本契约不改文件 IO 语义）

### 异常场景

| 场景 | 处理 | 提示文案 |
|------|------|---------|
| 空树 | 无焦点行，键盘事件不劫持正文输入 | 无 |
| 无子节点文件行按 ←/→ | 不动作、不报错 | 无 |
| 焦点在正文时按 ↑/↓ | 不触发侧栏动作（仅侧栏聚焦生效） | 无 |
| 键盘导航与拖拽并发（Esc 取消拖拽） | 既有 Esc 取消拖拽行为保持，两者互不干扰 | 无 |
