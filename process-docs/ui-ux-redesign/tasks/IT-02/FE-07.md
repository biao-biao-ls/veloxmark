# FE-07 - 大纲平滑跳转与 active 跟随（useOutlineNav 抽离，App.tsx 一行转发）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_05_sidebar.html`

> 来源：[NAV-sidebar.md#35-大纲激活态与平滑跳转nav-outline](../../design/api/NAV-sidebar.md#35-大纲激活态与平滑跳转nav-outline) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构) / [ac.md#AC-FN-11](../../requirement/ac.md#33-左侧导航栏prd-63)

把大纲跳转与 active 跟随逻辑从 `App.tsx` 抽到独立模块 `hooks/useOutlineNav.ts`（CLAUDE.md 红线：新逻辑不入 App.tsx，`goToHeading` 缩为一行转发）：① 点击/Enter 大纲项正文**平滑跳转**（`behavior: 'smooth'` 口径）垂直居中视口，该大纲项保持 active、动画期间不闪烁；② 滚动正文时当前可视章节对应大纲项 active 高亮随滚动位置切换；③ 跳转后光标落该标题处（现状 `goToHeading` 行为保持），目标在折叠区内先自动展开（`expandFolds` 既有行为保持）；④ 跳转/折叠不引起正文布局位移（AC-NF-05）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 大纲面板 | 大纲项 `outline-row lvl-N` | ListItem | 面板纵向列表，按标题层级缩进 | 标题文本 + 层级缩进 `--space-*` token | 无 active | 滚动跟随：可视章节对应项进入 active 高亮并随滚动切换 |
| 大纲面板 | active 项高亮 | Style | 当前行 | 高亮取 `--color-*` token（active-follow） | 首个可视章节项 | 跳转后保持 active；动画期间不闪烁 |
| 正文区 | 滚动定位目标 | EditorBlock | 标题块 | 垂直居中视口 | — | 平滑滚动动画（smooth），不瞬移 |
| 正文区 | 光标落点 | Caret | 目标标题处 | — | — | 跳转后键盘输入可直接编辑该标题 |

### 交互操作

**1. 点击大纲项平滑跳转（AC-FN-11-2）**
- 来源：[NAV-sidebar.md#35-大纲激活态与平滑跳转](../../design/api/NAV-sidebar.md#35-大纲激活态与平滑跳转nav-outline) / [ac.md#AC-FN-11](../../requirement/ac.md#33-左侧导航栏prd-63)
- 触发：点击大纲中某标题项
- 前置条件：文档含多个标题，大纲面板展开
- 操作：`useOutlineNav.jumpToHeading(headingId)` → 目标在折叠区内先展开（`expandFolds`）→ 正文平滑滚动定位该标题（垂直居中）→ 光标落该标题处
- 期望数据：入参 `{ headingId, level, text, foldKey }`；输出滚动位置与光标位置（行为 smooth）
- 状态更新：局部更新——大纲 active 项切换 + 正文滚动，正文内容与布局 0 位移（AC-NF-05）
- 期望效果：该大纲项保持 active 态；动画期间 active 不闪烁；随后键盘输入直接编辑

**2. 滚动 active 跟随（AC-FN-11-1）**
- 来源：[NAV-sidebar.md#nav-outline-active-follow](../../design/api/NAV-sidebar.md#2-契约清单) / [ac.md#AC-FN-11](../../requirement/ac.md#33-左侧导航栏prd-63)
- 触发：滚动正文
- 操作：`useOutlineNav` 订阅滚动位置 → 计算当前可视章节 → 对应大纲项 active 高亮随滚动切换
- 期望数据：`{ scrollTop, visibleHeadingId }` → 大纲 active 项跟随更新（节流/防抖避免闪烁）
- 状态更新：局部更新大纲高亮，不引起正文布局变化

### 异常场景

| 场景 | 处理 | 提示文案 |
|------|------|---------|
| 目标标题位于折叠区内 | 先自动展开折叠（`expandFolds` 既有行为）再定位 | 无 |
| 快速连续点击多个大纲项 | 平滑动画可打断重定向，active 终态与最后点击一致、无闪烁 | 无 |
| 文档无标题 | 大纲空态，跳转入口不出现 | 无 |
| 动画期间滚动正文 | 跟随逻辑与跳转动画互斥保护，active 不抖动 | 无 |
