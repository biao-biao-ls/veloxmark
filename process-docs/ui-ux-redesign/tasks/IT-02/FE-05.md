# FE-05 - 菜单与子菜单键盘遍历（方向键遍历/Enter 执行/Esc 关闭，Q8 菜单键盘化兜底）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_04_menubar.html`

> 来源：[grill-rulings.md Q8](../../design/adr/grill-rulings.md#菜单快捷键键盘通道q6q8--pend-010206) / [MENU-menubar.md#31-触发路径](../../design/api/MENU-menubar.md#31-菜单信息架构重排menu-tree-对照命令标识不变) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)

为顶部菜单栏及其子菜单补齐**键盘遍历通道**（Q8「菜单键盘化兜底」的菜单栏侧）：菜单栏聚焦后 ←/→ 切换根菜单、↑/↓ 遍历菜单项、→/Enter 进入子菜单、←/Esc 收拢、Enter 执行、Esc 关闭并焦点回正文。菜单项 hover 态/激活态/禁用态三态视觉可区分（UI-IXD-11），禁用项灰显不可点且键盘跳过不执行（UI-ELEM-04）。菜单状态机（AC-RULE-02）与四条关闭路径（AC-FN-10）语义保持：子菜单移回收拢回一级不关菜单、任何执行/Esc/外点终态必关闭。键盘通道与鼠标通道同源等效（AC-RULE-09 同源口径：快捷键/工具栏/⋮/右键/菜单栏键盘五面行为结果一致）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 菜单栏 | 根菜单按钮焦点态 | Button | Titlebar 菜单按钮 | 焦点环 token（`--color-*`/`--radius-*`），与 hover 态可区分 | 无焦点 | Tab/方向键聚焦后显示焦点环 |
| 下拉面板 | 菜单项激活态 `mi.is-hover`（键盘） | MenuItem | 面板内纵向项 | 激活高亮取 token；随 ↑/↓ 移动 | 无激活项 | 首项默认激活；↑/↓ 循环或边界停止（与鼠标 hover 同高亮样式） |
| 下拉面板 | 禁用项 `mi.is-disabled` | MenuItem | 分组内 | 灰显样式，不可点击 | 按 precondition 置灰 | 键盘遍历跳过、Enter 不执行 |
| 子菜单 | submenu 焦点态 | SubMenu | 父项侧向展开 | 进入后焦点移入子菜单首项 | 未展开 | ←/Esc 收拢回一级并把激活态还给父项 |
| 状态出口 | 关闭态 | — | — | 无残留焦点环 | 关闭 | Esc/Enter/外点后焦点回正文 |

### 交互操作

**1. 菜单栏键盘开合与遍历**
- 来源：[MENU-menubar.md#31-触发路径](../../design/api/MENU-menubar.md#31-菜单信息架构重排menu-tree-对照命令标识不变) / [grill-rulings.md Q8](../../design/adr/grill-rulings.md#菜单快捷键键盘通道q6q8--pend-010206)
- 触发：菜单栏聚焦（Tab 进入或点击后）按 ←/→/↑/↓/Enter
- 前置条件：焦点在菜单栏；正文输入焦点不被劫持（焦点在正文时键盘事件不进菜单）
- 操作：`menu:state-machine` 键盘侧——←/→ 切换根菜单并保持一级展开；↑/↓ 在可见项间移动激活态；含子菜单项按 →/Enter 展开子菜单并移入首项；按 ←/Esc 从子菜单收拢回一级（菜单不关闭）
- 期望数据：焦点模型 `{ level: 'root'|'menu'|'submenu', activeIndex, items: MenuItem[] }`（item 含 id/label/shortcut/disabled/submenu）
- 状态更新：局部更新（仅激活态类名切换），无布局位移

**2. Enter 执行与禁用项语义**
- 来源：[ac.md#AC-RULE-09](../../requirement/ac.md#22-操作与交互规则) / [menu-tree.md#05-交互与失败通则](../../requirement/prd/menu-tree.md#05-交互与失败通则适用全部交互节点)
- 触发：激活某菜单项后按 Enter
- 前置条件：该项 precondition 满足（非灰显）
- 操作：经 `menu:<id>` 同一命令注册表执行命令 id（与点击完全等效，AC-RULE-09 同源）
- 期望效果：执行结果、toast 文案（如有）、禁用规则与鼠标路径完全一致；禁用项 Enter 不执行、不弹报错
- 状态更新：按命令语义局部更新（如切换主题仅主题 token 翻值）

**3. Esc/外点关闭与焦点回正文（AC-FN-10）**
- 来源：[ac.md#AC-FN-10](../../requirement/ac.md#32-顶部菜单栏prd-62)
- 触发：按 Esc 或点击菜单外区域（每次验证单一触发）
- 操作：菜单状态机收拢至关闭态（含子菜单）
- 期望效果：焦点回编辑器正文，随后键盘输入直接进入正文编辑，不被菜单拦截

### 异常场景

| 场景 | 处理 | 提示文案 |
|------|------|---------|
| 焦点在正文时按方向键/Enter | 不劫持正文输入（键盘事件仅菜单聚焦时生效） | 无 |
| 激活项为禁用项时按 Enter | 不执行、不报错（灰显即语义） | 无 |
| 空子菜单（理论态） | 不展开，保持一级 | 无 |
| 快速连续按键（连发 ↑/↓） | 激活态跟手不闪烁，无越界异常 | 无 |
