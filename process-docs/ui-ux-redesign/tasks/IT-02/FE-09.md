# FE-09 - 折叠记忆口径统一（headingFolds 跨重启持久 + 失效清洗 + 不写正文收口）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_05_sidebar.html`

> 来源：[NAV-sidebar.md#33-折叠态会话记忆nav-fold-session-memory](../../design/api/NAV-sidebar.md#33-折叠态会话记忆nav-fold-session-memory) / [grill-rulings.md Q10](../../design/adr/grill-rulings.md#左导航与存储q9q10--pend-08091415) / [ac.md#AC-RULE-14](../../requirement/ac.md#22-操作与交互规则)

收口折叠记忆口径为**跨重启持久**（Q10：折叠态继续用 `veloxmark.session.headingFolds`，localStorage 天然跨重启，**零 schema 变更、不写 .md 正文**）：统一文档/代码注释中「会话内 vs 跨重启」分歧表述；核对标签页切换后与重启后折叠保持（AC-FN-25）；标题删除/改名后失效 key 被 `useFoldSync` 签名门控清洗（防抖写回）；折叠粒度含全部子章节、标题行保留、双向同步保持（AC-FN-15/AC-FN-30）；sanitizer 值须 `string[]`、脏数据丢弃不抛错（AC-NF-14 向后兼容，新键缺失按默认值降级）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 正文区 | 标题折叠三角（既有） | Icon | 标题行左侧 | 指向随折叠/展开切换（UI-IXD-06） | 按 headingFolds 持久态 | 点击切换折叠：子章节隐藏、标题行保留 |
| 大纲面板 | 节点折叠态（双向同步） | Icon | 节点行左侧 | 同正文三角语义 | 与正文一致 | 任一入口变更即同步另一处 |
| 存储层 | `veloxmark.session.headingFolds` | localStorage | `Record<filePath, string[]>` | foldKey = `level:text`（`editor/livePreview/fold.ts` 既有格式） | 既有键形状不变 | 折叠/展开增删 foldKey；标题改名后失效 key 清洗 |
| 清洗态 | useFoldSync 失效 key 清理 | State | — | 签名门控写回 + 防抖 | — | 标题删除/改名后自动移除失效 key |

### 交互操作

**1. 折叠并跨重启验证（AC-FN-25）**
- 来源：[NAV-sidebar.md#33-折叠态会话记忆](../../design/api/NAV-sidebar.md#33-折叠态会话记忆nav-fold-session-memory) / [ac.md#AC-FN-25](../../requirement/ac.md#33-左侧导航栏prd-63)
- 触发：点击标题折叠三角折叠某章节 → 切换标签页再切回 → 关闭并重启应用
- 前置条件：折叠态已写入本地偏好键
- 操作：`useFoldSync` 写回 `headingFolds[filePath]`（foldKey 集合）；重启后读同一键恢复折叠装饰
- 期望数据：`headingFolds: { 'D:/notes/a.md': ['2:第一章', '3:小节'] }`
- 状态更新：局部更新（装饰折叠），.md 正文逐字节一致（AC-FN-25-2）
- 期望效果：标签切换后与重启后折叠均保持

**2. 折叠粒度与双向同步（AC-FN-15/AC-FN-30）**
- 来源：[NAV-sidebar.md#34-折叠双向同步](../../design/api/NAV-sidebar.md#34-折叠双向同步nav-fold-bidirectional复用) / [ac.md#AC-FN-15](../../requirement/ac.md#34-渲染区prd-64)
- 触发：正文侧点折叠三角 / 大纲侧点折叠入口（每次验证单一入口）
- 操作：折叠含全部子章节、标题行保留；任一入口变更即更新另一处视图
- 期望效果：大纲一致、跨重启保持、.md 无字节变化；三角指向随态切换（UI-IXD-06）

**3. 失效 key 清洗**
- 来源：[NAV-sidebar.md#33-失效清洗](../../design/api/NAV-sidebar.md#33-折叠态会话记忆nav-fold-session-memory) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)
- 触发：删除/改名一个已折叠标题
- 操作：`useFoldSync` 签名门控写回（防抖），移除失效 foldKey；sanitizer 校验值须 `string[]`，脏数据丢弃不抛错
- 期望效果：存储无脏 key 残留；其余折叠不变

### 异常场景

| 场景 | 处理 | 提示文案 |
|------|------|---------|
| headingFolds 含脏数据（非 string[]） | sanitizer 丢弃不抛错，按默认值降级（AC-NF-14） | 无 |
| 旧版本键位缺失 | 默认值降级读取，不报错（AC-NF-14） | 无 |
| 标题改名后旧 foldKey 失效 | useFoldSync 清洗移除 | 无 |
| 折叠操作（轻量态） | 不回 toast（PEND-15） | 无 |
