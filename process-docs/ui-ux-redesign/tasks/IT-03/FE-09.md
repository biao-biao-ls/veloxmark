# FE-09 - 点击语义固化与纯选中保护（点击进编辑 / 拖选复制不弹 chrome）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_06_render_zone.html`（交互规则卡「点击语义裁决：内容点击进入编辑 · 拖选/选区后松开=选中复制不弹 chrome · 图/表/代码相邻处点击语义一致」）、`../../../../docs/requirements/ui-ux-redesign/ui/ui_01_main_quiet.html`（静息零 chrome 基线）

> 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-click:semantics`（AC-RULE-13 裁决固化）

将分散在表格/块/图片各处的点击处理收口为统一语义：点击元素内容进入该元素对应编辑形态（写作者路径优先）；纯选中/复制是安全动作，拖选文本松开不进入编辑、不弹任何工具浮层；图/表/代码相邻处点击语义一致（不弹与被点击元素无关的浮层）。既有逐处 stopPropagation 维持方式收敛为统一判定 + 非回归断言。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 普通文本区 | 段落内容 | 可点击内容 | 正文列内 | 正文 token | 静息渲染态 | 点击进入文本编辑（光标落点击位） |
| 表格区 | 单元格内容/表内空白 | 可点击内容 | 正文列内表格 | 既有表格样式 | 静息/hover | 点击进入表格编辑形态（既有 AC-FN-03 语义不回归） |
| 公式/代码/图区 | 块内容 | 可点击内容 | 正文列内 | 既有块 chrome | 静息渲染态 | 点击进入对应源码/编辑形态（公式/代码/mermaid 双区；图=编辑浮层） |
| 全渲染区 | 文本选区 | 选择行为 | 任意文本 | 选区高亮 | 无选区 | 拖选松开仅高亮 + 剪贴板得文本，不弹 chrome |
| 元素相邻处 | 命中边界 | 语义判定 | 图/表/代码相邻地带 | — | 静息 | 点击语义一致，无无关浮层 |

### 交互操作

> 更新模式：全部交互为局部更新（CM6 Decoration/单事务替换 + autosave 局部落盘），无整页刷新。

**1. 点击内容进编辑（写作者路径）**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-click:semantics`
- 触发：点击普通文本/表格内容/公式/代码/图内容（每次验证单一元素）
- 前置条件：界面静息或 hover 态
- 操作：统一点击判定路由（契约面 = `ren-click:semantics`，关键参数 = `hitTarget` 元素类型、`selection.isEmpty`）
- 期望效果：普通文本进文本编辑；表格进表格编辑形态；公式/代码/图进对应源码/编辑形态（AC-FN-17 判据 1-3）；全部路径不弹出与被点击元素无关的工具浮层（AC-FN-17 判据 4 / AC-RULE-13）
- 空态处理：点击未命中任何元素的正文空白走既有「一键回安静」语义（不属本条）

**2. 纯选中/复制保护**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-click:semantics`
- 触发：鼠标拖选一段文本后松开并复制
- 前置条件：渲染区静息态
- 操作：选区事件判定（`selection` 非空 → 不触发编辑路由）
- 期望效果：仅出现选区高亮；剪贴板得到所选文本；不进入任何编辑态、不浮现工具浮层/把手/chip（AC-FN-18 全判据）
- 空态处理：无

**3. 相邻处语义一致性回归**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互)
- 触发：在图/表/代码相邻区域反复点击
- 前置条件：文档含普通文本、表格、公式、图、代码块相邻区域
- 操作：逐元素点击断言（AC-RULE-13 判据 3）
- 期望效果：各元素点击语义一致（内容点击进对应编辑形态）；浮层绝不与编辑态抢事件（ui_06 规则卡）；同一次点击只产生一种语义
- 空态处理：无
