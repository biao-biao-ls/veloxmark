# FE-07 - 标题折叠/展开（含全部子章节 + 大纲双向同步 + 复用 headingFolds）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_06_render_zone.html`（区块 D 标题折叠：展开态/折叠态/折叠占位行）

> 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [prd.md#63-左侧导航栏](../../requirement/prd/PRD.md#63-左侧导航栏) / 契约 `ren-head:fold`（Q10：复用 headingFolds）

标题折叠能力已有基础实现（`fold.ts` 三角 + `headingFolds` + `useFoldSync`），本任务收口三件事：① 折叠粒度=该标题下**全部子章节**内容折叠隐藏、标题行保留；② 与大纲折叠**双向同步**（正文侧三角 ⇄ 大纲侧折叠入口，任一入口变更即更新另一处视图）；③ 折叠态跨重启持久 + `.md` 零字节变化的验收闭环（含标签切换/重启核验路径）。折叠为显示态不进文档 undo 栈，轻量切换不回 toast（PEND-15）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 标题行（ui_06 区块 D） | 折叠三角 | 折叠入口（fold-caret ▾/▸） | 标题文字左侧 | title「折叠本节/展开本节」（FE-01 i18n key）；指向随态切换 | 展开态 ▾ | 点击折叠 ▸ / 再点展开 ▾；点击只折叠、不移动光标 |
| 标题行 | 标题文字 | 标题（md-h2/md-h3） | 正文列内 | 标题字号 token | 按 .md 渲染 | 折叠后标题行保留可见 |
| 标题行下方 | 折叠占位行 | 灰字单行（fold-collapsed-line） | 折叠标题下 | 灰字 token，形如「（4 行内容已折叠 · 与大纲双向同步）」 | 折叠态才出现 | 展开后消失 |
| 章节内容区 | fold-body 子章节组 | 内容隐藏区 | 标题下至下一平级标题前 | — | 展开态可见 | 折叠态整体隐藏（含全部子标题与内容） |
| 侧栏大纲 | 大纲节点折叠入口 | 折叠三角（Outline.tsx） | 大纲节点行首 | 与正文三角同 token 观感 | 与正文折叠态镜像 | 点击即同步正文折叠/展开（双向） |

### 交互操作

> 更新模式：全部交互为局部更新（CM6 Decoration/单事务替换 + autosave 局部落盘），无整页刷新。

**1. 正文侧折叠/展开**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-head:fold`
- 触发：点击标题左侧折叠三角
- 前置条件：标题下含子章节内容
- 操作：折叠状态机切换 + `headingFolds` 写回（关键参数 = `foldKey`（`level:text`）、`filePath`；契约面 = `veloxmark.session.headingFolds` 复用）
- 期望效果：该标题下全部子章节内容折叠隐藏、标题行保留（AC-FN-15 判据 1）；三角指向切换（UI-IXD-06）；点击三角不移动光标；不回 toast；`.md` 正文零字节变化
- 空态处理：标题下无内容/子章节时不渲染折叠三角

**2. 大纲双向同步**
- 来源：[prd.md#63-左侧导航栏](../../requirement/prd/PRD.md#63-左侧导航栏) / [prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互)
- 触发：大纲侧点击某章节节点折叠/展开入口，或正文侧点击三角
- 前置条件：大纲面板展开，文档含多级标题
- 操作：`useFoldSync` 状态镜像（契约面 = `ren-head:fold` + NAV §3.4 共同契约）
- 期望效果：任一入口变更即更新另一处视图（AC-FN-30 判据 1）；折叠状态写本地偏好键、跨重启持久（AC-FN-30 判据 2）；`.md` 无任何字节变化（AC-FN-30 判据 3）
- 空态处理：大纲为空文档时无入口

**3. 持久化恢复（标签切换/重启）**
- 来源：[prd.md#7-关联与影响m10](../../requirement/prd/PRD.md#7-关联与影响m10) / 契约 `session:headingFolds`
- 触发：折叠某章节后切换标签页再切回，随后关闭并重启应用
- 前置条件：折叠态已写 `veloxmark.session.headingFolds`
- 操作：读出恢复（`restoreFolds` 既有路径）
- 期望效果：折叠状态在标签切换后与重启后均保持（AC-FN-15 判据 3）；`.md` 正文与折叠前逐字节一致（AC-RULE-14）
- 空态处理：旧 session 缺 headingFolds 键时按 `{}` 降级（既有 sanitizer 保证）
