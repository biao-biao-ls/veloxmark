# FE-05 - 链接 hover 浮层（编辑 URL 写回 .md / 外开 / 复制完整 URL）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_06_render_zone.html`（区块 B 链接 hover 浮层）

> 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构) / 契约 `ren-link:hover-float` + `ren-link:edit-url`

新增链接 hover 浮层：hover 链接 ≥150ms（FE-03 基座）浮现浮层，含 URL 展示框与「编辑 URL / 外开 / 复制」三入口；编辑 URL 写回 `.md` 链接语法为独立 undo 事务；外开只走 `shell.openExternal` 固定入口不传用户可控串；复制为完整 URL（含协议与路径）。浮层不遮挡链接文本。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 链接区（ui_06 区块 B） | 链接文本 | Widget（md-link） | 正文列内行内 | accent 链接色 token + 下划线 | 按 .md 链接语法渲染 | URL 编辑后按新 URL 渲染、文案不变 |
| 链接区 | 浮层 URL 展示框 | 文本框（url-box） | 浮层首行，贴链接下方 | 浮层表面 token、等宽小字 | 显示完整 URL | 编辑态变为可输入 input、原 URL 预填 |
| 链接区 | 编辑 URL 按钮 | Button（pop-btn is-primary） | 浮层按钮行第 1 枚 | ✎ 编辑 URL（FE-01 i18n key），primary 强调 | 可点击 | 点击进入输入态，按钮变「确认/取消」 |
| 链接区 | 外开按钮 | Button（pop-btn） | 浮层按钮行第 2 枚 | ↗ 外开 | 可点击 | 点击经 shell.openExternal 打开当前 URL |
| 链接区 | 复制按钮 | Button（pop-btn） | 浮层按钮行第 3 枚 | ⧉ 复制 | 可点击 | 点击剪贴板得完整 URL |
| 链接区 | 浮层本体 | 浮层（link-pop） | 贴链接下方，不遮挡链接文本 | 浮层表面/边框 token | 静息不渲染 | hover ≥150ms 浮现；移出延迟消失无残留 |

### 交互操作

> 更新模式：全部交互为局部更新（CM6 Decoration/单事务替换 + autosave 局部落盘），无整页刷新。

**1. 外开与复制**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#10-异常处理](../../design/tech-design.md#10-异常处理)
- 触发：浮层中点击「外开」或「复制」
- 前置条件：浮层已浮现，URL 非空
- 操作：外开 = `window.api` 既有外开通道（`shell.openExternal` 固定入口，不拼接、不传用户可控串）；复制 = 剪贴板写入完整 URL（契约面 = `ren-link:hover-float`，关键参数 = `url: string` 原样）
- 期望效果：外开经系统默认浏览器打开该 URL、无 toast（AC-FN-19 判据 1）；复制后剪贴板内容为完整 URL 含协议与路径（AC-FN-19 判据 2）；contextIsolation/sandbox 保持开启（AC-NF-12）
- 空态处理：空 URL 链接不渲染外开/复制入口或按钮灰显

**2. 编辑 URL 写回**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-link:edit-url`
- 触发：点「编辑 URL」→ 输入新 URL → 确认
- 前置条件：浮层已浮现；文件非只读
- 操作：`.md` 链接语法写回（契约面 = `ren-link:edit-url`，关键参数 = `text` 不变、`href` 新值）
- 期望数据（写回字段结构示例）：`[设计规范文档](https://example.com/design-spec)` → `[设计规范文档](https://example.com/v2-spec)`（仅 href 替换，锚文本不动）
- Loading 状态：确认按钮同步执行无网络；确认后浮层回展示态
- 期望效果：链接按新 URL 渲染；toast「已更新链接地址（Ctrl+Z 可撤销）」；autosave 落盘；一次 Ctrl+Z 还原修改前 URL；后续「外开」对新 URL 生效（AC-OP-14）
- 空态处理：输入空/非法 URL 时校验拒绝、保留输入内容、`.md` 不变

**3. 只读拦截与退出**
- 来源：[tech-design.md#10-异常处理](../../design/tech-design.md#10-异常处理)
- 触发：只读文件上确认 URL 编辑；或移出链接/点外部
- 前置条件：浮层已浮现
- 操作：只读路径全局拦截；退出路径走 FE-03 基座 hide
- 期望效果：只读时拦截不写入、toast「文件为只读，无法修改，可另存后编辑」（AC-ERR-08）；退出后浮层无残留、不遮挡链接文本（UI-IXD-07）
- 空态处理：无
