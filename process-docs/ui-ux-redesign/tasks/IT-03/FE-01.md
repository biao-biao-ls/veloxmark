# FE-01 - 渲染区文案与样式 token 基建（i18n 双字典回执键 + 浮层/折叠样式分区）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_06_render_zone.html`、`../../../../docs/requirements/ui-ux-redesign/ui/ui_01_main_quiet.html`

> 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构)

为期 4 渲染区全部浮层/折叠/微操作交付统一的文案键与观感 token 底座：i18n 回执键（含「（Ctrl+Z 可撤销）」后缀格式）双字典一次落齐，样式分区只引用 token 不写裸值。本任务不实现任何交互行为本身，只交付后续 FE-03~FE-10 共用的文案与样式契约。

### 页面元素

> 按区域拆分，覆盖设计稿中本任务交付的可交互文案与观感元素。每个元素描述完整 6 项属性。

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 图片编辑浮层（ui_06 区块 A） | 尺寸/对齐回执 toast 文案键 | i18n key | 浮层操作完成后 toast 区 | zh：「已调整图片尺寸（Ctrl+Z 可撤销）」「已设置图片对齐（Ctrl+Z 可撤销）」；en 对应「Image size adjusted (Ctrl+Z to undo)」「Image alignment set (Ctrl+Z to undo)」 | 未触发不显示 | 每次尺寸/对齐编辑后显示 5s 自动消失 |
| 图片编辑浮层（ui_06 区块 A） | 对齐三键与完成按钮文案/提示 | i18n key | 图下方浮动工具条 | 「左对齐」「居中」「右对齐」「宽度」「完成」双语；title 提示双语 | 工具条隐藏 | 对齐键激活态文案不变、仅样式翻转 |
| 链接 hover 浮层（ui_06 区块 B） | 三入口按钮文案键 | i18n key | 浮层内横排按钮 | zh：「编辑 URL」「外开」「复制」；en：「Edit URL」「Open」「Copy」；URL 编辑回执 zh「已更新链接地址（Ctrl+Z 可撤销）」 | 浮层隐藏 | 编辑态显示输入框 placeholder「请输入链接地址」 |
| 列表与任务项（ui_06 区块 C） | 把手/勾选回执文案键 | i18n key | 操作后 toast 区 | zh：「已移动列表项（Ctrl+Z 可撤销）」；任务勾选无回执（PEND-15 显式豁免，登记差异声明于 i18n 注释） | 未触发不显示 | 拖拽落位后显示；勾选不显示 |
| 标题折叠（ui_06 区块 D）/长引用折叠（ui_06 区块 E） | 折叠入口提示与摘要行尾标 | i18n key | 三角 title 与摘要行尾部 | 「折叠本节」「展开本节」「N 行」「展开还原」双语 | 展开态显示「折叠本节」 | 折叠态切换为「展开本节」/「N 行」尾标 |
| 浮层/折叠/把手/指示线全量 | 观感 token 组 | CSS token | `styles/tokens.css` `:root` 唯一声明点 | 新增 `--space-*`/`--radius-*`/`--color-*` token：浮层表面色、浮层边框、把手 accent、指示线、摘要行灰字、折叠三角过渡时长（≥150ms 防抖动画基值） | 深浅主题由 `.theme-light`/`.theme-dark` 翻值 | 零 `.theme-dark` 选择器补丁、零裸 px/色值 |

### 交互操作

> 更新模式：全部交互为局部更新（CM6 Decoration/单事务替换 + autosave 局部落盘），无整页刷新。

**1. 回执文案渲染（i18n key 消费契约）**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构)
- 触发：后续任务（FE-04/FE-05/FE-06）的 toast 回执调用 `t('render.toast.imageSize')` 等 key
- 前置条件：语言为 en 或 zh 之一
- 操作：渲染层 i18n 查询（无 HTTP；桌面适配：契约面 = i18n 字典 key 集合）
- Loading 状态：无（同步查表）
- 期望效果：`t()` 返回对应语言完整文案，含「（Ctrl+Z 可撤销）」后缀（en 为 "(Ctrl+Z to undo)"）；key 集合示例 `render.toast.imageSize` / `render.toast.imageAlign` / `render.toast.linkUpdated` / `render.toast.listMoved`，后缀由单一常量拼装而非每键重复硬编码
- 空态处理：缺失 key 时 `i18n/index.ts` 既有降级路径显示 key 字符串，单测断言不允许出现（key 全量登记）

**2. 双字典一致性校验**
- 来源：[prd.md#7-关联与影响m10](../../requirement/prd/PRD.md#7-关联与影响m10)
- 触发：`npm run test:unit` 执行 `i18n/i18n.test.ts`
- 前置条件：en.ts 与 zh.ts 已同步编辑
- 操作：纯函数断言（无 HTTP；校验面 = 两字典 key 集合对称差为空）
- 期望效果：任何一侧新增 key 而另一侧缺失时测试失败；新增 `render.*` 命名空间 key 全部在两侧有值
- 空态处理：无

**3. 样式分区 token 引用约束**
- 来源：[tech-design.md#112-参数化设计](../../design/tech-design.md#112-参数化设计)
- 触发：新增 `src/renderer/src/styles/render-zone.css` 并在既有样式聚合入口引入
- 前置条件：token 已在 `styles/tokens.css` `:root` 声明
- 操作：CSS 编写（无 HTTP；约束面 = 仅 token 引用）
- 期望效果：新分区样式仅使用 `var(--space-*)`/`var(--radius-*)`/`var(--color-*)` 取值；深浅主题差异只在 `.theme-light`/`.theme-dark` 翻 token 值
- 空态处理：无
