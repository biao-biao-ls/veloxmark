# FE-04 - 图片编辑浮层（尺寸拖拽/对齐按钮写 .md 图片语法 + undo + 回执）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_06_render_zone.html`（区块 A 图片编辑浮层）

> 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构) / 契约 `ren-image:edit-float` + `ren-image:write-md`

新增图片编辑浮层：hover/点击图片按需浮现（显隐走 FE-03 基座），右下角尺寸控制点拖拽改尺寸、对齐三键（◧▣◨）与宽度下拉改对齐/宽度，尺寸与对齐一律写 `.md` 图片语法（非显示态旁路），每次编辑为独立 undo 事务，toast 回执含「（Ctrl+Z 可撤销）」后缀。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 图片区（ui_06 区块 A） | 图片渲染体 | Widget（image-widget） | 正文列内，宽高随语法 | 按 .md 图片语法渲染 | 按源码尺寸 | 拖拽松开后按新尺寸渲染 |
| 图片区 | 尺寸拖拽角柄 | 控制点（img-resize-handle） | 图片右下角，绝对定位小方块 | accent token 描边，title「拖拽调整尺寸」 | 仅浮层激活/hover 态渲染 | 拖拽中预览尺寸随鼠标变化；松开落盘 |
| 图片区 | 图片浮动工具条 | 浮层（img-toolbar） | 图下方贴附，绝对定位 | 浮层表面 token；按钮：◧ 左对齐 / ▣ 居中 / ◨ 右对齐、宽度下拉「宽度 60%」、分隔线、✓ 完成 | 隐藏；hover/点击图片浮现 | 对齐键激活态高亮当前对齐；完成/点外部退出无残留 |

### 交互操作

> 更新模式：全部交互为局部更新（CM6 Decoration/单事务替换 + autosave 局部落盘），无整页刷新。

**1. 尺寸拖拽编辑**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构)
- 触发：按住尺寸角柄拖拽到新尺寸后松开
- 前置条件：图片编辑浮层已浮现；文件非只读
- 操作：`.md` 图片语法写回（非显示态旁路；契约面 = `ren-image:write-md`，关键参数 = `src`、`width/height` 新值、`align` 不变）
- 期望数据（写回字段结构示例）：`![cover.png](./cover.png =60%x*)` 或既有 markdown-image-ext 尺寸语法等价值——新尺寸落源码、对齐字段不变
- Loading 状态：拖拽中图片预览尺寸连续跟随鼠标；无网络请求
- 期望效果：松开后按新尺寸渲染；toast「已调整图片尺寸（Ctrl+Z 可撤销）」；autosave 落盘；一次 Ctrl+Z 还原编辑前尺寸（AC-OP-13 拖拽分支）
- 空态处理：无图片解析结果时浮层不浮现

**2. 对齐调整**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-image:write-md`
- 触发：点击浮层对齐三键中目标键（或宽度下拉选项）
- 前置条件：浮层已浮现；文件非只读
- 操作：`.md` 图片语法写回（关键参数 = `align: 'left'|'center'|'right'`、`width` 不变）
- 期望数据（写回字段结构示例）：对齐落图片语法标记（如 `<div align="center">` 包裹或扩展语法 align 字段，与 `markdown-image-ext.ts` 既有语法口径一致）
- Loading 状态：无（同步写回）
- 期望效果：按钮进入激活态；图片按目标对齐渲染、尺寸不变；toast「已设置图片对齐（Ctrl+Z 可撤销）」；一次 Ctrl+Z 还原（AC-OP-13 对齐分支）
- 空态处理：无

**3. 浮层退出与只读拦截**
- 来源：[tech-design.md#10-异常处理](../../design/tech-design.md#10-异常处理) / [prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互)
- 触发：点「完成」/点浮层外部区域；或只读文件上尝试尺寸/对齐编辑
- 前置条件：浮层已浮现
- 操作：退出收拢（无写入）；只读路径走全局拦截（契约面 = `ren-image:edit-float` 禁用规则）
- 期望效果：退出后无残留控件、正文位移 0px；只读时操作被拦截不产生半提交、toast「文件为只读，无法修改，可另存后编辑」（AC-ERR-08）；「另存为」副本上可正常写入并 autosave
- 空态处理：无
