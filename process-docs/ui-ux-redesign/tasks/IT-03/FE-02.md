# FE-02 - SessionState.quoteFolds 字段与 sanitizer 白名单扩展（含 store.test 用例）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_06_render_zone.html`（区块 E 长引用折叠「折叠态不写入 .md 正文」旁注）

> 来源：[prd.md#7-关联与影响m10](../../requirement/prd/PRD.md#7-关联与影响m10) / [tech-design.md#6-数据库设计](../../design/tech-design.md#6-数据库设计) / 裁决 Q10（grill-rulings.md 双键平铺追加）

按 Q10 裁决在 `veloxmark.session` 顶层平铺追加 `quoteFolds: Record<filePath, string[]>`，承载长引用折叠块 id 集；同步扩展 `normalizeSession` 逐字段白名单与 `DEFAULT_SESSION` 默认值，补齐 `store.test.ts` sanitizer 用例。不改任何既有字段形状，旧存盘 JSON 缺键按 `{}` 降级读取。

### 页面元素

> 存储契约任务：元素为用户可感知的持久化行为载体（长引用折叠态跨重启保持）。

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 长引用折叠（ui_06 区块 E） | 折叠态持久记忆 | localStorage 字段 `veloxmark.session.quoteFolds` | 无 UI 呈现（存储面） | JSON 平铺字段，camelCase | `{}`（旧 JSON 缺键降级） | 用户折叠/展开长引用块时该文档条目数组增删块 id |
| 长引用折叠（ui_06 区块 E） | 跨重启折叠保持 | 读出恢复行为 | 重启后正文区引用块 | 折叠块恢复为摘要行；展开块完整渲染 | 文档载入时读取该 filePath 条目 | 标签切换/重启后保持（AC-RULE-14） |

### 交互操作

> 更新模式：全部交互为局部更新（CM6 Decoration/单事务替换 + autosave 局部落盘），无整页刷新。

**1. quoteFolds 写入（折叠/展开触发）**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#6-数据库设计](../../design/tech-design.md#6-数据库设计)
- 触发：用户折叠/展开长引用块（消费方 FE-08 接入后）
- 前置条件：当前文档路径已知，session store 可写
- 操作：store 单一写入口 patch（无 HTTP；契约面 = `veloxmark.session`，关键参数 = `filePath: string`、`blockIds: string[]`）
- 期望数据（字段结构示例）：`quoteFolds: { "/d/docs/a.md": ["q:12:3", "q:40:8"] }`——键为文档绝对路径，值为该文档已折叠引用块 id 数组
- 期望效果：localStorage `veloxmark.session` 中该文件条目更新；既有键位（headingFolds/tableColWidths/openTabs 等）逐字节语义不变；写回沿用 `useFoldSync` 同款签名门控 + 防抖纪律
- 空态处理：展开最后一个折叠块后条目成为空数组，按 headingFolds 现行口径剪除或保留（行为由 store.test 钉住）

**2. 脏数据降级读取（sanitizer）**
- 来源：[tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则) / [prd.md#10-非功能需求m13](../../requirement/prd/PRD.md#10-非功能需求m13)
- 触发：应用启动 / session 读取
- 前置条件：localStorage 存在被污染的 `veloxmark.session` JSON
- 操作：`normalizeSession` 白名单过滤（无 HTTP；关键参数 = raw JSON 任意形状）
- 期望数据（校验规则）：顶层非对象 → 丢弃为 `{}`；条目键非空 string 否则丢弃该条；值非 Array → 整条丢弃；元素非 string → 丢弃该元素
- 期望效果：任何脏数据降级为缺省/丢弃、不抛错、不阻塞启动（AC-NF-14-3）
- 空态处理：缺键时 `DEFAULT_SESSION.quoteFolds = {}` 降级

### 涉及文件

| 文件路径 | 修改内容 |
|---------|---------|
| `src/renderer/src/preferences/store.ts` | `SessionState` 接口追加 `quoteFolds: Record<string, string[]>`；`DEFAULT_SESSION` 补 `quoteFolds: {}`；`normalizeSession` 白名单逐字段扩展 quoteFolds（沿用 headingFolds 同款逐文件过滤：键非空 string、值 Array、元素仅 string，脏数据丢弃不抛错） |
| `src/renderer/src/preferences/store.test.ts` | 追加 quoteFolds sanitizer 用例（沿用 headingFolds 既有用例风格）：合法值透传、非对象/非数组/非 string 元素丢弃、缺键默认 `{}`、脏数据不抛错、既有键位不受影响 |
