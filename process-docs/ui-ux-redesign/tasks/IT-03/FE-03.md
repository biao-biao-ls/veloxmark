# FE-03 - hover 浮层/微操作防抖基座与退出纪律（≥150ms、不遮挡、位移 0px、无残留）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_06_render_zone.html`（交互规则卡 + 设计标注面板「hover 防抖 ≥150ms，快速划过不闪烁」「不遮挡正文锚点内容」「零布局抖动（位移 0px）」）、`../../../../docs/requirements/ui-ux-redesign/ui/ui_01_main_quiet.html`（静息零 chrome 基线）

> 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#43-块级-chrome-四态mermaid-state-diagram-v2](../../design/tech-design.md#43-块级-chrome-四态mermaid-state-diagram-v2)

交付渲染区全部 hover 控件（图片浮层、链接浮层、列表把手、任务项微操作）共用的防抖显隐基座：浮现/消失双向防抖 ≥150ms、浮层贴附锚点不遮挡正文、绝对定位覆盖层零布局位移、移出无残留。FE-04/FE-05/FE-06 的控件显隐全部接入本基座，禁止各自手写 setTimeout。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 图片编辑浮层（ui_06 区块 A） | 浮层显隐通道 | 基座状态机 | 图片锚点旁侧/下方，绝对定位覆盖层 | 涌现过渡用 FE-01 防抖过渡时长 token | 静息不渲染 | hover ≥150ms 浮现；移出延迟消失；快速掠过 0 闪现 |
| 链接 hover 浮层（ui_06 区块 B） | 浮层显隐通道 | 基座状态机 | 贴链接下方，不遮挡链接文本 | 涌现过渡用 FE-01 防抖过渡时长 token | 静息不渲染 | hover ≥150ms 浮现；移出延迟消失；快速掠过 0 闪现 |
| 列表与任务项（ui_06 区块 C） | 行首拖拽把手显隐 | 基座状态机 | 行首左侧，accent 色圆角小块（⠿） | accent token 圆角小块，行底 `--bg-inset` 示意 | 静息不渲染（`is-idle` aria-hidden） | 仅 hover 行首浮现，不常驻不遮挡正文 |
| 全正文区 | 位移/残留守护 | 覆盖层约束 | 全浮层/把手/指示线 | 绝对定位，不占文档流 | 正文位置不动 | 显隐前后正文水平/垂直位移 0px；退出后零残留 DOM/半透明遮罩 |

### 交互操作

> 更新模式：全部交互为局部更新（CM6 Decoration/单事务替换 + autosave 局部落盘），无整页刷新。

**1. 防抖浮现（进入方向）**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#43-块级-chrome-四态mermaid-state-diagram-v2](../../design/tech-design.md#43-块级-chrome-四态mermaid-state-diagram-v2)
- 触发：鼠标进入图片/链接/列表行元素命中区
- 前置条件：界面处于静息态，无浮层常驻
- 操作：基座 `show` 请求进入防抖队列（无 HTTP；契约面 = `ren-hover:discipline`，关键参数 = `anchorEl`、`delayMs ≥ 150`）
- Loading 状态：防抖窗口内无任何视觉反馈（不闪现）
- 期望效果：停留 ≥150ms 后对应浮层/把手浮现；浮现期间不遮挡被 hover 元素正文文字（AC-FN-14 判据 2）
- 空态处理：无图片解析结果时图片浮层不浮现（REN §3.1 禁用规则）

**2. 防抖消失（离开方向）**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#43-块级-chrome-四态mermaid-state-diagram-v2](../../design/tech-design.md#43-块级-chrome-四态mermaid-state-diagram-v2)
- 触发：鼠标移出元素命中区（或移入浮层自身可交互区时挂起消失）
- 前置条件：浮层/把手已浮现
- 操作：基座 `hide` 请求进入防抖队列（无 HTTP；契约面 = `ren-hover:discipline`）
- 期望效果：控件延迟消失、无残留（AC-FN-14 判据 4）；鼠标在元素与浮层之间移动不闪烁关闭
- 空态处理：无

**3. 零布局抖动验证**
- 来源：[prd.md#10-非功能需求m13](../../requirement/prd/PRD.md#10-非功能需求m13) / [tech-design.md#10-异常处理](../../design/tech-design.md#10-异常处理)
- 触发：浮层/把手反复出入
- 前置条件：文档含图片/链接/列表混合内容
- 操作：测量正文区域 boundingClientRect 前后差值（无 HTTP；判定面 = AC-NF-05）
- 期望效果：垂直位移 0px、水平位移 0px；快速掠过多个块级元素期间闪烁次数 0（AC-NF-04）
- 空态处理：无
