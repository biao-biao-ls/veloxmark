# FE-08 - 长引用折叠（useQuoteFold + 摘要行 + quoteFolds 读写，阈值 >5 行）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_06_render_zone.html`（区块 E 长引用折叠：展开态/折叠态/「展开还原」入口）

> 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-quote:fold` + `ren-quote:store`（PEND-09/Q10 裁决）

新增长引用折叠：渲染行数 **>5 行**的引用块出现折叠入口（阈值常量集中一处便于调参），折叠后呈**摘要行**（首行文本截断 + 「N 行」尾标，N=折叠隐藏行数），点击摘要行/「展开还原」入口还原完整内容无字节差异；折叠块 id 集写 `veloxmark.session.quoteFolds`（FE-02 字段），跨重启持久；`.md` 正文零字节变化、不回 toast（PEND-15）。摘要行构成细则以「可折叠、可展开、内容不丢失」为判定（AC-FN-16 观感豁免）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 引用块（ui_06 区块 E） | 引用块本体 | 块（md-quote） | 正文列内，左侧缩进竖线 | 引用竖线/背景 token | ≤5 行整块渲染；>5 行可折叠 | 折叠态隐藏原文，展开态完整渲染 |
| 引用块 | 折叠入口 | 折叠入口（fold-caret ▾） | 引用块右上/摘要行左侧 | title「折叠本节」（FE-01 i18n key） | >5 行才渲染 | 点击折为摘要行 |
| 引用块 | 摘要行 | 单行（quote-summary + 尾标） | 引用块位置原地替换 | 灰字 token：`「首行文本……」` + 「N 行」尾标 | 折叠态才出现 | 点击展开还原 |
| 引用块 | 展开还原入口 | 按钮/链接（quote-restore ▸ 展开还原） | 摘要行右侧 | title「展开还原完整引用」 | 折叠态才出现 | 点击还原完整内容 |
| 存储面 | 折叠块 id 集 | localStorage `quoteFolds[filePath]` | 无 UI | `string[]` | 文档载入时读取恢复折叠态 | 折叠/展开时增删 id |

### 交互操作

> 更新模式：全部交互为局部更新（CM6 Decoration/单事务替换 + autosave 局部落盘），无整页刷新。

**1. 折叠为摘要行**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-quote:fold`
- 触发：点击 >5 行引用块的折叠入口
- 前置条件：引用块渲染行数 >5（阈值常量单一定义点）
- 操作：显示态切换 + quoteFolds 写回（关键参数 = `blockId`、`filePath`；契约面 = `ren-quote:store`）
- 期望效果：原引用内容不可见，呈现单行摘要（首行文本截断 + 「N 行」尾标，AC-FN-16 判据 1 观感豁免口径）；不回 toast；`.md` 零字节变化；块 id 追加进 `quoteFolds[filePath]`（签名门控 + 防抖，沿用 `useFoldSync` 写回纪律）
- 空态处理：≤5 行引用块不渲染折叠入口（阈值边界）

**2. 展开还原**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-quote:fold`
- 触发：点击摘要行或「展开还原」入口
- 前置条件：该引用块处于折叠态
- 操作：显示态还原 + quoteFolds 移除该 `blockId`
- 期望效果：引用内容还原为折叠前完整内容、无字节差异（AC-FN-16 判据 2）；展开为幂等可逆操作（不进文档 undo 栈）
- 空态处理：无

**3. 跨重启恢复**
- 来源：[prd.md#7-关联与影响m10](../../requirement/prd/PRD.md#7-关联与影响m10) / 契约 `session:quoteFolds`
- 触发：文档载入/切换标签/重启应用
- 前置条件：`quoteFolds` 已持久化该文档条目
- 操作：读出恢复（块 id 失配项由 sanitizer/清洗丢弃，不影响其他条目）
- 期望效果：折叠块恢复摘要行、展开块完整渲染；跨重启持久（AC-RULE-14 口径同 headingFolds）；旧版本缺键按 `{}` 降级（AC-NF-14，FE-02 已保证）
- 空态处理：id 失配（文档变化导致）的失效条目静默丢弃
