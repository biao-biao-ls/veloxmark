# FE-06 - 列表行首拖拽排序与任务项勾选（把手按需浮现、层级不变、轻量口径）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_06_render_zone.html`（区块 C 列表与任务项微操作）

> 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构) / 契约 `ren-list:drag-handle` + `ren-task:check`（PEND-15 轻量口径）

两项合一交付：① 列表行首拖拽把手 hover 按需浮现（⠿ accent 圆角小块），按住拖动显示插入位置指示线，落位后同层级顺序调整、缩进层级不变，`.md` 列表源码顺序写回 + toast 回执 + 一步 undo；② 任务项勾选框点击切换 `[ ]`/`[x]` 写回 `.md` 任务语法，行为保持既有实现、口径固化为轻量操作不回 toast（PEND-15 显式豁免）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 列表行（ui_06 区块 C） | 行首拖拽把手 | 拖拽把手（drag-handle ⠿） | 行首左侧，accent 色圆角小块 | accent token 底、title「拖拽排序」 | 静息不渲染（`is-idle` aria-hidden） | 仅 hover 行首浮现；拖动中随鼠标移动 |
| 列表行 | 插入位置指示线 | 指示线 | 拖动目标行间 | accent 色 2px 线（token） | 不可见 | 拖动过程显示目标落位线 |
| 列表行 | 列表项文本 | 文本（li-text） | 把手右侧行内 | 正文 token | 按 .md 渲染 | 落位后顺序变化、文本内容不变 |
| 任务列表（ui_06 区块 C） | 勾选框 | Checkbox（task-box） | 行首把手右侧 | accent 选中态；已勾选显示 ✓、文本 `task-done` 删除线 | 按 .md `[ ]`/`[x]` 渲染 | 点击即时切换两态并回显 |
| 任务列表 | 任务项文本 | 文本（li-text） | 勾选框右侧 | 正文 token / 完成态删除线 | 按源码 | 勾选切换完成态样式 |

### 交互操作

> 更新模式：全部交互为局部更新（CM6 Decoration/单事务替换 + autosave 局部落盘），无整页刷新。

**1. 列表项拖拽排序**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-list:drag-handle`
- 触发：hover 行首浮现把手 → 按住拖动 → 松开落位
- 前置条件：列表项 ≥2 项；文件非只读
- 操作：`.md` 列表源码顺序写回（关键参数 = `fromIndex`、`toIndex`、`indentLevel` 不变）
- 期望数据（写回字段结构示例）：源码行块整体移动，缩进前缀（`-`/`*`/`1.` 与空格数）逐项保持不变，仅行序重排
- Loading 状态：拖动中被拖项随鼠标移动 + 插入指示线；无网络
- 期望效果：落位后同层级顺序调整、层级（缩进）不变；toast「已移动列表项（Ctrl+Z 可撤销）」；autosave 落盘；一次 Ctrl+Z 还原顺序（AC-OP-16）
- 空态处理：单行列表无拖拽意义时把手灰显不可拖（选定行为，自测断言灰显态且拖拽不触发）

**2. 任务项勾选（轻量口径）**
- 来源：[prd.md#64-渲染区markdown-语法预览编辑交互](../../requirement/prd/PRD.md#64-渲染区markdown-语法预览编辑交互) / 契约 `ren-task:check`（PEND-15）
- 触发：点击任务项勾选框
- 前置条件：文件非只读
- 操作：`.md` 任务语法写回（关键参数 = 该行 `- [ ]` ↔ `- [x]` 状态位切换）
- 期望数据（写回字段结构示例）：`- [ ] 图片浮层尺寸/对齐写入 .md 语法` → `- [x] 图片浮层尺寸/对齐写入 .md 语法`，同行其余内容与同列表其他项不变（AC-RULE-04 状态由 .md 承载）
- Loading 状态：无（即时切换回显）
- 期望效果：勾选框即时回显两态（UI-IXD-09）；autosave 落盘；一次 Ctrl+Z 还原；**不回 toast**（PEND-15 轻量操作显式豁免，差异声明登记于 i18n 注释与自测报告）
- 空态处理：无

**3. 只读拦截**
- 来源：[tech-design.md#10-异常处理](../../design/tech-design.md#10-异常处理)
- 触发：只读文件上拖拽落位或点击勾选框
- 前置条件：文件只读
- 操作：全局拦截（契约面 = `ren-list:drag-handle` / `ren-task:check` 禁用规则）
- 期望效果：拦截不写入、不半提交、toast「文件为只读，无法修改，可另存后编辑」（AC-ERR-08）；另存为副本后可正常拖拽/勾选
- 空态处理：无
