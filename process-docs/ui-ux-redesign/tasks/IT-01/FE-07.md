# FE-07 - toast 动作按钮能力（useToast+ToastHost/5s 驻留/撤销按钮/多 toast 队列）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_07_global.html`

> 来源：[prd.md#65-全局交互](../../requirement/prd/PRD.md#65-全局交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构)

新增 toast 动作按钮基座：`hooks/useToast.ts` + `components/ToastHost.tsx`（照 Dialog/ctxMenu 单例 bus 模式，App.tsx 仅一行装配转发，2642 行债不加重）。能力：toast 支持动作按钮（结构操作回执含「撤销」按钮）、**5s 驻留**（PEND-05，不随鼠标悬停变长、不提前消失）、撤销按钮点击等效 Ctrl+Z 并回执「已撤销」、多 toast 队列（新 toast 顶替旧 toast，同屏至多 1 条或短队列）、既有 showToast 字符串调用点全量迁移到新基座（行为不回归）。冻结文案含 undo 后缀「（Ctrl+Z 可撤销）」由调用方拼装（FE-01/02/04/05）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| toast 浮层 | toast 容器 | ToastHost | 编辑区下方居中浮层（ui_07 标注位） | 圆角卡片 + token 投影 | 隐藏 | 有消息时浮现 |
| toast 浮层 | 消息文本 | ToastMessage | 容器左侧 | 冻结回执文案（i18n key 渲染） | — | 5s 后自动消失（PEND-05） |
| toast 浮层 | 「撤销」按钮 | ToastAction | 消息右侧 | accent 文字按钮 | 结构操作类 toast 显示 | 点击执行 undo → 文案换「已撤销」→ 5s 后消失 |
| toast 浮层 | 队列替换区 | ToastQueue | 同位置 | — | — | 新消息到达即替换当前 toast |

### 交互操作

**1. 结构操作回执 toast + 撤销按钮（核心）**
- 来源：[prd.md#65-全局交互](../../requirement/prd/PRD.md#65-全局交互) / [tech-design.md#4-核心处理流程](../../design/tech-design.md#4-核心处理流程)
- 触发：任一表格结构 op 执行成功（插/删/移行列、缩放、对齐、删表）
- 前置条件：toast 基座已装配；op 单事务入 undo 栈
- 操作：`toast({ message, action: { label: 撤销, run: undo } })`；期望数据示例：消息「已删除第 3 行（Ctrl+Z 可撤销）」+ 撤销按钮
- Loading 状态：同步，无 loading
- 期望效果：toast 驻留 5s；点撤销 → 执行一次 undo（一步还原）→ 文案改「已撤销」再驻留 5s；Ctrl+Z/编辑菜单与按钮三入口等效（AC-OP-12）
- 空态处理：无操作时无 toast

**2. 5s 驻留与队列（PEND-05）**
- 来源：[prd.md#65-全局交互](../../requirement/prd/PRD.md#65-全局交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构)
- 触发：toast 出现 / 连续多次操作
- 前置条件：不适用
- 操作：固定 5000ms 计时；新 toast 到达立即替换当前并重置计时
- Loading 状态：无
- 期望效果：驻留恒 5s（不因 hover 延长）；连续操作最新回执可见，无叠层遮挡正文
- 空态处理：不适用

**3. 既有 showToast 调用点迁移（非回归）**
- 来源：[prd.md#65-全局交互](../../requirement/prd/PRD.md#65-全局交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构)
- 触发：既有字符串 toast 调用（自动保存失败/只读提示等）
- 前置条件：调用点全量盘点
- 操作：App.tsx `showToast` 字符串状态迁移到 useToast bus；调用点改为 `toast({ message })` 无动作按钮形态
- Loading 状态：无
- 期望效果：既有文案/出现时机不变，仅承载层更换；App.tsx 净增一行装配
- 空态处理：不适用
