# FE-02 - 表格结构操作键位改造（Shift 升档 3 键/Ctrl+Shift 分流/Ctrl+Enter 专职插行/非回归）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_02_table_edit.html`

> 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)

按冻结 5 组键位表（TBL §3.2）与裁决 Q4/PEND-13 改造 `editor/table/keymap.ts`：新增 Ctrl+Shift+Enter / Ctrl+Shift+→ / Ctrl+Shift+← 三键（Shift 升档），Ctrl+Shift+←/→ 按 `selection.empty` 上下文分流（有文本选区时词选扩展优先、不触发插列），Ctrl+Enter 专职下方插行不再承担换行语义。键位字面量唯一声明点为 `STRUCT_KEYS`，菜单回显由其单源派生（AC-RULE-11 零例外）；表格键族仅单元格激活态生效，不劫持正文输入（AC-ERR-12）。

### 交互操作

**1. Ctrl+Enter 专职下方插行（PEND-13）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)
- 触发：单元格激活态按下 Ctrl+Enter
- 前置条件：光标位于第 i 行第 j 列激活单元格（i 任意，含末行）
- 操作：keymap `Ctrl-Enter` → op id `insertRowBelow`，单事务整表 replace（含 FE-01 参差补齐）
- Loading 状态：同步 dispatch，无 loading
- 期望效果：新空行插入第 i 行下一行；toast「已在下方插入行（Ctrl+Z 可撤销）」（与 ⋮ 同 op 文案一致）；一次 Ctrl+Z 还原
- 空态处理：不适用

**2. Ctrl+Shift+Enter 上方插行**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)
- 触发：单元格激活态按下 Ctrl+Shift+Enter
- 前置条件：光标位于第 i 行第 j 列激活单元格（i 任意）；i=1 时走 FE-01 表头身份迁移
- 操作：keymap `Ctrl-Shift-Enter` → op id `insertRowAbove`
- Loading 状态：同步
- 期望效果：toast「已在上方插入行（Ctrl+Z 可撤销）」；一次 Ctrl+Z 还原（含表头身份）
- 空态处理：不适用

**3. Ctrl+Shift+→/← 上下文分流插列（Q4）**
- 来源：[prd.md#12-开放问题与风险M16](../../requirement/prd/PRD.md#12-开放问题与风险M16) / [tech-design.md#4-核心处理流程](../../design/tech-design.md#4-核心处理流程)
- 触发：单元格激活态按下 Ctrl+Shift+→ 或 Ctrl+Shift+←
- 前置条件：keydown 时刻读取单元格内嵌编辑器 `selection.empty`
- 操作：`selection.empty=true` → op id `insertColRight`/`insertColLeft`（冒号行新增左对齐项）；`selection.empty=false` → 放行 CM6 词选扩展，不触发插列
- Loading 状态：同步
- 期望效果：无选区路径 toast「已在右侧插入列（Ctrl+Z 可撤销）」/「已在左侧插入列（Ctrl+Z 可撤销）」；菜单回显保留冻结键位不变
- 空态处理：剪贴板/选区为空时不影响分流判定（仅 selection.empty 参与）

**4. 键族作用域与非回归（AC-ERR-12 / PEND-13）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)
- 触发：焦点位于正文普通段落时逐个按表格键族；单元格内按 Shift+Enter / Tab / Enter
- 前置条件：正文段落非单元格激活态；或单元格激活态换行/跳格场景
- 操作：keymap 作用域判定（仅表格单元格激活态注册结构键族）；Shift+Enter 插入 `<br>`、Tab/Shift+Tab 跳格、Enter 下移单元格维持既有绑定
- Loading 状态：同步
- 期望效果：正文段落按下全键族无结构变化、不弹工具栏；三键非回归行为与改造前一致
- 空态处理：无表格文档按下键族无事发生
