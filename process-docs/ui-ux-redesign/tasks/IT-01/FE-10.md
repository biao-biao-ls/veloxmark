# FE-10 - 静息零 chrome 与防抖零抖动（显隐收口/≥150ms 防抖/0px 位移）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_02_table_edit.html`、`../../../../docs/requirements/ui-ux-redesign/ui/ui_07_global.html`

> 来源：[prd.md#65-全局交互](../../requirement/prd/PRD.md#65-全局交互) / [tech-design.md#4-核心处理流程](../../design/tech-design.md#4-核心处理流程)

落地块级 chrome 四态（静息/hover/聚焦编辑/错误，§4.3 状态机）的显隐收口：**静息零 chrome**——无 hover/无编辑态/无浮层时把手/工具栏/chip 等 chrome 全部不渲染，正文零残留（AC-FN-23）；**表格工具栏为例外**——仅编辑态渲染、hover 态不渲染（AC-FN-33/UI-ELEM-05），hover 仅安全选中复制不弹任何工具浮层；**防抖零抖动**——hover 微控件（col-grip 抓手等）出入防抖阈值 ≥150ms（AC-NF-04），快速掠过闪烁 0 次、不半途浮现、浮现期间不遮挡被 hover 正文；**位移 0px**——chrome 显隐全程正文不位移（AC-NF-05），槽位预留/overlay 化消除布局抖动。写作者路径（AC-RULE-13）：hover→点击内容即进聚焦编辑态，写作者动线不断。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 表格工具栏 | chrome 载体 | Toolbar | 表格上方 overlay 位 | token 背景/投影 | 仅编辑态渲染（hover 态不渲染，AC-FN-33） | 编辑态显示（FN-03）/退出编辑态立即隐藏、无残留（FN-31） |
| hover 微控件 | col-grip 抓手等 | Grip/Chip | 列边界等块区 | token 提示线 | 静息不渲染（UI-ELEM-05） | hover 防抖 ≥150ms 浮现/离开延迟消失，快速掠过 0 闪烁（AC-NF-04） |
| 布局 | chrome 槽位 | LayoutSlot | 工具栏占位区 | 预留高度或 overlay | 0px 占位（overlay） | 显隐不改变正文坐标（AC-NF-05） |
| 防抖 | hover 计时器 | Debounce | 模块级 | ≥150ms | — | 进入计时浮现/离开计时隐藏，中途取消不闪 |
| 静息态 | 零 chrome 断言面 | Behavior | 全表格区 | — | — | 静息时工具栏/把手/浮层全不渲染（AC-FN-23） |

### 交互操作

**1. hover 微控件防抖与工具栏例外（AC-FN-33 / AC-NF-04）**
- 来源：[prd.md#65-全局交互](../../requirement/prd/PRD.md#65-全局交互) / [tech-design.md#4-核心处理流程](../../design/tech-design.md#4-核心处理流程)
- 触发：指针进入/离开表格块区（hover 态，未点击）
- 前置条件：非编辑态
- 操作：hover 态不渲染表格工具栏/把手/任何常驻 chrome（工具栏仅编辑态渲染）；hover 微控件（col-grip 抓手等）进入后 ≥150ms 防抖计时到才浮现、离开同延迟消失、快速掠过取消计时；拖选单元格文本复制不触发编辑、不弹浮层
- Loading 状态：无
- 期望效果：闪烁 0 次、不半途出现、浮现不遮挡被 hover 正文（AC-NF-04）；正文位移 0px（AC-NF-05）
- 空态处理：无表格文档无 chrome 路径

**2. 静息零 chrome**
- 来源：[prd.md#65-全局交互](../../requirement/prd/PRD.md#65-全局交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构)
- 触发：Esc/空白回安静（FE-09）或指针离开
- 前置条件：无浮层、非编辑态
- 操作：全部 chrome 显隐状态收口到四态状态机单点
- Loading 状态：无
- 期望效果：静息时零 chrome 残留（AC-FN-23/31/32/33 族口径：显隐收口、无闪烁、无残留）；截图比对静息态与纯正文一致
- 空态处理：不适用

**3. 写作者路径（点击进编辑）与选中复制安全**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#4-核心处理流程](../../design/tech-design.md#4-核心处理流程)
- 触发：hover 态点击表格内容（或静息态点击）
- 前置条件：非禁用区
- 操作：点击内容进入编辑态（工具栏此时才渲染），光标落点正确；纯拖选复制不触发编辑
- Loading 状态：无
- 期望效果：一次点击进编辑（AC-RULE-13/AC-FN-03 衔接），无中间确认/闪烁；复制路径零副作用（AC-FN-33）
- 空态处理：不适用
