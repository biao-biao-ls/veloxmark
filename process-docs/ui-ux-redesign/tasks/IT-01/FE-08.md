# FE-08 - 仅删表确认流（删行/列无确认+确认框冻结文案/Esc 仅关最上层）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_07_global.html`（确认框）、`../../../../docs/requirements/ui-ux-redesign/ui/ui_02_table_edit.html`（删行/列入口）

> 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#10-异常处理](../../design/tech-design.md#10-异常处理)

按 Q3/PEND-04 裁决落地「仅删表确认」策略：**删除表格**（🗑 或菜单「删除表格」）弹确认框，冻结文案「删除后可用一步撤销还原，确认删除该表格」，确认/取消双按钮；**删除行/列不弹确认**，直接执行 + toast+undo 回执（Q3 覆盖 ac.md 旧判据处以裁决为准）。确认框 Esc/点击空白仅关闭最上层确认框、不执行删除（PEND-04）；取消零副作用。确认执行后 toast「已删除表格（Ctrl+Z 可撤销）」+ 撤销按钮一步还原。

### 交互操作

**1. 删除表格确认流（仅此一处确认）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#10-异常处理](../../design/tech-design.md#10-异常处理)
- 触发：工具栏 🗑 或 ⋮/右键「删除表格」
- 前置条件：光标/焦点在表格内；非只读
- 操作：弹确认框（冻结文案）→ 确认则 op id `deleteTable` 单事务删除 + toast「已删除表格（Ctrl+Z 可撤销）」+ 撤销按钮；期望数据示例：确认后源码表整块移除，一次 undo 还原整表
- Loading 状态：同步，无 loading
- 期望效果：删除可一步撤销（AC-OP-09）；🗑 与菜单同走此流
- 空态处理：无表格时 🗑 不可见/不可达

**2. 删行/列无确认直执行（Q3）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#4-核心处理流程](../../design/tech-design.md#4-核心处理流程)
- 触发：菜单「删除行/删除列」或快捷键
- 前置条件：非禁用态（FE-01 判定）
- 操作：直接执行 deleteRow/deleteCol → toast「已删除第 i 行（Ctrl+Z 可撤销）」/「已删除第 j 列（Ctrl+Z 可撤销）」（AC-OP-10）
- Loading 状态：同步
- 期望效果：全程无确认框；一次 undo 还原
- 空态处理：禁用态点击不执行、无确认框、无 toast 报错

**3. Esc/空白仅关最上层（PEND-04）**
- 来源：[prd.md#8-异常与边界M11](../../requirement/prd/PRD.md#8-异常与边界M11) / [tech-design.md#10-异常处理](../../design/tech-design.md#10-异常处理)
- 触发：确认框开启时按 Esc / 点击遮罩空白
- 前置条件：确认框为最上层浮层
- 操作：仅关闭确认框，不执行删除，不触发一键回安静（与 FE-09 分层接线）
- Loading 状态：无
- 期望效果：零副作用关闭；再次 Esc 才走一键回安静（AC-ERR-07）
- 空态处理：无确认框时 Esc 走 FE-09 常规收拢
