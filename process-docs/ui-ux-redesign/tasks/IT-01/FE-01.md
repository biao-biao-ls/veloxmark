# FE-01 - 表格结构操作语义改造（表头身份迁移/删首行下移/参差补齐矩形/最小结构禁用/单事务）

## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_02_table_edit.html`

> 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)

### 交互操作

**1. 首行上插表头身份迁移（insertRowAbove，i=1）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)
- 触发：op id `insertRowAbove`（锚定第 1 行激活单元格，经快捷键/⋮/右键任一入口）
- 前置条件：表格处于编辑态，光标位于表头行激活单元格
- 操作：op `insertRowAbove(model, at=1)` → 单事务整表 replace：空行插入原表头位置并升为表头，原表头降级为 body 首行，冒号行仍为源码第 2 行
- Loading 状态：无异步过程，单次 dispatch 同步完成
- 期望效果：输出 `{ changes, nextActive }` 一次写回；undo 栈压入单条事务，一次 Ctrl+Z 还原表头身份与行序逐字节一致
- 空态处理：不适用（表至少 1 行 1 列）

**2. 删首行表头身份下移 + 末行禁删（deleteRowOp，PEND-12）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)
- 触发：op id `deleteRow`（锚定首行）或菜单「删除行」禁用判定
- 前置条件：删除首行时存在 body 行；表头为最后一行时禁用
- 操作：`deleteRowOp(model, 1)` 存在 body 行时执行删除并令原首条 body 行升为表头；`canDeleteRow(model)` 在「行数=1」或「表头为末行」时返回禁用
- Loading 状态：同步执行，无 loading
- 期望效果：删除后冒号行仍第 2 行；禁用态下点击不执行、不弹 toast 报错（禁用即语义）
- 空态处理：行数=1 时禁用，不产生空表/空表格语法残留

**3. 参差表结构操作单事务补齐矩形（PEND-07）**
- 来源：[prd.md#8-异常与边界M11](../../requirement/prd/PRD.md#8-异常与边界M11) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)
- 触发：任一结构操作（插/删/移行列、⊞ 缩放）作用于参差表
- 前置条件：表中存在单元格数不等的行
- 操作：`modelToGrid`/`opFrom` 路径在单事务内全表补齐为矩形（空缺补空单元格），冒号行列数同步，写回一次 dispatch
- Loading 状态：同步执行
- 期望效果：各行既有内容不丢失、不错位；一次 Ctrl+Z 一并还原参差态（还原前源码逐字节一致）
- 空态处理：不崩溃、不抛未捕获异常，插入位置与锚定单元格语义一致

**4. 最小结构禁用判定（AC-ERR-02）**
- 来源：[prd.md#8-异常与边界M11](../../requirement/prd/PRD.md#8-异常与边界M11) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)
- 触发：菜单渲染前读取禁用规则
- 前置条件：表格处于行数=1 或列数=1（含 1×1）
- 操作：`canDeleteRow`/`canDeleteCol` 纯函数输出禁用布尔（行数=1 禁删行、列数=1 禁删列，另一维度未达最小值的删除项仍可点）
- Loading 状态：同步
- 期望效果：opsTable 禁用规则消费同一数据源，灰显与不可执行一致
- 空态处理：1×1 表两项删除均禁用
