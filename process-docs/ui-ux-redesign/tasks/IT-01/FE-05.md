# FE-05 - ⊞ 网格选择器可选范围改造（max(20,R0)×max(12,C0) 动态上界/拖选缩放/超限表可选）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_02_table_edit.html`

> 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)

改造 `editor/table/gridPicker.ts`：可选范围由固定 `GRID_MAX_ROW=20 × GRID_MAX_COL=12` 改为运行时逐维上界 `max(20, 当前行数 R0) × max(12, 当前列数 C0)`——超限表（如 25×15）自身行列全部可选（AC-FN-04/AC-ERR-13），缩放仅按拖选值执行（含缩到 1×1，不设最小值下限钳制之外的额外约束）。拖选交互与 §4 按钮组（1×1/2×2/3×3/自动适应窗口）沿用，toast 回执冻结文案「表格缩放为 R×C（Ctrl+Z 可撤销）」。缩放事务复用 FE-01 单事务语义（含参差补齐、undo 一步还原）。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| ⊞ 网格选择器 | 格点矩阵 | GridPicker | 工具栏 ⊞ 下方浮层 | 亮格 hover 高亮 + 已选区 accent 底 | 上界 max(20,R0)×max(12,C0) 动态渲染 | 拖选扩大/缩小高亮区，读数实时更新 |
| ⊞ 网格选择器 | 尺寸读数 | Label | 矩阵下方 | 「R × C」 | 当前表格 R0×C0 | 拖选值实时改写 |
| ⊞ 网格选择器 | 4 预设按钮组 | Button | 读数下方 | 1×1 / 2×2 / 3×3 / 自动适应窗口 | — | 点击立即按预设值缩放（AC-RULE-12） |
| ⊞ 网格选择器 | 超限表可选区 | GridCell | R0>20 或 C0>12 时矩阵扩大 | 既有亮格样式 | — | 超出 20/12 的行列格点亮且可拖选（AC-ERR-13） |

### 交互操作

**1. 拖选缩放（核心）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)
- 触发：⊞ 点击展开 → 格点按下拖动 → 松开
- 前置条件：表格处于编辑态；矩阵上界已按 max(20,R0)×max(12,C0) 渲染
- 操作：松开时取拖选 R×C → op id `resizeTable` 单事务缩放（扩行列补空单元格/缩行列删多余，表头身份迁移规则随 FE-01）；期望数据示例：拖选 4×3 后 toast「表格缩放为 4×3（Ctrl+Z 可撤销）」
- Loading 状态：同步，无 loading
- 期望效果：源码表恰为 R×C；一次 Ctrl+Z 还原原行列与参差态
- 空态处理：拖选 1×1 允许执行（AC-OP-07 缩到 1×1）

**2. 超限表自身行列可选（AC-ERR-13）**
- 来源：[prd.md#8-异常与边界M11](../../requirement/prd/PRD.md#8-异常与边界M11) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)
- 触发：打开 ⊞（当前表 25×15 等超限形态）
- 前置条件：R0>20 或 C0>12
- 操作：矩阵逐维扩展到 R0×C0；拖选任一自身行列格可确认缩放
- Loading 状态：同步
- 期望效果：超限表原尺寸格点全部可达，可缩放回 20×12 内任意值或保持/微调自身尺寸
- 空态处理：不适用

**3. 预设按钮组**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)
- 触发：点击 1×1 / 2×2 / 3×3 / 自动适应窗口
- 前置条件：⊞ 浮层展开
- 操作：直接按预设 R×C 执行 resizeTable；「自动适应窗口」按既有窗口宽度估算列数逻辑
- Loading 状态：同步
- 期望效果：与拖选路径同 toast 冻结文案、同 undo 事务边界
- 空态处理：不适用
