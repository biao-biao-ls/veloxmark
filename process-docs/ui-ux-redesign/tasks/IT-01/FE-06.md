# FE-06 - 列宽拖拽右邻吸收改造（总宽不变/最右列例外/列宽钳制/防误触）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_02_table_edit.html`

> 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)

按 PEND-10 裁决改造列宽拖拽（`col-grip`，保留把手）：拖拽第 j 列右边界时仅第 j 列与第 j+1 列宽度此消彼长、**表格总宽不变**；**最右列**边界拖拽为例外——可增减总宽；全部列宽钳制在正文列范围内（不溢出正文栏、不产生 0 宽/负宽）。列宽持久化复用既有 `tableColWidths`（存储键不新增）。防误触：拖拽过程指针捕获 + 结束阈值判定，误点击不改列宽。

### 页面元素

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |
|------|------|------|-----------|-----------|---------------|---------|
| 列边界 | col-grip 拖拽抓手 | Grip | 每列右边界条状热区 | 拖拽时竖直指示线 | hover/编辑态可见 | 拖拽中 cursor col-resize + 指示线跟随 |
| 列边界 | 右邻吸收反馈 | Layout | 相邻两列 | 拖拽中实时刻度 | 两列宽和恒定 | 松手后写回 tableColWidths |
| 最右列边界 | 总宽可变抓手 | Grip | 末列右边界 | 拖拽指示线 | — | 拖拽增减总宽，钳制正文列内 |
| 状态栏/存储 | tableColWidths | PersistedState | `veloxmark.session` | 数字列宽数组 | 文档既有列宽 | 拖拽结束后持久化 |

### 交互操作

**1. 中间列右邻吸收（总宽不变）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)
- 触发：拖拽第 j 列右边界 col-grip（j < 末列）
- 前置条件：表格处于 hover/编辑态；抓手命中
- 操作：`nextWidth[j] = w`，`nextWidth[j+1] = 旧(j)+旧(j+1)-w`（`next[col] = w` 右邻吸收，widget.ts onUp 改造）；期望数据示例：两列 120/120 拖到 150/90，总宽 240 不变
- Loading 状态：同步；拖拽中实时渲染，无 loading
- 期望效果：表格总宽像素级不变；松手写回 tableColWidths；列宽拖拽进 undo 单事务，一次 Ctrl+Z 还原列宽（对齐 AC-OP-11 判据 3，不采用「拖拽前值持久化还原」替代路径）
- 空态处理：不适用

**2. 最右列边界总宽可变（例外）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)
- 触发：拖拽末列右边界
- 前置条件：表格处于 hover/编辑态；抓手命中，j = 末列
- 操作：仅改末列宽，总宽随之增减；宽度钳制 [minColWidth, 正文列宽]
- Loading 状态：同步
- 期望效果：总宽可增可减但不溢出正文列；不触发右邻吸收
- 空态处理：1 列表拖其右边界即走此例外路径

**3. 钳制与防误触（AC-ERR-03 / UI-IXD-16）**
- 来源：[prd.md#8-异常与边界M11](../../requirement/prd/PRD.md#8-异常与边界M11) / [tech-design.md#9-数据校验规则](../../design/tech-design.md#9-数据校验规则)
- 触发：拖拽接近极限值 / 单击未拖动
- 前置条件：拖拽会话进行中
- 操作：宽度钳制 min/max（min=`minColWidth`，取 48px 并 token 化常量集中一处，与场景 2 的 `minColWidth` 同源；max=正文列宽）；单击无位移不写回
- Loading 状态：同步
- 期望效果：无 0 宽/负宽/溢出正文；误点击列宽不变、无异常弹窗
- 空态处理：不适用
