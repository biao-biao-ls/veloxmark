# FE-11 - 冻结文案 i18n 双字典与样式 token 基座（toast/确认文案 key 双写对齐/新浮层 token）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_07_global.html`、`../../../../docs/requirements/ui-ux-redesign/ui/ui_02_table_edit.html`

> 来源：[prd.md#65-全局交互](../../requirement/prd/PRD.md#65-全局交互) / [tech-design.md#83-组件结构](../../design/tech-design.md#83-组件结构)

基座任务（P1，供 FE-02/04/05/07/08/10 消费）：① **冻结文案进 i18n 双字典**——toast 回执族（「已在上方/下方插入行（Ctrl+Z 可撤销）」「已在左侧/右侧插入列（Ctrl+Z 可撤销）」「已删除第 i 行（Ctrl+Z 可撤销）」「已删除第 j 列（Ctrl+Z 可撤销）」「已删除表格（Ctrl+Z 可撤销）」「已撤销」「表格缩放为 R×C（Ctrl+Z 可撤销）」「第 j 列对齐：左对齐/居中/右对齐（Ctrl+Z 可撤销）」）、确认框「删除后可用一步撤销还原，确认删除该表格」、只读/autosave 失败族，全部以 i18n key 承载，en.ts+zh.ts 同步新增且 key 全对齐（AC-FN-28）；② **样式 token 基座**——toast/确认框/⋮ 菜单/网格选择器新分区所需 token 补进 `:root` 唯一声明点，间距/圆角用 `--space-*`/`--radius-*` 不写裸 px 新值，`.theme-light`/`.theme-dark` 仅翻 token 值（零选择器级补丁，AC-RULE-16）；③ i18n key 对齐测试与 token 宪法断言就位（AC-ERR-08/15 口径）。
