# FE-04 - 表格工具栏与⋮/右键同源菜单（五组分组/回显单源/禁用规则/键盘通道兜底）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`../../../../docs/requirements/ui-ux-redesign/ui/ui_03_table_menu.html`（菜单面）、`../../../../docs/requirements/ui-ux-redesign/ui/ui_02_table_edit.html`（工具栏）

> 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)

改造工具栏与 ⋮/右键菜单为四面同源面：⋮ 与右键为同一菜单面（同 id/同分组/同禁用/同回显），菜单按五组呈现（行操作/列操作/对齐/单元格/结构删除，menu-tree §4 五组为 UI 真值，grill-rulings 生成期差异 §1）；快捷键回显由 `STRUCT_KEYS` 单源派生（有键项 100% 回显、无键项右侧留空）；禁用规则与 FE-01 判定同源（首行上移/首列左移灰显、表头末行禁删、行数=1/列数=1 禁删）；菜单限高滚动 + 边缘翻转全项可达；对齐三键按下态即时回显；键盘通道兜底：Shift+F10/Menu 键唤出 ⋮=右键同源菜单 → 方向键遍历 → Enter 执行（Q8，不补专键）。全部结构操作回执 toast 冻结文案（含 undo 后缀）。

### 交互操作

**1. ⋮/右键菜单打开与五组呈现**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)
- 触发：点击工具栏 ⋮，或单元格内右键，或 Shift+F10/Menu 键（键盘通道）
- 前置条件：表格处于编辑态（至少一单元格激活）
- 操作：opsTable 拼装 19 项五组菜单面；无 HTTP 调用（本地 op id 路由）
- Loading 状态：同步展开，无 loading
- 期望效果：菜单按行操作/列操作/对齐/单元格/结构删除五组渲染，组间细分隔线；⋮ 与右键项集/分组/顺序逐项一致（镜像全同）
- 空态处理：不适用

**2. 结构操作执行与 toast 回执（四面同源）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#4-核心处理流程](../../design/tech-design.md#4-核心处理流程)
- 触发：点击菜单项/工具栏按钮（op id 路由）
- 前置条件：非禁用项；表格非只读
- 操作：op id `moveRowUp`/`moveRowDown`/`moveColLeft`/`moveColRight`/`alignLeft`/`alignCenter`/`alignRight` 等 → 单事务 dispatch；期望数据示例：toast 消息串「已上移该行（Ctrl+Z 可撤销）」「第 j 列对齐：居中（Ctrl+Z 可撤销）」
- Loading 状态：同步
- 期望效果：toast 显示冻结回执文案（与快捷键/工具栏同 op 文案完全一致）；对齐类操作冒号行第 j 项即时改写并回显；移行时列对齐不变、移列时冒号行对齐项随列交换
- 空态处理：剪贴板空时 pasteCell 无事发生（静默）

**3. 禁用规则与灰显（表头保护 + 最小结构）**
- 来源：[prd.md#61-表格交互](../../requirement/prd/PRD.md#61-表格交互) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)
- 触发：菜单渲染前判定 / 点击禁用项
- 前置条件：首行（表头）/首列/行数=1/列数=1/表头为末行
- 操作：禁用规则消费 FE-01 `canDeleteRow`/`canDeleteCol` 与首行上移/首列左移判定；禁用项渲染 `is-disabled` 灰显
- Loading 状态：同步
- 期望效果：点击禁用项不执行、无 toast 报错、无异常弹窗（AC-ERR-05/06）；「上插行」「左插列」等非禁用项保持可点（AC-FN-24）
- 空态处理：1×1 表删除行/列均灰显

**4. 键盘通道兜底（Q8）**
- 来源：[prd.md#12-开放问题与风险M16](../../requirement/prd/PRD.md#12-开放问题与风险M16) / [tech-design.md#5-领域模型](../../design/tech-design.md#5-领域模型)
- 触发：单元格激活态按 Shift+F10 或 Menu 键
- 前置条件：EditorContextMenu 键盘遍历（方向键/Enter/Esc）已具备，仅补唤出接线
- 操作：唤出 ⋮=右键同源菜单 → 方向键遍历菜单项 → Enter 执行 op；禁用项同步灰显不可达
- Loading 状态：同步
- 期望效果：无专键项（删除行/列、对齐三键、⊞ 缩放、删表）键盘可达；键位表维持冻结 5 组不增键
- 空态处理：焦点在正文时 Shift+F10 不唤出表格菜单
