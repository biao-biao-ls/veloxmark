# FE-02 - 全域对照走查与收尾核验（NF/OP/ERR/ELEM/RULE 专项）

<!-- REQUIRED:任务目标 -->
## 任务目标

期 2/3/4 全部实现收敛后，执行全域对照走查与非功能/导出/数据层收尾核验：深浅主题各一遍全界面对照走查、Win10/11×深浅四组合、1280×768-4K 分辨率冒烟、对比度/命中区域/防抖核验、30 行 × 12 列性能、导出三通道一致性、autosave 对账、主题色四副本同步、数据层零迁移声明，并以 converge 三关收口。任一条目未通过则回单项迭代修复后重走该条目。

### 页面元素

- 全部块级渲染物与 chrome：表格工具栏/⋮/⊞、块级浮层、把手、chip（对照 ui_01..ui_07 七页原型）
- 弹层族：菜单栏（ui_04）、右键/⋮ 菜单（ui_03）、确认框/toast（ui_07）、图片/链接浮层（ui_06）
- 侧栏（ui_05）：文件树/大纲、焦点环三态
- 导出通道：HTML/PDF/富文本导出物；状态栏保存态；`.md` 源码落盘面

### 交互操作

1. **性能与防抖核验**：30 行 × 12 列表格执行任一结构操作，测量「执行触发 → 视觉更新完成」≤100ms（AC-NF-01）；约 20 页/2000 行文档（含表格/公式/代码块）连续滚动帧率 ≥30fps（AC-NF-03）；hover 控件出入防抖 ≥150ms、快速掠过闪烁 0 次、位移 0px（AC-NF-04/05 已由 IT-01 承载，本任务回归抽查不重复计）
2. **命中区域与提示**：逐个 hover 检查全部块级可点击控件（工具栏、块级 chrome、浮层按钮、把手、chip）均有 hover 提示，覆盖率 100%（AC-NF-07）
3. **对比度与主题色**：深浅主题各一遍测量正文/控件文字对比度 ≥4.5:1（AC-NF-09）；逐项核对全部块级渲染物/弹层/控件文字使用主题 token 配色、无未适配硬编码浅色块、⊞ 网格单元格边界可辨（AC-ERR-14）；核对主题色四副本（styles.css token / exportCss / palette / hljsTokens）色值一致、导出与编辑视图无色差（UI-ELEM-06）
4. **平台×主题×分辨率组合**：Windows 10 与 Windows 11、系统深色/浅色共四种组合走查清单通过率 100%（AC-NF-10）；1280×768 至 4K 各尺寸执行冒烟操作集（表格结构操作、菜单展开、大纲跳转、渲染区编辑、Esc 收拢）无控件裁切不可达（AC-NF-11）
5. **导出与落盘对账**：含已完成结构操作的表格分别经 HTML/PDF/富文本导出，行列数/内容/对齐/冒号行逐项一致且观感无色差（AC-OP-17）；结构操作后逐项核对 .md 源码含变更、状态栏「已保存」、无数据丢失（AC-OP-19）
6. **数据层声明核验**：.md 仍为唯一数据源、存盘纯 .md、无新增数据实体、无数据迁移（AC-NF-13）
7. **用户旅程无权限差异**：四类用户（重度写作者/复杂排版/阅读审阅/新用户轻度）核心旅程各走一遍，无权限差异（AC-RULE-18）
8. **走查总口径与收口**：深浅两遍全界面对照走查清单通过率 100%，任一条目未通过 → 回单项迭代后重走该条目（AC-NF-15）；收口执行 converge 三关：typecheck 双 tsconfig + Vitest 单测 + cdp 冒烟且 e2e 缝契约未破坏（AC-NF-16、AC-RULE-17 口径）

### 分批执行与留档协议

8 个核验域按域分批执行（每批一份留档条目，不合并）：①性能与防抖 ②命中区域与提示 ③对比度与主题色四副本 ④平台×主题×分辨率组合 ⑤导出与落盘对账 ⑥数据层声明 ⑦用户旅程 ⑧双主题走查总口径与 converge 收口。每批执行后在走查清单留档「批次号 + 条目结果 + 问题条目去向（回炉任务 id）」，全部批次留档齐备后方可进入阶段 3/4 验收；单批次可独立成 session，以留档条目为续跑锚点。

### 涉及文件

- 无产品代码改动（纯核验任务）；发现问题登记 change-log 并回对应单项任务（IT-01/02/03.FE-*）
