# FE-01 - 验收基线修订与文档收敛（ac.md PEND 转正/附录别名对账/总看板收敛）

## 任务目标

以 `design/adr/grill-rulings.md` 为唯一裁决真源，把 ac.md 中 AC-PEND-01..16 全量转正为正式条目并完成 4 处措辞对齐；对附录 A/B/C 的 AC-01..22 别名做双向溯源对账；建立总看板 ui-redesign-tasks.md 并收敛既有看板条目；登记期 1 门禁已闭证据。闭合跨迭代 self-check-gate「AC 全覆盖」维度的文档承载缺口。

### 页面元素

- `docs/requirements/ui-ux-redesign/ac.md`：AC-PEND-01..16 条目、AC-RULE-15/17、AC-OP-10、AC-FN-05、附录 A/B/C 别名映射表
- `process-docs/ui-ux-redesign/design/adr/grill-rulings.md`（只读：PEND 闭合状态表 + 生成期差异登记）
- `process-docs/ui-ux-redesign/design/adr/e2e-contract-delta.md`（只读：AC-RULE-17 修订口径）
- `docs/ui-redesign-tasks.md`（新建：总看板）
- `docs/refactor-tasks.md`、markdown-ux-optimization 看板（收敛标注）

### 交互操作

1. **PEND 转正**：逐条将 AC-PEND-01..16 按 grill-rulings.md 对应裁决（01→Q6、02→Q7、03→Q4、04→PEND-04 模态叠加、05→PEND-05 toast 5s、06→Q8、07→PEND-07 补齐矩形、08→Q9、09→PEND-09 >5 行折叠、10→PEND-10 右邻吸收、11→Q5、12→PEND-12 表头下移、13→PEND-13 专职插行、14→PEND-14 显式豁免、15→PEND-15 差异声明、16→Q3）改写为正式条目：删除 `[PENDING]` 标记，Given/When/Then 判据文字与裁决要点逐条一致
2. **措辞对齐 4 处**：AC-RULE-15（确认流收窄为仅删表）、AC-RULE-17（改为「已登记的契约集演进为准入变更，此后变更须走登记流程」）、AC-OP-10（删行/列无确认回执 + 表头身份下移）、AC-FN-05（⋮ 菜单按五组口径含单元格组）；冻结中文文案以 ac.md 为准**不改文案面**（生成期差异登记 #2）
3. **别名对账**：附录 A/B/C 的 AC-01..22 与正文规范 id 双向核对——每个别名可追到正式 id、每个正式 id 有承载任务（本任务 frontmatter 即登记面）；发现悬空映射就地修正并留痕
4. **总看板收敛（AC-FN-34）**：新建 `docs/ui-redesign-tasks.md`，按期分组（期 2/3/4）可追溯到 PRD 5.3 交付主流程 E 步骤；逐项核对 refactor-tasks / markdown-ux-optimization 条目去向：范围内条目收敛入总看板无遗漏、迭代池条目显式标注「另立需求」
5. **期 1 门禁留档（AC-FN-26/27）**：登记《UI/UX 设计规范》五部分定稿评审记录（视觉原则/交互模式库/chrome 规范扩展/快捷键总表/信息架构，快捷键总表为菜单提示唯一派生源）与原型用户评审通过记录（评审通过前不启动实现阶段代码改造的前置门禁已满足）

### 涉及文件

- `docs/requirements/ui-ux-redesign/ac.md`（修订，唯一改动面）
