## 一致性确认（无偏差，仅记录正面证据）

以下为双图核对一致的项，不计入清单，供主 agent 裁决时参考：

1. **收拢后终态静息**：quiet 态图中菜单与表格工具栏均消失、无浮层残留，与设计角标「终态必为静息」「不存在工具栏残留、半展开菜单、浮层驻留」一致。
2. **焦点回归正文**（页面元素「焦点回归」项）：收拢后正文区出现文本光标（表后空行处），与设计 `.focus-glow`「焦点回正文 · 静息」+ `.focus-caret` 语义一致。
3. **不误伤 toast**（AC-FN-21/22）：收拢后 toast「已删除第 2 行（Ctrl+Z 可撤销）」仍在右下角未被收拢——toast 不属 chrome 收拢对象，与设计（toast 自动消失、不打断输入）及任务口径一致。
4. **零布局抖动 0px**（与 FE-10 衔接口径）：impl 与 quiet 两图正文段落/表格像素位置一致，收拢未引起正文位移。
5. **菜单文案逐字**（读图放大核对，无差字）：行操作「在上方插入行 Ctrl+Shift+Enter / 在下方插入行 Ctrl+Enter / 上移该行 Alt+↑ / 下移该行 Alt+↓ / 删除行」；列操作「在左侧插入列 Ctrl+Shift+← / 在右侧插入列 Ctrl+Shift+→ / 左移该列（灰显）Alt+← / 右移该列 Alt+→ / 删除列」；对齐「左对齐 / 居中对齐 / 右对齐」——与设计键位排版及 ui_03 口径一致（「左移该列」灰显亦符合首列保护语义）。
6. **toast 视觉与文案模板**（场景 B 交叉印证）：深底（#1f2328 系）白字、小圆角、右下角锚定、执行态右侧「撤销」钮（accent 字 + accent 描边）；文案模板「已删除第 2 行（Ctrl+Z 可撤销）」与设计样例「已插入列（Ctrl+Z 可撤销）」同构（操作名随操作变化，非文案偏差）。
