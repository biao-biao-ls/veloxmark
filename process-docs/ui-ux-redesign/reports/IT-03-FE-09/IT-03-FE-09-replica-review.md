## 取稿与读图备注

- 设计稿类型：html（`ui_06_render_zone.html` 主稿 + `ui_01_main_quiet.html` 交叉印证）
- 取稿方式：Read html 源（精确样式值/规则卡文案）；html 型设计稿不产 design.png（与既往报告口径一致：「无 PNG（html 型设计稿）」）
- 读图方式：Read PNG（`IT-03-FE-09-impl.png`，两遍细读）
- 备注：
  1. **任务性质**：FE-09 为交互语义任务，设计稿主交付物是 ui_06 交互规则卡文案「点击语义裁决：内容点击进入编辑 · 拖选/选区后松开=选中复制不弹 chrome · 图/表/代码相邻处点击语义一致——同一次点击只有一种语义，浮层绝不与编辑态抢事件」。实现图按任务验收约定为「拖选文本后无浮层的静息截图」，与规则卡「拖选=选中复制不弹 chrome」的期望呈现一致：图中无任何 hover 浮层、块级工具条、拖拽把手、code-idle chip、图片浮层残留。
  2. **选区色值无设计声明**：两稿均无 `::selection` 样式；实现选区高亮呈浅紫（CM6 默认系，约 `#d7d4f0` 读图）。因无设计稿值，不列偏差；若产品欲用 `--accent-soft`（rgba(9,105,218,0.12) 蓝系）作选区色，属设计补口径后的独立决策。
  3. **Beta 段链接呈源码形态**（`[a link](https://example.com/page)` 括号与 URL 可见、URL 等宽字体）：与本仓实时预览「光标/选区进入装饰范围时跳过装饰回源码态」的既定规则一致（选区正跨该链接），非 chrome 残留、不列偏差；ui_06 区块 B 的蓝链形态对应无选区/无光标进入的静息态。
  4. **#1 需交互复测定性**：133 字符计数与 5:72 光标位支持「选区覆盖 Alpha+Beta 两段」的读图推断，Beta 段行文本未着色据此判为绘制缺口；但也可能是截图瞬间的重绘竞态。主 agent 可派 frontend-dev 一次交互复测（拖选跨链接段落）后判定豁免或修复。
  5. 文案逐字（④）不适用于本图：正文为自测夹具文档（`fe09-click-selftest.md`，Alpha/Beta/head a/head b 等），非设计稿演示文档，无逐字对齐基准；外壳菜单根文案（文件/编辑/视图/插入/帮助）与设计逐字一致。
