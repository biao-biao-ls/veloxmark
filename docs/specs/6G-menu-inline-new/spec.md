# 6G 右键菜单补齐与新建内联输入（任务 6.13 + 6.14）

## What / Why

文件树右键菜单补齐常用项（**在新标签打开 / 在资源管理器中显示 / 刷新**，新建文件夹入口核对），新建（文件/文件夹）从 prompt 对话框改为 **树内内联输入行**（Typora 形态：直接在树中输入名，Enter 确认 / Esc 取消）。评估 P1-7——右键缺项、新建流程割裂（prompt + 内联改名两套体验）。

## 背景与现状

- 菜单三档（`useWorkspaceTree.ts:305-341`）：空白处（根）= 新建文件/新建文件夹/拷贝路径；目录行 = +拷贝相对路径/重命名/删除；文件行 = 拷贝路径/相对路径/重命名/删除。**缺**：在新标签打开、在资源管理器中显示、刷新。
- 新建 = `prompt` 对话框 + 自动 `.md` 后缀 + 完成后进入内联重命名（L181-244）；内联改名已有（`filetree-renaming` class 契约）。
- `TreeMenu`（`components/TreeMenu.tsx:1-76`）自绘单例：fixed 定位、边缘翻转、Esc/外点关闭——保持。
- 多标签（P26）：树点击走 `openDocPath`（已开则激活）；「在新标签打开」对已打开文件 = 激活（无重复 tab 语义，P26 按路径去重）。

## 验收标准（AC）

1. 右键菜单补齐：
   - 文件行 + **在新标签打开**（未打开 = 新 tab 打开；已打开 = 激活该 tab，与 P26 去重语义一致）；
   - 文件行/目录行 + **在资源管理器中显示**（定位该节点；根空白处 = 定位树根）；
   - 任意档 + **刷新**（同 6D 面板刷新）；
   - 目录行新建文件夹入口已存在——核对语义统一（与内联新建共用通道）。
2. 新建（文件/文件夹）改**内联输入行**：树内插入输入行，输入名、Enter 确认、Esc 取消；`.md` 自动后缀语义保持（仅文件）；重名提示不静默覆盖。
3. 6D「+」与菜单新建共用此内联路径（prompt 对话框退役）。
4. 既有菜单项（拷贝路径/相对路径/重命名/删除/拖拽移动）与删除确认流不回归；`TreeMenu` 行为（定位翻转/Esc/外点）不回归。
5. 内联输入与内联重命名（`filetree-renaming`）视觉/交互一致。

## 约束

- 新菜单项 id 用 `data-op` 风格字面量（plan 定名）登记为新契约；既有 `data-op` / 命令 id / `__velox*` 不改。
- `openDocPath` / P26 tabs 语义不改（在新标签打开 = 复用现有通道）。
- `showItemInFolder` 复用 6D/D6 已核通道。
- i18n 纪律 en+zh；删除确认文案不变。
