# 6D 底部栏与「操作」面板（任务 6.7 + 6.8）

## What / Why

文件 tab 补 Typora 式底部操作栏（`temp/typora/typora-2.png` 底栏 + `typora-4.png`「操作」面板，语义经用户 2026-09-23 描述确认）：左「+」新建文件、中当前目录名（点击弹「操作」面板）、「操作」按钮、右「切换列表/树视图」按钮。面板顶部操作组五项：新建文件 / 搜索 / 在资源管理器中显示 / 打开文件夹… / 刷新。评估 P1-4a/4b——底部工具栏全缺，且现有「+」固定建在工作区根。

## 背景与现状

- 文件树底部**无任何操作栏**：操作全在 `sidebar-header` 顶部（目录名 + 搜索 + 「+」，`App.tsx:1428-1467`）；树下只有 `.filetree-blank` filler（`filetree.css:82-85`）。
- 「+」新建固定落**工作区根**（`App.tsx:1439`），prompt 对话框输入名 + 自动 `.md`（`useWorkspaceTree.ts:181-244`）。
- 无手动刷新；watcher 降级时树静默不刷新（`folder.ts:164-167`）。
- 「在资源管理器中显示」：`shell.showItemInFolder` 已有 IPC 收编（2D 记录：`ipc/shell.ts` 收了 image.ts 的 `showItemInFolder`）——需核 RendererApi 是否已 expose 给渲染端。
- 弹层惯例：Dialog / ctxMenu / mermaidLightbox 单例 bus 模式（宪法好模式）。

## 验收标准（AC）

1. 文件 tab 底部常驻操作栏（不随树滚动）：左「+」、中当前目录名、右「操作」+「列表/树」两按钮，布局同 Typora（左中右）。
2. 「+」= 新建文件，落点 = **当前选中目录 → 激活文档所在目录 → 树根**（改进：不再固定根）。
3. 中目录名显示当前树根名（`title` 全路径），点击弹出「操作」面板；「操作」按钮同效（两个入口同一面板）。
4. 「操作」面板顶部操作组五项齐全：
   - 新建文件（同「+」）；
   - 搜索（进入 QuickOpen 文件名模糊搜索——plan D4）；
   - 在资源管理器中显示（系统文件管理器定位树根）；
   - 打开文件夹…（现有 `openFolder` 对话框）；
   - 刷新（手动重扫当前根——watcher 降级兜底）。
5. 右 2 按钮 = 列表/树视图状态切换（**渲染差异由 6.12 实现**；本单元按钮可切换并持久化状态）。
6. 面板开合交互（Esc / 外点 / ×）与现有弹层单例 bus 模式一致，不新增第三种弹层范式。
7. e2e：新增 class / id 登记为新契约（plan 定名）；既有 `data-op` / 命令 id / `__velox*` 不改。
8. **（2026-09-24 补充，6.4a 联动）** 底栏仅在 files tab **有树根**时显示（与空态卡互斥）——未落盘/无根不装工作区面（6.4a「不装工作区」契约的延伸）；有根时底栏常驻（含树内暂无 md 文件的情形）。面板形态对齐 `typora-4.png`：标题「操作」+ ⊗ 关闭 + 五操作项（6E 排序行 / 6F 最近目录段后续插入同一容器，本单元只搭容器）。

## 约束

- App.tsx 不堆逻辑：面板独立组件 `components/SidebarOpsPanel.tsx`（或等价）+ 现有 hook 复用（宪法：App 只装配）。
- 安全：`showItemInFolder` 只传树节点路径（非用户可控串）；不新增 `shell.openExternal` 面。
- i18n 纪律：全部新文案 en+zh 同加。
- 间距/圆角 `--space-*`/`--radius-*`，不写裸 px 新值。
- 6.12（列表渲染）未落地前按钮行为 = 切换偏好值 + 视觉态（AC5 明示分界）。
