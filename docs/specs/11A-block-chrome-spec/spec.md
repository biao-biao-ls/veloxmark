# 11A spec — 「块级 chrome 规范」定稿（11.9 / ⑱）

> 看板任务：⑱ 11.9（`docs/markdown-ux-optimization.md` 实施优先级 P2 横向收口）。

## 背景 / 差距（what & why）

表格/公式/代码/mermaid 的 hover chip、聚焦 chip、工具栏位置在 ③⑦⑧⑪ 等批次各自落地（表格顶部工具栏、块右上 hover 工具栏、math 右上提示 chip、mermaid 左上状态徽标、语言 chip 闭栏右下、退出 chip 面板首行右上），形态是各批次基准截图驱动的**结果**，但没有一份横向规范收口「位置/显隐时机/点击语义」——P3 新元素（图片/链接/列表/标题…）若逐块发明将再次发散。

**What**：把已落地形态收口为一份**「块级 chrome 规范」附录**（落 `docs/markdown-ux-optimization.md` 附录章），并逐块审计 ③⑦⑧⑪ 实际形态与规范的一致性；不一致处**要么改代码要么改规范，显式记录**。红线区补一行指向规范，P3 按规范长 UI。

**Why**：同构机制集中设计是本看板排序原则 2 的横向兑现；后续元素不再逐块发明。

## 审计发现（implement 前置核查）

- **A1（缺陷，改代码）**：math hover 提示 chip（8A，`top:4/right:6`）与 P06 块工具栏（同锚点 `top:4/right:6`，z-20、按钮不透明底）**同角叠放**——hover 时「复制」按钮盖住「公式 </>」chip。8A 落地时未与 P06 组合核查（当时冒烟未签）。
  **修法**：chip 并入工具栏 flex 行、作**最右（贴角）元素**，动作按钮向左排——一排一簇，规范 N2「同锚点簇」条款由此落地（chip class 名/点击语义不变）。
- **A2（差异，改规范）**：退出 chip（`公式 ✓`，面板**首行右上**）与语言 chip（**闭栏右下**）位置不同——不是缺陷而是**角色槽位**不同（退出 chip 对照 `math-focus.png` 右上；语言 chip 对照 `code-focus.png` 右下，9A 公约）。规范 N2 按角色定槽位，机制共用（dualPane 锚线 absolute 零布局）。
- **A3（例外，改规范）**：表格编辑工具栏浮于表头上方（非块内右上）+ 行列把手带——受 UX-P28 F3 零位移契约（红线 10）与 `table-focus.png` 基准双重约束，规范立**交互块例外**条款。
- 其余形态（mermaid 左上状态徽标、错误条+跳源码、9B hover 角标同槽同皮肤、8D 行内 hover 底纹）与规范草案一致，无改码。

## AC（可测试）

1. **规范成文**：附录落在 `docs/markdown-ux-optimization.md`（含 N1 显隐时机 / N2 位置槽位 / N3 点击语义 / N4 皮肤约束 + 各元素×各态实际形态索引表）；红线区新增指向行。
2. **审计闭合**：③⑦⑧⑪（及连带 7C/8C/9B/10B）实际形态与规范一致；不一致处已改代码（A1）或已改规范并显式记录（A2/A3）——记录在 plan 收敛记录。
3. **A1 修复**：math hover 时提示 chip 与动作按钮同排一簇、互不遮挡（chip 贴右角、按钮向左排）；chip class `.cm-md-math-hover-chip` 不改、点击仍冒泡 click-to-source；代码块工具栏按钮顺序（Fold 先于 Copy 的缝契约）零触碰。
4. **收敛门禁**：typecheck/test:unit/madge/e2e 缝核对全过；无新 `.theme-dark` 补丁、无裸色值（N4）。
