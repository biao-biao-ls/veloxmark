设计标注 · 顶部菜单栏
  • 语义分组：分隔线 → 组名升级，一眼可见的信息架构
  • 行业习惯命名（新建/打开/另存为/偏好设置…）
  • 命令 id 全部不变（e2e 缝：window.__velox* / data-op）
  • 展开时延 ≤200ms，菜单下拉投影 0 6px 24px
  • 深浅主题对比度 ≥4.5:1（.theme-dark token 翻值）
  • 「格式 ▸」贴下缘自动上翻：768 高视口内 5 项全可见（末项删除线不裁切）
  • Ctrl+Shift+T 冲突双挂：reopenClosedTab 与 toggleTheme 均标「冲突待裁决」（§8-1）
  • 缩放 / 开发者工具键位双源未裁决 → 回显「待定」（§8-2），不空显
