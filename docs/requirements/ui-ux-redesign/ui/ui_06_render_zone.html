设计标注 · 渲染区
  • 按需浮现、退出干净：浮层不残留半透明遮罩
  • 零布局抖动（位移 0px）：浮层与把手均为绝对定位覆盖层
  • hover 防抖 ≥150ms，快速划过不闪烁
  • 不遮挡正文锚点内容，贴附锚点下方/旁侧
  • 长引用折叠：摘要行 + 展开还原，展开后零字节差异
  • 深浅主题对比度 ≥4.5:1（正文与 UI 文本）
