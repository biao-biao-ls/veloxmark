# P03 偏好设置与会话持久化

优先级：P03 | 类别：功能 | 预估规模：M

## 背景

当前仅主题存于 `localStorage`；`showOutline` 每次启动重置为 true，侧栏模式
（files/outline）不记忆；字体、字号、行高、编辑器最大宽度全部硬编码在
`styles.css`；没有最近文件列表；没有偏好设置界面。

## 目标

提供偏好设置面板，所有外观与行为选项可配置且跨会话持久化；补充最近打开
文件列表。

## 功能需求

### 可配置项
- [ ] 外观：主题（亮/暗/跟随系统）、编辑器字体族、字号、行高、
      编辑器内容最大宽度（窄栏写作模式）
- [ ] 编辑：输入辅助开关（对接 P01）、行号显示开关
- [ ] 行为：启动时恢复上次打开的文件/文件夹、侧栏默认展开与否

### 持久化
- [ ] 侧栏可见性、侧栏模式（files/outline）、侧栏宽度记忆
- [ ] 最近文件列表（最近 10 个，File 菜单内展示，点击打开；失效路径置灰）
- [ ] 窗口位置/尺寸记忆（主进程 `electron-window-state` 模式或自实现）

### 设置 UI
- [ ] 设置面板（模态或独立侧页皆可），分组：外观 / 编辑 / 行为
- [ ] 字号等外观项实时预览（改动立即生效，无需确认）
- [ ] 入口：标题栏/File 菜单 "Preferences…"，快捷键 `Ctrl+,`

## 实现要点

- 渲染进程配置存 `localStorage`（键 `veloxmark.preferences`，JSON 单键
  存储 + 版本号迁移）；窗口几何由主进程存 `app.getPath('userData')` 下
  JSON（主进程生命周期管理更可靠）。
- 字体/字号/行高/宽度通过 CSS 变量注入 `:root`，`styles.css` 现有硬编码
  值改引变量（`--editor-font-size` 等）。
- 最近文件记录点：`openFile` / `openFileFromTree` / `openFromSystem` /
  `saveFileAs` 成功后；主进程或渲染进程维护均可，建议渲染进程 + IPC 同步
  给原生菜单（macOS）。
- 新组件：`src/renderer/src/components/Preferences.tsx`。
- "恢复上次会话"依赖 P12 的会话快照则更完整，本需求先做"恢复上次打开的
  文件路径并只读打开"级别的最小实现。

## 验收标准

1. 改字号为 18px、重启应用后仍为 18px；切换暗色后重启保持暗色。
2. 关闭侧栏后重启，侧栏保持关闭；打开过文件夹重启后侧栏回到 files 模式。
3. File 菜单出现 Recent Files 子菜单，超过 10 项淘汰最旧。
4. 设置面板中所有改动即时生效且无需重启。

## 非目标

- 云同步设置、多配置 profile。
