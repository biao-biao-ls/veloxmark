# P01 编辑输入辅助

优先级：P01 | 类别：UX | 预估规模：S–M

## 背景

当前编辑器对 Markdown 输入几乎没有自动化辅助：列表靠手打、粘贴 URL 不会
变链接、`#` 后不会补空格。Typora 的"顺手"很大程度来自这些细节。这是单
位成本提升日常体验最大的一项。

## 目标

让高频 Markdown 结构的输入"半自动完成"，减少手敲标记的次数。

## 功能需求

### 列表行为
- [ ] 在列表项行首按 Enter：新建同级列表项；空项上按 Enter：退出列表
      （删除空项标记）
- [ ] 有序列表自动递增编号（输入 `2.` 后回车得到 `3.`）
- [ ] Tab / Shift+Tab 对光标所在列表项整体升降级（含子树）
- [ ] 任务列表回车自动插入 `- [ ] `

### 行内快捷输入
- [ ] 粘贴一个 URL 且当前有选区 → 自动包成 `[选区](url)`
- [ ] 粘贴纯 URL 无选区 → 按设置决定是否自动包成 `<url>` 或保持原样
- [ ] `#` + 空格触发标题（保留 `#`，补空格）；连续输入更多 `#` 升级
- [ ] 行首 `>` + 空格、`-`/`*`/`+` + 空格、`1.` + 空格 触发对应块
      （部分可由 CM6 `markdown({ addKeymap: true })` 提供，需核对补齐）
- [ ] 行首输入 3 个以上 `-`/`*`/`_` + 回车 → 分割线

### 包裹增强
- [ ] 现有 Ctrl+B/I/E（`setup.ts` 的 `wrapSelectionWith`）支持"无选区时插入
      标记对并把光标置于中间"和"再次按同快捷键取消标记"
- [ ] 粘贴多行纯文本时若包含 Tab 缩进，可选择性转为列表层级（可选，低优）

## 实现要点

- 主战场：`src/renderer/src/editor/setup.ts`。用 `@codemirror/commands` 的
  `insertNewlineAndIndent` 扩展点或自定义 keymap `Enter` 处理器实现列表
  续行/退出；需要读取 `syntaxTree` 判断当前行为 `ListItem`。
- Tab 升降级：遍历光标所在 `ListItem` 的兄弟范围做统一缩进变更，注意
  有序列表需重排编号。
- 粘贴拦截：`EditorView.domEventHandlers({ paste })`，在 `livePreviewConfig`
  同层新增编辑配置对象。
- 所有行为应可通过一个 `editingAssists: boolean` 配置关闭（为 P03 偏好
  设置预留开关）。

## 验收标准

1. `- foo` 后回车得到 `- `；再回车退出列表，不留空标记。
2. `1. foo` 连续回车产生 1./2./3.，退出后编号不残留错乱。
3. 选中文字后粘贴 URL 变成 `[文字](url)`。
4. Tab/Shift+Tab 只影响当前列表项子树，不影响其他行。
5. 关闭 assists 配置后上述行为全部还原为 CM6 默认。

## 非目标

- 智能纠错/自动格式化整个文档（类似 Prettier 的 format-on-save 不在本需求）。
